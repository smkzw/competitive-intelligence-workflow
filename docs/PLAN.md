## 执行规则（来自 v1 / ciw2 的教训，必须遵守）

1. **一条真实端到端命令优先。** 每个里程碑都以 `ciw run indications/<slug>.yaml` 或网页自助调研跑出真实 release 为准。组件测试通过不能代替。
2. **测试按根因成族写，最后统一跑。** 不搞“改一处、全仓测一次”。`uv run pytest` 必须在 60 秒内跑完，并在干净 clone 上全绿。
3. **不设额外的门。** 不派多模型会商，不做“资格认证”或回执签发链，不保留 24 门户矩阵。真正的核对只有两种：确定性规则，以及异构模型交叉核对（PRD §3）。
4. **缓存只按原件内容键入**，即原件 sha256 + 抽取 schema + 指令，不按代码哈希。改分析或渲染代码不能让已核对的抽取失效。
5. **STATUS 只保留当前块，整块替换。** 不新建 packets/、prompts/、reviews/、receipts/ 这类过程目录。
6. **运行产物不入库。** 包括 workspace、captures、sqlite、第三方原文，`.gitignore` 已经排除。执行包T1明确要求的小型实屏截图存入`docs/screenshots/`，仅此例外。
7. **函数不超过 80 行，文件不超过 600 行**，超出就拆。渲染层、流水线里不得写适应症或药物专用逻辑，这些只放在 `indications/*.yaml`。

## 单写恢复与目录稳定性

一次独立测试发生重复启动，两个作业写同一测试副本，当前产物不接受为科学或UI验收。先做单写保护及进程退出恢复测试，区分当前/历史模型任务；保护源原件和全部已保存模型答复。必要时在新的受控副本从最后独立接受release恢复派生状态，原失败现场只读保留，不手工编造科学映射。新来源仅增量组织已核对目录，冻结后再用唯一进程完成真实核对与浏览器验证。

测试工具自身的等待取消不能代替进程退出。长生成由独立测试者一次启动，原生Bash立即返回，既有私有监督助手保存唯一claim、ready与terminal；owner等待精确PID的OS结束事件，期间不轮询阶段或重派。若PID已不存在而terminal缺失，记执行完整性失败，保全已保存缓存，确认无活跃写者后才能新尝试；不新增产品执行平台。

## M7 膜性肾病真实用户轮根因批

独立网页轮实际6m02s完成C；重开/筛选/键盘通过，但来源语义失败。按一组反例修正：中文主题/别名参与同查询搜索；阈值主题按指标而非预猜数值；句段摘录保留上下文，背景不混救援；多疾病登记保留研究，N/年龄标全研究，目标队列图与其他/未明原始记录分开。检查B、安全性、共同轴及工作台样本量范围等相邻消费者。开发相关批/里程碑全测后冻结，先独立挑战共病/同义词误判及信息丢失，再由原测试者在同来源重建和真实浏览器复验。不得删整个篮子研究或把0例撤回记录改成有入组的研究，不重跑已完成检索。

同源重建后的实际复验仍发现背景方案误索引及主题计数代替横比，按一个有界批收口：共享原字段catalog/主题ID；对复杂条款复用两角色提取连续原文及父条件，内容缓存可恢复，A/B不等待C新调用；主题点选表直接列条款，保留综合矩阵与同查询图表。年龄显示“登记年龄”，与队列原文并存。后端与前端分文件并行，相关回归后一次宽门；冻结候选后由原Cursor实际重建并完成四研究来源及两宽主题任务，不拼旧PASS、不重复检索。通过后换新适应症和报告类型继续原指定双测试者LOOP。

真实续跑遇已返回HTTP429时，仅对此拒绝按Retry-After/有限退避继续，超过预算明确失败；401、超时和未知执行结果不重发。列表父句按Key入排标题与同级列表结构结束；确定性错误回送具体原句/字段标签问题。保持原任务、来源、成功答复与已有采用项，不为修正校验器重做检索或清空缓存；独立来源探针与真实重建接受分开。

本批只补两个共同根因：已明确临时并发/容量/换模429时可有界等候16次、至多900秒且服从更短总timeout；普通429保持6次/180秒，额度/401/503/未知执行结果不重发。C阅读主层用源绑定中文要点，内容/Schema/指令缓存独立于已核条款，跨主题复用；A/B仅复用。不改变两产品模型或生产接纳配置。先独立代码挑战与一次开发宽门，冻结后由指定测试者在受控副本做真实中文表达/两宽/键盘接受；该副本结果不代替原网页全量生成。原任务只在没有活跃写者时继续一次，仍保留旧current和所有成功答复。

## 已核源事实的无模型重建恢复

真实NMPA垂直链发现：普通offline且未启用模型时，公司／公众号事件和论文结果被跳过，旧快照保留但新current丢失既有采用。修复必须按相同原件和任务读取真实已核B条目，不拷旧release或降门；当前schema/引文/研究产品绑定重新校验，源或任务变化、部分缺失及后续修订分别测试。新候选冻结后，指定Cursor用原CRSwNP资料一次无模型离线重建＋audit，逐项比对26旧verified事件和15论文结果及新NMPA版本，不靠总数相等；C完整定义根因由Luna同源四研究复验，两个workspace可并行后端，浏览器仍串行。
