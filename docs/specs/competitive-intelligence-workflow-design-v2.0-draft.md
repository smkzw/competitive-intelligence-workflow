## 1. 一份科学事实，三种投影

共享底座复用 `domain/facts.py::AtomicFactVersion`。三个门户 A/B/C 从同一事实版本读取，消除报告私有事实身份的重复权威。

### 1.1 必须修复的共享摄取缺陷（来源：审阅 F14-F16）

- `version_id` 计算必须覆盖完整科学字段（含 disclosure_state、原文、上下文），不能只 hash normalized_value
- 相同 version_id + 不同完整载荷 = 冲突，不得 INSERT OR IGNORE 吞掉
- 逐事实精确 fragment（source_version + locator + 原文范围），替代整页共享 fragment
- 来源回执绑定实际访问尝试内容，同 source_id 不同字节须新建

### 1.2 派生依赖 DAG

`graph/impact.py` 扩展支持 FACT→DERIVATION→FACT/VIEW 有向无环边。n/N→粗率等 fact→fact 依赖显式登记，重算只沿有证据公式路径。禁止字符串替换模拟传播。

## 2. B 门户：共同工作空间 + 分面

### 2.1 三层比较合同（替代 compatible 布尔值）

| 层 | 职能 | 复用 |
|----|------|------|
| WorkspaceMembership | 该研究是否与当前临床问题相关；核心/支持角色 | 现有 semantic_grouping 的分桶逻辑 |
| FacetPlan | 按真实差异（人群/量表/单位/时间）组织分面 | 现有 _controlled_concept + _canonical_statistical_form |
| NumericFrameEligibility | 哪些记录可共轴绘图 | 现有确定性医学守卫 |

### 2.2 查询守恒

匹配事实集 Q = 可绘制集合 P ∪ 明确显示的不可绘制集合 U。P ∩ U = ∅。图表可多事实派生一点，但必须有显式输入映射。完整表/证据覆盖 Q。

### 2.3 时间模型

保存 anchor、kind=point|interval|schedule、起止/时点、单位与原文。28天=4周仅同锚点/同语义精确换算。累计0-24周 ≠ 24周单次评估。自然月 ≠ 固定4周。缺失不伪造。

## 3. C 门户：设计先例库

### 3.1 DesignClause

每条保留：研究/方案版本、领域/主题、原文/译文、source locator、适用队列/期间/组别、原始顺序、父子/引用关系、结构化变量/运算符/阈值/单位/时间锚点、解析状态。

复合标准用表达式树。全部入排、组别、给药、终点、访视、统计设计全量保存，不截断。

### 3.2 交付门槛变更

删除"至少两条候选设计路径"门槛。一项完整试验即可交付 C 先例页。旧路径数据只读兼容。

### 3.3 查询与呈现

关键词 + 受控中英同义词 + 主题点选 + 可选组合。用户选研究列/基准/主题/期别/给药/人群分类，切共同点/差异点，展开原文。缺失标缺失。长入排条款用可检索对照表。

## 4. A 门户：完整竞争景观

实体/地域/阶段/机制筛选、产品→试验→事实下钻。保留终止/撤回/临床前项目。区分 planned/actual 样本量及未知/明确零。

## 5. 实际事实修订与一致性

### 5.1 修订事务

用户 typed 编辑 → 校验 expected revision → 生成新事实版本 → 计算影响闭包 → 原子切换 → 各页面读同一修订。原始来源和审定快照不覆盖。

### 5.2 安全边界

修订不继承旧独立复核结论；新内容标"用户修订"。需要重新独立核验时复用现有 review issue 入口。

### 5.3 保存校验

有限数、类型、单位、n/N 类型和范围、阈值运算符、统计形式、试验/组别/期间身份、披露状态。0/缺失/不适用不互换。

## 6. 编辑与分享

本地按需 loopback 编辑会话 + 静态离线分享包。分享包含当前有效事实、配置、来源入口。读者双击 HTML 可读、筛选、下钻。修改须由本地工作流编辑器打开。

## 7. 多 Skill 共享执行

合并 A/B/C 的实体/证据域需求为一张 SourcePlan。同内容只获取/解析一次。独立复核由非生产者节点执行。
