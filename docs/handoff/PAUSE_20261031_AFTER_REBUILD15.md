## 3. 系统组件及真正的数据流

```mermaid
flowchart LR
    INPUT[网页需求或适应症YAML] --> PLAN[检索词与临床索引配置]
    PLAN --> SOURCE[登记/论文/中国来源原件]
    SOURCE --> FACT[来源定位与确定性抽取]
    FACT --> CHECK[DeepSeek主抽取与GLM来源核对]
    CHECK --> ANALYZE[临床问题/数值框/设计条款]
    ANALYZE --> RELEASE[不可变release与current]
    RELEASE --> A[A竞品全景]
    RELEASE --> B[B临床结果]
    RELEASE --> C[C设计先例]
    RELEASE --> WB[工作台读模型与Studio候选]
```

|---|---|
|`cli.py / api.py / research.py / pipeline.py`|同一公开运行链；自然语言计划只是检索索引，不是科学事实；所选报告优先、复用已取资料、恢复及写者互斥。|
