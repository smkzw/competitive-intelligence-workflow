# ADR 0006：Phase 2 创新药宇宙与来源真源边界

状态：已批准设计与实施计划的精简执行摘录

## 创新药与宇宙

- 本体输出保存组件和方案各自的适格性、规则版本、证据片段、边界原因和审查回执。
- 单抗、多抗、小分子、PROTAC、siRNA、ADC、融合蛋白等创新模态可由明确规则纳入；抗组胺药、csDMARD、传统激素、仿制药和生物类似药明确排除。
- 创新组件与传统背景治疗组成的方案可纳入，但传统组件不获得独立竞品档案、创新身份或宇宙计数；纯传统组合排除。
- 改良制剂、重定位、固定复方和未知边界项无匹配规则时为 `review_pending`。存在任何待审查项时 `universe_closed=false`，A/B/C 门槛、快照和渲染不得启动；审查决定须保留规则版本、证据和独立回执。
- 竞品宇宙不得用 Top-N 截断；产品名和 NCT/CTR 号不是全局主键。

## 来源路线与恢复

- 来源权威按声明域、地域和披露阶段定义，不使用单一总排名。
- 境外/全球必查 ClinicalTrials.gov，并关联历史版本、结果和论文；PubMed 论文区分主要报告、亚组/事后、综述等角色，后者不得替代主要报告。
- 中国路线必查 CDE、chinadrugtrials.org.cn、丁香园用药助手，并交叉检查 ClinicalTrials.gov、PubMed、监管、会议、公司和指定行业来源。
- 医药魔方 info、药融圈、丁香园 Insight 数据库、米内网、中国药审可直接支持主要疗效/关键安全性、中国开发与监管状态、企业关系/交易和专利，但须保留准确来源角色与披露成熟度。
- 论文不替代登记平台的方案/统计设计字段。现有登记结果、主要论文或监管材料已覆盖关键字段时，补充材料为 `not_required`。
- 尝试结果、路线完成性与事实披露状态分离。技术失败不能写成“未公开”或“无证据”。
- 可重试故障同路径至少三次带时间和退避；持续失败至少两条适用且不同的替代策略；连续两轮不同恢复无门槛信息增益后方可判饱和。
- 历史快照按 `first_disclosed_at` 判断；截止日后首次披露的内容只进入刷新候选，获取日期不决定历史适格性。

## 科学链与验收

- 原文、来源版本、片段、原子事实、规范化值、冲突集合和声明均版本化、可定位且不可覆盖；无法重开的数值不得进入事实层。
- 规范化必须可逆并保留原始值、单位、组别、人群、时间点、分母、方法和披露状态。
- Phase 2 退出 fixture 必须能从来源原文重建实体—片段—事实—声明；传统药不进入宇宙，国内外路线和指定中文来源可追溯。
- 当前阶段不生成正式报告，不扩大安全性测试；用户可见文字继续使用中文临床语境。
