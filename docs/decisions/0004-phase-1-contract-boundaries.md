# ADR 0004：Phase 1 项目与科学真源基座边界

状态：已批准计划的实施摘录

## Task 1.1 当前约束

- 稳定 ID 必须由类型前缀与规范化身份材料确定性生成；相同输入相同、不同对象或命名空间不同。
- 报告选择只允许 A/B/C 且可多选；HTML 始终进入输出，用户只需可选 PDF、HTML 演示稿和可编辑 PPTX。
- 九组状态必须精确且互不替代：路由尝试结果、路由完成性、事实披露/值、事实审查、项目/运行、报告证据、格式产物、下载请求、修订审批。
- 空字符串、`None`、数值 0 不能替代事实披露状态；路由失败不能写入事实披露列。
- 合同默认时区 `Asia/Shanghai`；默认或显式日期在创建时按声明 IANA 时区物化为当日 `23:59:59.999999` 并保存 UTC offset。
- 同一合同版本跨日恢复不重算 cutoff；扩大 cutoff 只能生成新合同版本。

## Phase 1 后续边界

- 项目完全自包含且可移动；持久路径只用相对路径。
- SQLite、内容寻址原文、事件 JSONL、检查点和不可变快照职责分离。
- 能力预检按用户选择适用；缺失只阻断相关报告/格式，用户收到简洁中文原因和下一步。

## 选择理由

Phase 0 已锁定 Pydantic 2.13.4、JSON Schema 2020-12 和 Python 3.12–3.13。Task 1.1 不引入新依赖或替换架构，因此复用已验证栈，避免无收益的重新选型。
