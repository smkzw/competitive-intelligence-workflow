# ADR 0013：首版以站点式 HTML 为唯一必选交付

- 状态：已批准
- 日期：2026-08-31
- 范围：首个可安装的竞品调研多 Skill 工作流版本

## 决定

首版继续完整支持 A、B、C 三类报告，但正式交付与发布验收只把**多页面站点式 HTML**列为必选格式。用户仍只需选择报告类型、输入适应症；站点式 HTML 自动生成，不再要求用户理解或确认输出技术路线。

PDF、HTML-PPT 和可编辑 PPTX 调整为后续可选能力。已经完成的实现、合同、验收记录和暂停检查点全部保留，不删除、不回退，也不计入首版发布阻断条件。未完成的 PPTX 来源包、串行生成、PowerPoint 验收和四格式覆盖维持原检查点，后续恢复时必须沿用同一任务和既有会话，不得伪装成已完成。

## 首版完成口径

1. A、B、C 均为门户首页加真实物理详情页，并共用全局导航、搜索、筛选、下钻和证据定位。
2. 关键证据不足时仍然禁止生成草稿；网络或技术失败必须与“未公开”或穷尽后未找到分开诊断。
3. 首版宿主能力预检默认且必选 `html`；未选择 PDF、HTML-PPT 或 PPTX 时，不检查也不提示其依赖。
4. 用户主动选择后续格式时，仍使用既有格式独立阻断语义：缺少该格式能力只阻断该格式，不影响已经满足条件的站点报告。
5. 首版候选包、三宿主真实试用和最终验收以站点式 HTML 的科学完整性、中文原生表达、交互和真实浏览器视觉结果为准。
6. 原计划中要求四格式齐备才能进入 Phase 9/10 的条款，对首版改为“HTML 已接受即可进入”；四格式全矩阵、PPTX 和相应导出设计进入后续扩展里程碑。

## 设计合同

首版只加载项目内 `contracts/kangzhe/design_specs/ROUTER.md`、`core.md`、`project_profile.md` 和 `track_site.md`。不得把固定 1280×720 幻灯片、PDF 分页或 PPTX 母版规则叠加到门户。

站点候选仍执行定稿前闭环：视觉策划、候选生成、真实浏览器诊断、定向美化、隔离审阅。至少覆盖 1280、1440、1920 px 桌面宽度；首页核心疗效图、安全性热图和疗效—安全性气泡图必须在内容列内完整显示，不能要求用户左右拖动才能看全。

## 恢复边界

后续若用户重新选择 PDF、HTML-PPT 或 PPTX，从各自现有 Trellis 检查点继续。恢复某一格式不得改变站点已锁定的科学快照、覆盖集合和已接受结果；格式自身完成后再追加独立验收，不追溯性修改本首版决定。
