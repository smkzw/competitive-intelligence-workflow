# ADR 0010：事实版本、字段冲突与声明链

状态：Task 2.7 实施依据

## 结论

- 只有已按来源版本重新打开、且原文与证据片段逐字一致的最小片段，才能生成原子事实。事实同时保存原始值、单位、组别、人群、时间、分子分母、抽取方法、披露状态和来源片段。
- 事实标识由科学内容决定，不受生成日期影响。同一事实在次日重跑仍得到同一版本标识；科学内容变化才生成新版本。
- 规范化必须生成新事实版本，保留原始值，并记录规则、规则版本、方法、规范值、逆向表达和上一个事实版本。重复应用同一规则不得制造新版本标识。
- 同一字段、组别、人群和时间范围出现互斥值时，建立字段级冲突集合并同时保留全部来源。未完成裁决时不得按“先到先得”选值。
- 声明分为直接证据、确定性计算和 AI 综合判断。每条声明显式链接支持事实；确定性计算保存公式、输入与复算结果，文字必须与结果一致；AI 综合判断在用户可见文字中明确标识。
- “已报告为零”“未报告”“不适用”“因获取路线尚未解决”等状态不得混写。零值必须有明确零值原文证据；不适用和路线未解决必须分别链接适用性谓词或路线回执。
