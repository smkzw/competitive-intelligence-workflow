# ADR 0009：临床来源定位器绑定版本与结构锚点

状态：Task 2.6 实施依据

## 结论

- 文档分类保留内部角色与中文名称。未知自动文件进入“资料类型待确认”，不得猜成论文、登记或官方资料；用户补充文件保留原文件名，用户无需重命名。
- 登记 JSON 定位器绑定来源版本、快照摘要和精确字段路径；网页定位器绑定标题、同名标题出现次序与段落序号；PDF 表格定位器绑定页码、表名、行号/行名和列名。
- 定位器只能在同一来源版本和同一内容摘要上重开。版本或内容变化时失败，不用全文模糊搜索自动迁移旧定位。
- 内容快照以不可变结构保存。任何无法在绑定快照上重开的数值不得进入事实层。
- 补充材料和用户文件具有独立文档 ID、独立来源版本、内容摘要和父文档关系。规范文件名由稳定文档身份、中文角色、版本和摘要生成；出版商原文件名保留在元数据。
- `EvidenceLocator` 的标题、页、表、行、列、段和 URL 合同同步进入来源版本、证据片段和指南 schema。

## 依赖选择

本任务不新增依赖。结构定位与摘要使用 Python 标准库和既有 Pydantic；后续真实 PDF 抽取沿用项目已锁定的 `pdfplumber`/`pypdf`，本任务只定义其必须产出的可重开结构合同。
