# ADR 0008：中国登记、监管与行业披露连接边界

状态：Task 2.5 实施依据

## 结论

- CDE 与 NMPA 均为中国官方路线，但事件职责不同。CDE 的受理、审评任务、优先审评、突破性治疗、临床试验默示许可等事件逐条保存；NMPA 的批准和说明书状态另存。受理或审评中不得推断为已批准，暂停、撤回和恢复不得覆盖历史事件。
- 中国药物临床试验登记与信息公示平台以 CTR 号作为来源内试验身份，累计保存不可变页面版本。试验状态、方案编号/版本、入排、干预、终点、时间点和已公示结果均保留原字段与页面位置；未出现结果摘要不等于结果为零。
- 丁香园用药助手保留为经过医学编辑的二次药品参考来源，用于说明书、药品身份和安全用药等字段的交叉核验；不能冒充 NMPA/CDE 官方批准、审评或登记来源。适用的 NMPA/CDE 官方页面使用各自官方角色。
- 企业公告、证券披露、新闻稿、Topline、会议摘要和会议演示分别保存披露角色与成熟度。Topline 和会议数值可以支持其明确披露的疗效/安全性字段，但必须标记初步或会议披露，不能冒充登记结果、监管审评或同行评议主要论文。
- 仅 `医药魔方info`、`药融圈`、`丁香园Insight数据库`、`米内网`、`中国药审` 五个账号可作为指定行业权威来源；直接采纳仅限主要疗效/关键安全性、中国开发与监管状态、企业关系与交易、专利。其它字段只作交叉核验，文章数值永不标记为同行评议全文。
- CDE 指南复用 FDA 同一版本化合同，但两条监管轨平行保存，不设普遍优先级。征求意见稿必须标记草案，已废止/已替代版本只作历史材料，不能驱动当前默认。

## 官方核验入口

- CDE 首页与信息公开：<https://www.cde.org.cn/>
- 中国药物临床试验登记与信息公示平台：<https://www.chinadrugtrials.org.cn/>
- 中国登记公开查询：<https://www.chinadrugtrials.org.cn/clinicaltrials.searchlist.dhtml>
- 丁香园用药助手说明：<https://drugs.dxy.cn/pc/about>

## 验证方式

- 离线录制形态测试锁定字段、版本、来源角色、成熟度和位置。
- 实时访问独立诊断；超时、验证码、页面结构变化和访问限制进入技术失败，不写成“未公开”。
- 五个指定公众号的资格来自批准合同；检索可发现文章，但文章只有在账号、标题、日期、链接、内容快照和产品/试验/事件身份都可核验时才进入证据链。
