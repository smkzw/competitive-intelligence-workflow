# PRD v2：竞品调研子系统（医学经理工作台 · 证据调研与方案设计）

版本 2.0，2026-10-27。依据 [DECISIONS.md](DECISIONS.md)。v2 发布于 `codex/ciw-v2-trunk`；旧 main 保留，历史 archive 标签尚未经证实存在。

## 1. 用户与场景

**用户**：康哲医学部医学经理，在工作台的项目里工作。首个项目是 MG-K10 CRSwNP III 期。

**主场景**：立项或写方案前，对一个适应症做一次性深度竞品调研。

**次场景**：临时查一个数值，例如“度普利尤单抗 SINUS-52 第 24 周 NPS 较安慰剂差多少”。

**交付**：只在工作台里展示 HTML 报告。同一份 release 同时喂给工作台读模型和设计 studio 的竞品候选池。

一份调研要回答四个问题：

| 问题 | 门户 |
|---|---|
| 谁在做、做到哪一步（全球 / 中国，阶段、状态、权益方、时间线） | A 竞品全景 |
| 结果多好（主要终点、关键次要终点、组间差与 CI、安全概况） | B 临床结果 |
| 怎么设计的（人群、对照、剂量频次、背景治疗、终点与时点、样本量、救援） | C 设计先例 |
| 本品放在哪里（MG-K10 与竞品同框） | A/B/C 统一高亮本品 |

## 2. 范围

### v1 做

- 一个适应症 YAML 驱动整条流水线：检索 → 获取 → 抽取 → 归一 → 核对 → 分析 → release → 渲染。
- 来源：
  - ClinicalTrials.gov v2（检索、方案、结果，确定性抽取）；
  - Europe PMC / PubMed（按 NCT 关联的论文）；
  - CDE 药物临床试验登记与信息公示平台；
  - NMPA 药品批准信息；
  - 药企官网公告；
  - 微信公众号权威账号（丁香园 Insight、医药魔方 Info）。
- 异构模型交叉核对：非结构化来源由DeepSeek主抽取，cms-smk的glm-5.3-flash读取完整原文和候选核对、纠错与补漏；通过确定性来源校验记verified，剩余进入“待核”。核对者可见候选，不宣称独立盲抽取，不再调用Qwen或第三模型仲裁。确定性校验失败时仅向同一GLM回送错误条目纠正一次；正常条目不重跑，超次或仍失败保留待核，修复阶段不接受新增身份。
- A/B/C 三个中文 HTML 门户：桌面宽屏，ECharts 图 + 同查询表 + 来源链接；在工作台“证据调研与方案设计”里打开。
- 工作台适配器 `ciw_release`：把 release 映射为工作台现有的产品/试验设计/结果读模型。

### v1 不做

PPT/Excel/PDF 导出、离线分享、门户内编辑事实、个人视图配置、定时监测、历史截止日回放、移动端、Skill 安装包与多宿主、药智、排名或综合评分、Meta/NMA。

## 3. 科学合同（硬规则，均有测试）

1. **缺失不是 0。** 登记未报告的数值记为未报告；只有来源明确写 0 才是 0。0/0 不计算比例。
2. **统计对象分开。**
   - 人数（n/N）、比例、均值/LS 均值、中位数、事件次数、调整估计各自建模。
   - 比例只能来自人数 n/N，或来源明确报告的百分比。
   - “percent change” 是连续变量，不是比例。
   - 不同物理单位分别成图，原单位不变；通用文字单位仅规范大小写与空白，不把 g/L 和 g/dL 混为一轴。
3. **组别角色只来自显式信息。**
   - 依据：CT.gov `armGroups.type`（实验/活性对照/安慰剂/空白），结果组与臂的显式匹配。
   - 登记结果匹配不上时显示“组别未匹配”，不猜。D18允许论文按原文明示分组独立呈现、关联研究；无独立登记臂时保留arm_id为空，不猜对应、不改登记，不把汇总拆到剂量组。
   - 产品身份可来自登记臂明确写出的、配置已核实的制剂代号；仅干预通用成分字段未写代号不丢研究。未知角色保持未知，标题或申办方不替代臂身份，联合名称不取首个产品。
4. **组间比较只有两种来源。**
   - 来源报告的 analyses：组间差、CI、p 值、方法。
   - 同一试验内与明确安慰剂臂的差值，标“计算值”，不带 CI。
   - 不同试验之间并列展示，不计算差值。
   - 论文明确报告的调整差值、方向、P值与比较符直接保留，不由舍入后的组均值重算；未报告组数值时不填0，阈值P不能写成确定等值P。
5. **时间点保留原文。** 只做 day↔week 精确换算，月不折算成周。并列图按时间点分面。
6. **域默认 other。** 疗效概念只来自适应症概念字典；PK/PD/免疫原性/安全按通用规则判定，判定不了就归 other，仍然可查。
7. **创新药范围。** 竞品宇宙只纳入创新药（新分子、新靶点、改良新药按配置）；传统药只作为背景、对照或救援出现。宇宙中的每个产品都有纳入理由，未归类的干预单列，不静默丢弃。
8. **每个数字可追溯。** 门户里每个数字都带来源链接、定位（JSON 路径或原文片段）和核对标签：
   - 登记结构化
   - 模型核对（verified；旧双模型一致/仲裁只读兼容）
   - 待核
9. **适应症保留否定原意。** 明确“不伴鼻息肉/without nasal polyps”的研究不因出现“鼻息肉”字样进入CRSwNP核心集合；“伴或不伴”混合队列仍保留原始人群。差异规则只放在适应症YAML。
10. **事件日期与发稿日分开。** 批准/受理日期须由同段原文明确支持；只有宣布“已经获批”时日期留空。结果回顾不登记为新顶线披露，各辖区分别保留。
11. **保留来源冲突。** 登记臂名/角色与干预关联矛盾时保留原件和问题记录；论文按明确药名、登记臂名及角色绑定，不按数组顺序翻转。摘要未给分析N时留空。
12. **登记与研究地域分开。** 中国登记不自动证明全研究仅在中国开展；没有国家清单时不生成国家数量。

## 4. 门户要求

**A 竞品全景**
- 首屏：产品 × 最高阶段（全球 / 中国）矩阵，本品高亮。
- 产品表：通用名/代号、靶点/机制、剂型/途径、研发企业与中国权益方、全球与中国状态、关键试验。
- 时间线：首个受试者入组、主要完成、结果公布、获批。

**B 临床结果**
- 首屏按“临床问题”组织（概念 × 时间点）。每个问题一张跨试验图，展示各组数值和组间差（95% CI），配同查询表。表中列出 N、统计形式、分析人群、来源。
- 安全概况：任何不良事件、严重不良事件、因 AE 停药、死亡，以及按组的高频 AE。
- 多时间点数据用折线图。
- 全部观测提供按药物/研究/原文/分析人群检索及类别筛选、分页与组值下钻；PK、PD、免疫原性、other及未进疗效图的记录仍可查。分页显示范围和总数，保留0、缺失、限定原值及来源统计比较。
- 补充论文结果须在摘要中明确关联登记号，并按D18关联研究、保留论文明确分组或已明确绑定的登记臂；主要结果、总体与亚组分别保留。论文链接与真实核对标签随数值显示，不覆盖登记结果。

**C 设计先例**
- 试验 × 设计维度矩阵，可搜索、筛选。维度包括：期别、设计/盲法、随机比例、关键入选（NPS/NCS 阈值、既往手术/全身激素、合并哮喘）、组别/剂量/频次、背景治疗、治疗期、主要终点与时点、关键次要终点、样本量、地区。
- 单试验详情：完整入排原文和来源链接。
- 主要终点构成及样本量/入组图跟随矩阵同一筛选；无可绘值隐藏图卡，真实0保留；少量研究使用紧凑高度，单日期显示完整年月日。
- 临床主题由适应症YAML配置，索引研究摘要、设计描述、入排、组别与终点描述中的逐字条款。矩阵优先显示，条款原位展开，阈值用字重、深色和下划线强调；原文保持完整，关键词命中不自动等于数值归属或入组资格判断。
- 矩阵研究行支持键盘进入详情，Esc返回实际触发位置。

**共同要求**
- 中文临床表达；药名用正式中文名并保留 INN/代号。
- 不输出内部键名、日志或免责声明墙。
- 1440–2560 CSS px 桌面宽屏可用。
- 按用户要求采用最新康哲Design的近白阅读底、橙色主要操作/当前态、深色正文、清晰字号层级与宽幅下钻；数据区不做倾斜或装饰性运动，不用缩字挤密度。共用组件约束A/B/C，实际页面需目视核验。内部规范与Logo不入公共仓库。

## 5. v1 验收

1. **工程**
   - 在干净 clone 上 `uv sync && uv run pytest` 全绿。
   - `uv run ciw run indications/crswnp.yaml` 一条命令产出 release 和三个门户，可重复运行。
2. **产品**
   - 在工作台 MG-K10 CRSwNP 项目里打开 A/B/C，能回答第 1 节的四个问题。
   - 从 B 任一数字出发，两次点击内能到达来源。
3. **科学**
   - 随机抽 30 个数字对照原件，0 错误。
   - 已上市与 III 期 CRSwNP 生物制剂（以 FDA/EMA/NMPA 获批信息和 CT.gov III 期检索为准）全部出现在 A。
4. **泛化**
   - 只新增 `indications/pnh.yaml`，不改 Python，就能产出 PNH 的 A/B/C。
