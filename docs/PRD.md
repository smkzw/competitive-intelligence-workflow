# PRD v2：竞品调研子系统（医学经理工作台 · 证据调研与方案设计）

版本 2.1，2026-10-28。依据 [DECISIONS.md](DECISIONS.md)。D22已恢复cms-smk/glm-5.3-flash核对，D21临时DGX与CMS证书故障记录保留。v2 发布于 `codex/ciw-v2-trunk`；旧 main 保留，历史 archive 标签尚未经证实存在。

## 1. 用户与场景

**用户**：康哲医学部医学经理，在工作台的项目里工作。首个项目是 MG-K10 CRSwNP III 期。

**主场景**：立项或写方案前，对一个适应症做一次性深度竞品调研。

**次场景**：临时查一个数值，例如“度普利尤单抗 SINUS-52 第 24 周 NPS 较安慰剂差多少”。

**交付**：只在工作台里展示 HTML 报告。同一份 release 同时喂给工作台读模型和设计 studio 的竞品候选池。

一份调研要回答四个问题：

| 问题 | 门户 |
|---|---|
| 谁在做、做到哪一步（全球 / 中国，阶段、状态、权益方、时间线） | A 竞品全景 |
| 结果多好（主要终点、关键次要终点、组间差与 CI、安全概况） | B 临床结果 |
| 怎么设计的（人群、对照、剂量频次、背景治疗、终点与时点、样本量、救援） | C 设计先例 |
| 本品放在哪里（MG-K10 与竞品同框） | A/B/C 统一高亮本品 |

## 2. 范围

### v1 做

- 工作台自助入口：填写适应症、可选研究问题并选A/B/C；自动生成检索/索引YAML、获取来源，优先深入生成所选报告（D20）；其他类型按需复用已取得原件和已核对事实继续生成。A核对药物属性，B补充临床论文，C先完成登记设计分析；B/C不等待A。只有完成的门户有阅读入口，补生成期间与失败后原有报告仍可读。高级用户仍可提交已核实YAML。任务按身份隔离；重复提交不重复启动，离页/接口重启保留执行和已取资料，失败复用缓存继续。
- 已完成的类型可“重建当前报告”：复用现有资料和缓存，按当前规则重建，不冒充重新核查动态来源。操作绑定所见任务次数，重复送达不多启作业；新版本提交前保持旧报告可读，提交后阅读器装载新版本。首次旧自动计划缺少的中文搜索同义词可由同一DeepSeek/GLM补齐并按内容缓存；不修改来源匹配词、药名、科学身份或比较资格，不对人工配置额外调用模型。
- 网页首次发现的登记药物先保留“创新属性未判定”，未核实中文名/企业/靶点留空；来源候选不得冒充已确认创新竞品宇宙。中国来源沿用真实浏览器采集收件箱，未采集在来源覆盖中如实记录。
- 一个适应症 YAML 驱动整条流水线：检索 → 获取 → 抽取 → 归一 → 核对 → 分析 → release → 渲染。
- 来源：
  - ClinicalTrials.gov v2（检索、方案、结果，确定性抽取）；
  - Europe PMC / PubMed（按 NCT 关联的论文）；
  - CDE 药物临床试验登记与信息公示平台；
  - NMPA 药品批准信息；同一许可号的动态记录若内容变化，另存观察版本并保留旧原件/旧release；当前投影使用有效观察时间最近的完整记录，同一时点内容冲突不按文件顺序择一。相同内容本次查询回执与解析复用分别保留。
  - 药企官网公告；
  - 微信公众号权威账号（丁香园 Insight、医药魔方 Info）。
- 关闭新的模型调用不取消已有核对事实：按当前原件、任务（内容／schema／指令）及真实核对者原响应复用已核公司、公众号和论文条目，重新校验当前引文及研究／产品绑定；不复制旧HTML或整份release，不伪造新模型回执。无匹配记录、冲突、仅主抽取或未核条目继续待核。部分条目不能复用时，其他有效条目保留，来源覆盖如实标记部分完成。当前待核条目只按原来源/任务/Schema/身份及实际缓存答复恢复，状态仍为待核；引文、身份、事件动作或日期不成立时只进复核清单，不在报告中显示成里程碑，原始候选不删除。
- 异构模型交叉核对：非结构化来源由DeepSeek主抽取，cms-smk/glm-5.3-flash（D22恢复路线）读取完整原文和候选核对、纠错与补漏；通过确定性来源校验记verified，剩余进入“待核”。核对者可见候选，不宣称独立盲抽取，不再调用Qwen或第三模型仲裁。确定性校验失败时仅向同一GLM回送错误条目纠正一次；正常条目不重跑，超次或仍失败保留待核，修复阶段不接受新增身份。主抽取答复为空或JSON结构无效时，仅向原主模型请求一次格式恢复，再由原核对者读取来源核对；原错误答复和实际调用均保留，网络失败不走格式恢复，不能把格式失败当成来源没有信息。
- 模型传输形状兼容：除标准`{items:[...]}`外，只兼容字段集合完全属于指定模型、且整条通过完整Schema的单个数据对象，按一条解包。原始答复、缓存键、模型身份和来源回执保持不变；后续科学校验、冲突裁决及独立来源绑定全部执行。不完整对象、未知包装、多个JSON文档及错误items类型仍按失败处理，禁止猜字段或补事实。
- 来源指标索引遇到真实回执标明输出额度耗尽时，只对失败批做一次二分恢复；子批不递归拆分，成功指标不重跑，原失败回执保留。量表标识与测量数值分开校验，英文文字阈值保留严格/含等号的区别；不能为收口待核而省掉阈值或放行不同标识。
- A/B/C 三个中文 HTML 门户：桌面宽屏，ECharts 图 + 同查询表 + 来源链接；在工作台“证据调研与方案设计”里打开。
- 工作台适配器 `ciw_release`：把 release 映射为工作台现有的产品/试验设计/结果读模型。临床结果包括单组原值、已投影的组间比较及其他来源统计量；没有组间差值不能使单组结果消失。保留原值、原单位、N、统计形式、时间和来源状态；同组多个来源分析有不同且稳定的候选身份，重复引用同一记录不重复计数。未知保持未知，未生成门户不提供阅读链接。

### v1 不做

PPT/Excel/PDF 导出、离线分享、门户内编辑事实、个人视图配置、定时监测、历史截止日回放、移动端、Skill 安装包与多宿主、药智、排名或综合评分、Meta/NMA。

## 3. 科学合同（硬规则，均有测试）

1. **缺失不是 0。** 登记未报告的数值记为未报告；只有来源明确写 0 才是 0。0/0 不计算比例。
2. **统计对象分开。**
   - 人数（n/N）、比例、均值/LS 均值、中位数、事件次数、调整估计各自建模。
   - 比例只能来自人数 n/N，或来源明确报告的百分比。
   - “percent change” 是连续变量，不是比例。
   - 通用统计形式名显示“比例”，百分号只来自具体原单位；原0–1 proportion不自动加百分号或乘100。
   - 不同物理单位分别成图，原单位不变；通用文字单位仅规范大小写与空白，不把 g/L 和 g/dL 混为一轴。
3. **组别角色只来自显式信息。**
   - 依据：CT.gov `armGroups.type`（实验/活性对照/安慰剂/空白），结果组与臂的显式匹配。
   - 登记结果匹配不上时显示“组别未匹配”，不猜。D18允许论文按原文明示分组独立呈现、关联研究；无独立登记臂时保留arm_id为空，不猜对应、不改登记，不把汇总拆到剂量组。
   - 产品身份可来自登记臂明确写出的、配置已核实的制剂代号；仅干预通用成分字段未写代号不丢研究。未知角色保持未知，标题或申办方不替代臂身份，联合名称不取首个产品。
   - 登记类型为实验/活性对照/空白，但该臂全部明确干预仅为Placebo等时保留原类型与名称，当前角色记未知并保留逐臂冲突定位；不直接猜改为安慰剂对照。真正活性药联合安慰剂不按此规则处理；论文自己的明确分组仍按D18保留。
4. **组间比较只有两种来源。**
   - 来源报告的 analyses：组间差、CI、p 值、方法。
   - 同一试验内与明确安慰剂臂的差值，标“计算值”，不带 CI。
   - 不同试验之间并列展示，不计算差值。
   - 论文明确报告的调整差值、方向、P值与比较符直接保留，不由舍入后的组均值重算；未报告组数值时不填0，阈值P不能写成确定等值P。
5. **时间点保留原文。** 只做 day↔week 精确换算，月不折算成周。并列图按时间点分面。
   基线class（含“分项名称 - Baseline”）保留在全部观测，并明确标为基线；不得落到outcome整体“至148周”等末次范围，也不进入随访疗效横比或治疗历时曲线。原文整体时间范围仍可查。
   “Up to/through/until”及明确0–N区间保留为观察范围，不作为第N周单访视；原class写明的具体访视优先于整体范围。未知人群或定义限定在原来源测量内，不以两处空白当作跨研究同一分析条件。
6. **域默认 other。** 疗效概念来自适应症概念字典及真实来源标题/定义经既有两角色核对的运行时索引；检索前字面词组不等于实际覆盖。明确临床组织学阈值不因计数字样直接归PD。来源索引保留精确标题与定义、来源定位及核对记录，不更改数值或比较资格；PK/PD/免疫原性/安全仍独立，未确认保留原域与问题记录。
7. **创新药范围。** 竞品宇宙只纳入创新药（新分子、新靶点、改良新药按配置）；传统药只作为背景、对照或救援出现。宇宙中的每个产品都有纳入理由，未归类的干预单列，不静默丢弃。
8. **每个数字可追溯。** 门户里每个数字都带来源链接、定位（JSON路径、原始XML的XPath或原文片段）和核对标签：
   - 登记结构化
   - 模型核对（verified；旧双模型一致/仲裁只读兼容）
   - 待核
9. **适应症保留否定原意。** 明确“不伴鼻息肉/without nasal polyps”的研究不因出现“鼻息肉”字样进入CRSwNP核心集合；“伴或不伴”混合队列仍保留原始人群。差异规则只放在适应症YAML。
10. **事件日期与发稿日分开。** 批准/受理日期须由同段原文明确支持；只有宣布“已经获批”时日期留空。结果回顾不登记为新顶线披露，各辖区分别保留。 产品原名与适应症必须在所选连续引文中出现，不能从片段外借先行词；细节摘要另保留该引文内的连续支持片段（原样细节本身已是片段时直接校验）。试验启动事件须有首例已经入组的证据，计划入组或仅“III期启动”不能替代。只有计划或否定的递交/受理不作已发生事件；明确患者关系从句须在细节原文片段中完整保留，不能把实际适用范围扩大。面向目标适应症的许可投影可保留来源明示子范围，不声称来源只批准该适应症。
11. **保留来源冲突。** 登记臂名/角色与干预关联矛盾时保留原件和问题记录；论文按明确药名、登记臂名及角色绑定，不按数组顺序翻转。摘要未给分析N时留空。
12. **登记与研究地域分开。** 中国登记不自动证明全研究仅在中国开展；没有国家清单时不生成国家数量。

## 4. 门户要求

**A 竞品全景**
- 首屏：产品 × 最高阶段（全球 / 中国）矩阵，本品高亮。
- 产品表：通用名/代号、靶点/机制、剂型/途径、研发企业与中国权益方、全球与中国状态、关键试验。
- 时间线：首个受试者入组、主要完成、结果公布、获批。

**B 临床结果**
- 桌面存在历时数据时，当前时点比较图与历时曲线并排利用首屏；原始表保持全宽并可展开，无历时数据不留空图栏。字号不因压密度而缩小；点表及提示保留各源原始单位。
- 首屏按简短中文临床问题主题组织，来源指标ID保持独立。已核对来源之间的主题归组复用现有DeepSeek/GLM，每个成员有自己的原文引文；不同量表、总体/子评分、应答/恶化不混同，失败或未分组的原始问题继续可达，不因目录整理重抽已采用指标。
- 同一问题保留全部研究，时间点、统计形式、单位、定义/分析人群等保留为分析分面；具备相同原有数值条件的研究共用ECharts与同查询数值表。全研究对照表保留各分面的组值、原始统计比较和来源，支持逐行看图与来源详情。Global/US定义、持续缓解、无激素、条件应答人群等不能因粗主题相同就共轴。表中列出 N、统计形式、分析人群、来源，组间比较保留95% CI。
- 共同测量轴由既有DeepSeek/GLM核对来源上下文，按唯一测量定义复用，不逐观察对签发。只有量表/组成、统计形式、明确分析集、基线、治疗期和估计策略有来源支持才进入同图；不同研究目标人群用原文支持的简短分层标签分别保留，N、原始单位、组别及来源不合并。时间、单位维度、阈值和分析策略冲突继续分面；未知不补齐。图与同查询表、历时曲线共享这一投影。
- 原文已报告但尚不能按臂角色或方向投影的统计，仍在当前问题内用原始统计量图表呈现，不猜方向或补组均值。明确共享合并分析只显示一次并保留全部来源；不得仅凭相同数值归并。
- 安全概况：任何不良事件、严重不良事件、因 AE 停药、死亡，以及按组的高频 AE。
- 多时间点数据用带时点标注的ECharts折线图，并配可展开的逐时点表；跟随当前临床问题，切换后不得残留其他问题的曲线。曲线与表的药物、期别、研究、时间、数值和来源一致。
- 全部观测提供按药物/研究/来源组名/原文/分析人群检索及类别筛选、分页与组值下钻；PK、PD、免疫原性、other及未进疗效图的记录仍可查。分页显示范围和总数，保留0、缺失、限定原值及来源统计比较。
- 观测与问题检索保留数字边界：Week 1不命中Week 12/16或1.5；忽略来源括号/连字符等排版差异，原文、时间字段与比较符均保留，检索不改变科学分面。
- 已明确单时点的问题按实际切片筛选；原始标题提到其他周次不会使不同切片混入。数值行与全部观测行均可鼠标/键盘进入当前来源详情，折叠区外壳不拦截行操作；行内链接、按钮与展开控件各自响应。原始长终点与分析人群原位展开，数值、N、单位与研究身份默认可见。
- Europe PMC查询失败时补查官方PubMed ESearch/EFetch；检索命中不直接采纳，摘要必须明确出现登记号。原始XML入CAS并以XPath定位，仍只用D22两角色抽取核对；上游失败与PubMed补查分别记录，失败不写成无论文。已成功查询只复用，显式离线不发请求。
- 补充论文结果须在摘要中明确关联登记号，并按D18关联研究、保留论文明确分组或已明确绑定的登记臂；主要结果、总体与亚组分别保留。论文链接与真实核对标签随数值显示，不覆盖登记结果。

**C 设计先例**
- 中文检索同时使用确有匹配原文的主题名称与配置别名；检索别名不改变药名、指标含义或数值比较资格。入排主题按指标检索实际阈值，不预猜几个阈值后漏掉其余研究。摘录显示命中句段并保留上下文及全文；给药、背景治疗、救援和随访分别索引。
- 多疾病登记继续作为相关设计先例，样本量标明全研究范围，年龄标为“登记年龄”并保留各疾病入排原文；登记年龄字段不证明每个队列适用相同年龄。不得把全研究N或其他疾病队列结果当作本次适应症人数。按结果中的组判断人群，来源比较必须全部落在已确定的组；其他及未分明的原始观测保留原分组图、表和来源，不硬猜缩写。安全性同样保留来源范围。多个病名并列不自动证明多个互斥队列。
- 试验 × 设计维度矩阵，可搜索、筛选。维度包括：期别、设计/盲法、随机比例、关键入选（NPS/NCS 阈值、既往手术/全身激素、合并哮喘）、组别/剂量/频次、背景治疗、治疗期、主要终点与时点、关键次要终点、样本量、地区。
- 单试验详情：完整入排、终点定义及阈值、登记条件、逐组给药和研究描述可展开；不把末次给药后的避孕期、给药频率或终点评估周数写成治疗暴露时长。不能完整结构化的背景方案保留原文，不以空值冒充没有背景治疗。
- 主要终点构成与样本量图配同查询完整数据表；未映射的主要终点列入“其他原文终点”，没有登记主要终点的单列，不能仅展示已分类的小部分。分类可筛选回原始研究。表内保留真实0以及未绘制记录的缺失字段。复杂长时间窗在矩阵原位展开，研究详情保留完整原文。
- 主要终点构成及样本量图跟随矩阵同一筛选；单一类别或单个可绘研究用紧凑事实区，多个观察保留ECharts与完整表，筛选清空和恢复可逆。真实0、未知及未绘制记录保留在同查询表。日期显示原登记开始日期，不将计划或未区分类型的start字段宣称为首例入组；图中提示先给药物、期别与研究身份，再给原日期、N与样本量类型。
- 临床主题由适应症YAML配置，索引研究摘要、设计描述、入排、组别与终点描述中的逐字条款。矩阵优先显示，条款原位展开，阈值用字重、深色和下划线强调；原文保持完整，关键词命中不自动等于数值归属或入组资格判断。
- 矩阵研究行支持键盘进入详情，Esc返回实际触发位置。
- 同一C门户提供“主题横比”和“综合设计”。主题横比按研究列出用户点选主题的实际条款，默认选择最多四个入排主题，全部主题与研究始终可达；单元格直接呈现入选/排除、阈值和决定适用性的父条件，不以“几个主题”链接代替。长原文就地展开，原图表与全表继续采用同一查询；纯文字条件不用假数值图替代。
- 简短明确条款保留原文；长逻辑条件、叙述性方案及多疾病语境复用既有两角色整理，逐条绑定原字段和连续引文。推荐用药、一般疾病背景、泛称长期随访不作为本试验给药/访视安排。失败保留原资料和旧current；补生成A/B只复用已取得的C整理与中文检索词，不为呈现变化重抽资料。
- 列表父句与子句各有原文定位，主层保留适用条件，完整上下文保留其他分支；不通过删除父句或拼接原文解决引文问题。重复或无法唯一确定的关系继续保留原始资料，不推断。原文同句包含审核依据、前提或依赖条件时，主层不得在依赖连接词前截断；完整定义、AND/OR替代条件及治疗后缓解／复发前提同样保留；不能以单一阈值代替定义。完整条件本已包含指标时，以一个完整要点呈现，保留所有适用前提；正文已逐字包含的条件／队列不再重复翻译，原字段不变。
- 来源含列表父句及分支定义时，完整分支定义与AND/OR留在条款正文，上位列表父句单独保留；不能用定义挤掉父句。原文已表达的既往检查史不得译成签署ICF之后的未来要求。
- 长英文条款的主层呈现为简洁中文医学要点，适用条件、队列和时点同层可见，原文与完整上下文原位展开。要点在来源核对层由既有DeepSeek/GLM整理，保留全部数值、比较符、单位、否定及AND/OR逻辑；未核对不伪装成中文事实。纯指标阈值允许直接用完整科学记号；英文数字、明确频次、并列时点和带括号的原单位别名可作等价表示，数值、严格/含等比较、日周月年及绑定原字段范围仍须一致。只新增内容键阅读投影，不使已核条款、原件或原始数值失效；渲染层不翻译、不猜中文药名。主层不重复来源元数据，不以长英文或防御性教学挤占横比空间。

## 5. v1 验收

1. **工程**
   - 在干净 clone 上 `uv sync && uv run pytest` 全绿。
   - `uv run ciw run indications/crswnp.yaml` 一条命令产出 release 和三个门户，可重复运行。
2. **产品**
   - 在工作台 MG-K10 CRSwNP 项目里打开 A/B/C，能回答第 1 节的四个问题。
   - 从 B 任一数字出发，两次点击内能到达来源。
3. **科学**
   - 随机抽 30 个数字对照原件，0 错误。
   - 已上市与 III 期 CRSwNP 生物制剂（以 FDA/EMA/NMPA 获批信息和 CT.gov III 期检索为准）全部出现在 A。
4. **泛化**
   - 只新增 `indications/pnh.yaml`，不改 Python，就能产出 PNH 的 A/B/C。

C的数值入排主题只查入排章节，终点定义主题只查原始终点；实际给药期限与随访/避孕分开，保留条件性再治疗的原意、完整原文及上下文。不能把原文未定义的缓解阈值补成定义。已有报告阅读时收起新建表单，长研究问题可展开，保留草稿和新建入口；视觉验收仍须实际宽屏页面，不能只靠组件测试。

C条款的格式兼容只处理父句前的空白或无序项目符号，医学内容逐字保留，来源定位对应真实原文。阅读引用可忽略行首ASCII缩进，但不得改写已保存引用；明确人数的英文数词与阿拉伯数字、相同有序编号的行首/行内布局可归一，HTML注释不作为测量值或比较符。规则修复后可重新检查原来完整的核对者回答，须有同一原件、任务和真实B响应证明；不能用主抽取回答或缺失证明代替核对，也不为了补一个项目符号重新请求来源模型。

同一临床问题的默认历时图须对应当前分析分面的原始结果，或已有核对的共同测量轴；不能仅因同一主题便默选另一研究。其他相关研究继续可主动点选，图与表同步，不新推断共轴。图卡按真实容器宽重排标签、绘图区与刻度，保持16px，并在容器变化后恢复合理布局。
已定位列表的中文阅读保留所提供上下文中的备选分支，原来源条款不改；同句完整条件已进入正文时不再重复条件字段。明确的既往检查及筛选诊断窗口需表达清楚相对ICF的前后方向，不把“的5年内”当成已保真，未来检查不能强制改为既往。

来源中明确声明的有序列表编号可以在中文要点中移至行内，但编号序列必须与来源对应；它们不作为临床测量计数，真实剂量、阈值及单位仍逐项校验。嵌入工作台时使用宿主的一套报告导航，保留截止日期；科学数值、P值和研究标识不拆成逐字多行，完整表格可在表内横向查看。

混合疾病研究的设计条款可附原字段明确疾病标题及其逐字位置，主层展示短人群标签；标题须来自当前原文，不能凭病名共现或别名猜队列。跨多个疾病章节的完整条款不得归为单一队列，全研究样本量不分摊。同源标题投影不进入科学原子身份，不使已核中文及模型缓存失效；原件改变仍有新的内容地址source_id，不能引用旧版本中文。跨来源版本不附新标题到旧条款。

数值、单位和时间校验不等于完整语义证明；中文条款继续由既有两家族核对和来源检查保证条件及复合逻辑。原文明确的活检前提不能因译文保留年龄等数值而被省略。以上为内部处理规则，报告不增加防御性教学内容。

## 桌面交互约定

图中药物、期别、研究名称先于登记号；点估计按其真实研究行定位，置信区间单独保留，区间缺失不隐藏点估计。图例保留组别与研究身份。散点悬停显示该点的真实研究与样本量类型。Esc先关闭当前展开原文并回到摘要，再关闭外层详情；正文与操作字号不低于16px。

设计条款的入选／排除角色取实际分节标题，正文中提到“inclusion/exclusion criteria”不改变角色；重复条款用连续引文限定其原文出现位置。数字父句编号只有在原件唯一位置明确存在时才可用于匹配，不能把任意临床数值当装饰。明确同句的组别 receiving 或参与者 will receive 属于可核对的实际操作形式，推荐语不能借相邻操作句充当本方案。

条款核对失败反馈定位到具体 clauses 序号与真实字段ID；错误字段同时给出该主题可用原始字段。继续使用同一GLM的一次纠错与按内容缓存，已接受条款不重做，不增加第三模型、签发或审批。
