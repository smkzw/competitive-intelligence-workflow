# Task 2.2 验收结论

日期：2026-08-11

结论：**接受稳定实体身份、冲突保留与完整竞品宇宙，允许进入 Task 2.3。**

产品、药物项目、方案、企业、试验、队列与组别使用带实体类型的稳定内部身份；名称、别名、NCT 与 CTR 不得直接充当身份依据，更换登记号不改变既有内部身份。别名及外部标识符冲突保留全部候选与证据，不自动合并；同一内部身份内容不一致时拒绝静默覆盖。

竞品宇宙要求候选实体与适格记录严格一一对应：重复实体、重复适格、漏评实体和未知引用均拒绝闭合；任一待审查项阻止闭合；150 个适格实体完整保留，不做 Top-N、排序切片或其它静默截断。

首次独立验收发现重复适格会重复计数、漏评实体会被静默丢弃两项 P1；修复后原 session `019ff143-b659-7000-ad51-77680e15f60d` 复核为 PASS，P0=0、P1=0、P2=0，无 fallback。Task 2.2 组合套件 10 项、全库 147 项、Ruff、strict mypy、包校验与差异检查均由构建者和验收者分别通过。

证据说明：待审查阻断节点在新增测试时首次即通过，属于既有行为的回归覆盖，不虚构 RED；独立报告中“该节点有真实 RED”的一句概括不准确，以 `red.txt` 的逐项记录为准。当前结论不接受 Task 2.3 之后的来源规划、连接器、证据声明链或报告生成。
