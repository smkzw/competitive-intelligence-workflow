# Task 6.4 验收结论

## Verdict

通过。

## Boundary

本结论只接受 B 类疗效—安全性气泡图和比较矩阵的强类型数据、计算、状态与交互合同；不创建或放行物理页面，不代表 HTML、PDF、PPT 或浏览器视觉验收完成。

## 决定性结论

- 每个气泡只对应一个产品的一项明确试验和治疗组；横轴只使用同试验、同疗效语境的治疗—对照信号，纵轴只保存治疗组原始安全性发生率。
- 倒序纵轴不是安全性得分；气泡面积而非半径与明确治疗组样本量成正比。
- 宽泛样本量键、安全性事件分母和缺失值不会被借用或伪装为具体 N。
- 多口径尚未选定与真实未报告分开；五类矩阵状态、原始事实、中文原因和不可绘制行均保留。
- 切换安全性家族不会继承旧家族筛选；不同疗效效应形式不相减且拥有唯一比较行标识。
- 图、表、提示、证据和 URL 同源同步，可逆重置；不生成排名、综合分数或跨试验合并结论。
