# 视觉与交付包验收

## 输入合同

接收实际渲染产物、康哲设计合同、页面与格式验收标准、当前运行清单和内容锚点。

## 输出合同

输出逐格式验收记录、真实渲染证据、缺陷定位和接受或否决结论。

## 禁止行为

不得仅凭源码、文件存在或“没有溢出”判定通过；不得以伪截图或旧运行产物冒充当前验收。

## 失败与恢复

缺陷必须定位到报告、页面、组件和当前文件摘要；修复后重新打开真实产物并复测受影响路径和相邻路径。
