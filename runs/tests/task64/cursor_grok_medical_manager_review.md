## 阻断问题

### 1. 产品级样本量会串到该产品的每一项试验

`_lookup_sample_size` 在找不到（产品, 试验, 组别）后，会回落到 `product_id`。反例：同一产品 NCT00000001 与 NCT00000002，映射仅为 `{"product-a": 999}`，**两项试验的治疗组 N 都变成 999，并生成两个气泡**。立项会上这会被读成“两项研究样本量相同、证据权重相当”。气泡面积是医学经理用来判断把握度的视觉通道，这里已经在做跨试验的 N 借用。

要求：样本量只能来自该试验该治疗组；按产品、按试验号无组别的键不得画气泡，应「待核实」。

### 2. 「有数但语境未选定」被写成「未报告」，文案还像 TEAE

同一试验同时有「治疗16周」和「整个研究期」总体 TEAE 时，不指定窗口则两套发生率都丢掉，状态为「未报告」，理由是「治疗组原始治疗期间不良事件发生率未报告」。CSR 里明明有数，经理会理解成「这份结果没报 TEAE」。

从 TEAE 切到 SAE、只改维度和事件、继承默认窗「整个研究期」时，SAE（窗为「治疗期间」、3%）也对不上，仍是「未报告」，理由仍写「治疗期间不良事件」。补上 SAE 自己的时间窗后，纵轴才正确为 3%，图/表/URL 才同源。

立项读图时，「未报告」和「待核实/请选择时间窗」不是同一句话。前者会进缺口清单，后者是筛选问题。当前合同把筛选缺口说成证据缺口，且安全性维度切换后文案不换口。

## 非阻断改进

- 无样本量映射时，气泡 N 用安全性分母（反例为 87）。疗效常在全分析集，安全性在安全性分析集。差几个例可以接受，但必须在点上标明「安全性分析集例数」，不能暗示这是 FAS/ITT 的 N。
- 分组键不含效应量形式。治疗组标成风险差、对照标成比值比，但都是应答率 60% 对 30% 时，仍算「可比」、信号 30。若效应量只是误填尚可；若两组本就不是同一估计量，应「不兼容」。
- 默认安全性窗按文本排序，本例默认落到「整个研究期」而不是「治疗16周」。默认必须来自锁定快照的预先指定窗，不能靠中文排序。
- 对照臂安全性缺失仍可画点（纵轴只要治疗组）。与「纵轴=治疗组原始发生率」一致，但完整表应标明对照 TEAE「本次未用于纵轴」，避免被当成头对头安全性。
- 官方测试未覆盖：产品级 N 回落、多窗歧义、SAE 继承 TEAE 窗。19 项通过不能代表这些临床路径。

## 医学经理读图结论

可以把这套类型当作**试验内二维观察草稿**：横轴是同一试验、同一终点桶的治疗—对照方向校正差，纵轴是该治疗组原始发生率，面积本应反映该组 N，缺失不进 (0,0)。

**还不能进竞品会。** 同一产品两项试验可能被画成一样大的气泡；多窗或切 SAE 时，有数会被写成没报。这不是画工问题，是会把“这项研究没数据”和“这项研究更大”读进错误的立项判断。

补救后再审的最低门槛：样本量不得按产品回落；多窗/维度切换未命中时用「待核实」并写清事件与时间窗；气泡 N 标明分析集；并做一次真实页面的倒序轴与面积目视，不能再用测试绿灯代替。
