## 首轮阻断：已关闭

### 1. 样本量不再按产品/试验/组别串借

`_lookup_sample_size` 现在只认 `(产品, 试验, 组别)` 或疗效事实行 ID；`(产品, 试验)` 下面必须再点到治疗组。产品键、试验号、孤立 `arm-treatment`、无组别的 `(产品, 试验)` 一律不画气泡，状态「待核实」，N 为缺。

实测：同一产品 NCT00000001 / NCT00000002，映射 `{"product-a": 999}` 时，两项试验 N 均为空、0 个气泡。精确三元组 111、嵌套 `{"arm-treatment": 123}`、事实行 ID 150 仍生效。官方参数化测试覆盖了宽键。

立项读图含义：不能再把两项研究画成一样大的气泡。

### 2. 「有数但没选定」不再叫「未报告」

两套总体 TEAE（治疗16周 18%、整个研究期 35%）时，默认时间窗为 `None`，状态「待核实」，理由是「存在多个安全性统计口径，请先选择事件、时间窗、分析人群和分母口径」。选「治疗16周」后纵轴 18%，图/表/提示/证据/URL 同一行，重置回默认。

把时间窗硬设成「整个研究期」而库里只有「治疗期间」时，状态「待核实」，理由是「已有该安全性维度数据……请调整筛选条件」，不再说没报 TEAE。

从唯一 TEAE 窗「整个研究期」切到 SAE、窗对不上时，同样是「待核实 / 请调整筛选」，不是「未报告」。补全 SAE 时间窗后纵轴 3%，表面同源。

真的原文未报告，仍是「未报告」，纵轴不是 0。

默认安全性家族固定为 TEAE。快照里只有 SAE 时，不会偷偷改成 SAE 去画点。

### 效应形式不一致不再相减

分组键已含 `effect_measure`。治疗组风险差、对照比值比时，拆成两行，各缺一臂，「未报告」，横轴 `None`。人为塞进同一行时为「不兼容」，原值 60 和 30 仍在。

## 剩余问题

**P0：** 无（相对首轮阻断）。视觉未做，不能用测试绿灯代替目视。

**P1**

1. 治疗组与对照 `effect_measure` 不同时，比较行 ID 仍不含效应形式，`build_bubble_matrix` 会因「比较行标识不得重复」直接失败。不会再偷偷相减，但会把整张图打掉。真实 CSR 两臂一般同口径；误标时应变成「不兼容」行，而不是崩溃。
2. 从 TEAE 切到 SAE 时，会带上 TEAE 的事件定义/时间窗。有 SAE 也会先停在「请调整筛选」。这比「没报」正确，但立项会上会显得「切不过去」。切维度时应丢掉上一维度的事件/窗，而不是继承后判失败。
3. 无样本量映射时，气泡 N 仍用安全性分母（实测 87）。差几个例可接受，点上必须写清「安全性分析集例数」，不能让人当成 FAS/ITT。

**P2**

- 对照臂安全性仍可不画进纵轴（符合「纵轴=治疗组原始发生率」），完整表仍宜标明「对照 TEAE 本次未用于纵轴」。
- 唯一总体 TEAE 时，默认窗仍取该条事实的时间窗，不再靠中文排序在多窗里猜；多窗则空着等选。预先指定窗若与「唯一总体 TEAE」不是同一条，仍需锁定快照显式给出。

## 医学经理判断

首轮会把立项判断带偏的两件事——**把别人的 N 画进这项试验**、**把没选窗说成没报数**——在类型层已经堵住。现在这是一张试验内二维观察草稿：横轴同一试验同一终点桶的方向校正差，纵轴该治疗组原始发生率，面积只认该试验该治疗组的 N。

**还不能进竞品会。** 缺一次真页面的倒序轴和面积目视；效应口径冲突时整图崩溃、切 SAE 要再点筛选、气泡 N 可能是安全性分析集，都会在会上被问住。合同层阻断可记关闭；放行进会要等视觉过目，并处理上面三条 P1。
