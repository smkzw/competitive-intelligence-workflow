## 3）缺陷清单

### D1 — 图上的 82.3 点不开数据依据，表里的 82.3 才能打开
- **路由**：首页 / 疗效（`overview.html`、`efficacy.html`）
- **宽度**：1024（1280/1440 同样：SVG `text` 可点区域约 29×20）
- **复现**：按页上「点击数值查看数据依据」去点柱顶 **82.3** → 抽屉仍空（仅标题「数据依据 / 冲突 / 历史版本 / 固定此条」）。再点表里比较值 **82.3** → 抽屉才填上。
- **观察**：图标签命中高度约 20px，低于合同 24×24。
- **级别**：P1  
- **分类**：evidence（交互与合同不一致）
- **最小修补**：柱顶数字、柱体、热图格做成 ≥24×24 的同一套点击；空抽屉不要先露系统按钮。

### D2 — 抽屉分子与表不一致，并露出后端路径
- **路由**：首页，打开 APPLY 治疗组 82.3 抽屉
- **宽度**：1024
- **复现**：表：分子 **51**、分母 **60**、比较值 **82.3**。抽屉：值 **82.3**、分母 **60**、分子 **来源未列示**；「原文定位」为 `nct04558918/efficacy/apply-treatment`、`行：apply-treatment`；另有「规范化说明」「固定此条」「原文未提供」。
- **观察**：数据依据页本应能核对图/表，这里反而缺分子、多内部字段。
- **级别**：P0  
- **分类**：evidence  
- **最小修补**：抽屉分子与表同为 51；藏内部路径/「固定此条」；空的量表/阈值不要占行。

### D3 — 受众可见英文内部状态与字段名
- **路由**：矩阵 `efficacy-safety-matrix.html`；基线 `baseline-overview.html`、`baseline-demographics.html`；产品/试验档案下半页
- **宽度**：1024–1440
- **复现**：矩阵「比较状态」= **`comparable`**（1440 仍会断成 compara / ble）。基线「统计形式」= **`sample_size` / `mean` / `proportion`**。档案页同样出现。
- **级别**：P0  
- **分类**：evidence（合同禁止后端字段名原样出现）
- **最小修补**：改为「可比较 / 样本量 / 均值 / 比例」；矩阵不要把内部 enum 印出来。

### D4 — 1024/1280 全宽表列被压成条，试验名被竖切开
- **路由**：首页、疗效、安全性、矩阵表
- **宽度**：1024 最重，1280 仍重，1440 口径列才勉强可读
- **复现**：无整页左右拖，但 12 列均分。1024 约 72px 列，口径提示把行撑到约 307px；安全表 `APPOINT-PNH` 被拆成 `APPOIN` / `T-PNH`。合同要的是核心比较列在默认视野可读，不是「页面没横滚」。
- **级别**：P1  
- **分类**：evidence + aesthetic  
- **最小修补**：身份列可收；比较值/分子分母/披露固定可读宽；口径放到行下说明或抽屉，禁止等宽 72px。

### D5 — 热图「不适用」在图上是空白格
- **路由**：`safety.html`（任何 TEAE 等）
- **宽度**：1024（三宽度结构相同）
- **复现**：APPOINT 对照在表为发生率 **不适用**、披露 **不适用**。热图该格空白，无「不适用」、无纹理。图例是治疗组橙/对照蓝，格子却是红橙连续色；色条无 0–最大刻度。
- **观察**：零值突破性溶血格子印 **0**（对）；缺失/不适用与零的差别在图上丢掉了。
- **级别**：P1  
- **分类**：evidence  
- **最小修补**：不适用格印「不适用」+非颜色编码（斜线/虚框）；色条加数值；图例与热图配色一致。

### D6 — 矩阵表口径自相矛盾
- **路由**：`efficacy-safety-matrix.html`
- **宽度**：1024–1440
- **复现**：APPLY 行：疗效位置 **80.5**（与 82.3−1.8 一致）、安全性 **54.8**、比较状态 `comparable`、口径 **未列示**、披露 **未报告**。图上只有这一颗泡。APPOINT 不打点，表说明单臂无对照——这句是对的。
- **观察**：同一行又有坐标又写「未报告」，医学经理无法判断能不能引用 80.5。
- **级别**：P1  
- **分类**：evidence  
- **最小修补**：有坐标则披露为已报告；「未列示」的组别改为「试验内治疗−对照」或「综合点、不分组」；`comparable` 改中文。

### D7 — 筛选器像后台维度浏览器

- **宽度**：1024 两列最挤

- **级别**：P1
