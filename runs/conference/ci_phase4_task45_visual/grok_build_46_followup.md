## 决策效率评价

我要核对的是：这是哪条终点、哪个时间点、哪个分析人群/分母、和另一条能不能比、有没有口径冲突。疗效页固定两条之后，对照表把这些摊开了，不用学软件。柱图一点就亮、表图能对上 5.2/7.8，这一步合格。

后面就不合格。

热图格子里能看见 8.4 / 9.6，下面表的「比较值」是空的，披露状态却写「已披露」。点空格子还能打开 8.4 的抽屉——表上没有数，点进去才有数。这种反馈会让人以为系统坏了，或以为未披露。两块几乎同色的大橙，看不出谁高谁低。

状态矩阵更糟：标题仍是「主要终点 HbA1c 较基线变化值」，纵轴把终点名写两遍，格子里却是「已完成 / 进行中」，单位还挂着 mg/dL。我第一眼会当成疗效数字，第二眼才发现是试验状态。筛选产品甲之后这块还在，等于同一页用同一标题讲两件无关的事。

基线、完成情况页没有图，也没有筛选。完成情况合同里该有的筛败/随机/完成/退出/失访都不在首屏，只剩一行「停止治疗（不良事件）」。要比较定义只能靠抽屉，还只能固定一条。中间 2400px 空白要把人滚到页脚「重点模块」才结束——对懒于操作的人，等于这页没有信息。

1280 打开抽屉后，顶栏「试验完成情况」被抽屉头挡住，点不到。1024 要先找「菜单」，首屏看不到图。网址刷新/复制在疗效筛选和基线固定上是通的，这是少数让人放心的点。

## 视觉与中文评价

浅底、橙身份条、中文主导航（医学结果 / 基线与人群 / 试验完成情况）和「数据依据 / 固定此条 / 不适用 / 原文未提供 / 已报告值」读得懂，没有把后端状态名直接甩给用户。筛选芯片「整份报告 · 产品：产品甲」清楚。完成情况「互斥但未穷尽」「按规范原因族对齐后比较」是医学经理语言。

问题在信息密度和语义，不在配色：

- 1280 搜索框只露出「搜索页面或关键词..」，像半截控件。
- 特应性皮炎报告里主图是 HbA1c，单位 mg/dL；原文还写 `-5.2 mg/dL`。这不是糖化血红蛋白的惯用单位，也不是皮炎终点。夹具可以假，但不能让人以为系统会把单位配错。
- 热图、状态矩阵几乎是两块实心橙，图例仍写「治疗组 / 对照组」，状态色没有独立说明。
- 1024 抽屉切掉左侧表列，完成情况导语「兼容规则。」被裁。菜单展开后和抽屉叠在一起，首屏又挤又乱。
- 「重点模块」只有编号和「主要终点 / 安全性事件」，点不进去，像未做完的目录。

缺失语义：三页抽屉都能看到「不适用」「原文未提供」。**没有出现「尚未公开」或「技术暂不可用」**。不能证明这两类状态在真实界面上能被医学经理一眼分清。

## 结论

**REVISE**

不是「页面能开、流程能跑」。疗效页的固定对照、筛选收窄、刷新/后退是可用的；**基线抽屉把 EASI 写成年龄，热图表空值，状态矩阵把完成状态当成疗效比较值**——这三件事任何一件都会让医学经理停手，不拿来开会。P0 不修，不能按 Task 4.5 交互合同验收。

最高影响缺陷：基线当前卡片后半段字段归属错误。若把错误归属视为证据门槛失败，基线页已接近 BLOCK；整站因疗效对照仍可操作，本次判 REVISE。
