## 数据一致性问题
- 次要终点…治疗组 / 对照组 在热图 / chart-table 中 显示 比较值=空白 但 披露状态=已披露；点击该行 drawer 显示 8.4/9.6 与 104 分母 — 表格渲染 bug
- 状态矩阵的 比较值 列填了“已完成 / 进行中”状态字符串，单位列写 mg/dL（单位与内容不匹配）
- HbA1c 单位写成 mg/dL，医学上正确单位是 % 或 mmol/mol — 临床准确性疑点
- “匹配 N 项结果”仅 efficacy 页面有，baseline / disposition 没有
- 4 种披露语义只覆盖 已披露 + 不适用；未公开 / 技术暂不可用 未在 fixture 出现
