## 仍可复现的 P1 问题

### P1-1. 筛选后越界固定项被静默移除，无中文说明

- **复现步骤**：固定产品甲 EASI + 产品丙 疾病活动度 → 筛选"产品乙"→ 固定对照表格从产品丙 + 产品甲 变为仅剩产品甲 1 列，产品丙被静默移除。
- **期望行为**：筛选移除越界固定项时应有中文说明，如"以下固定项因不符合当前筛选条件已暂时移除：产品丙 · 次要终点疾病活动度评分较基线变化值"。
- **实际行为**：仅显示通用提示"当前选择过多，请保存为本地视图"和"完整记录仍列于下方表格，便于核对来源与口径"，未明确告知用户哪条固定项被移除。
- **影响**：医学经理筛选后会以为之前固定的对照数据"丢失"，产生恐慌。
- **证据**：截图 `02`（2 列）→ `08`（只剩 1 列）。

### P1-2. 1024×768 下数据依据抽屉仍然遮挡主内容区点击

- **复现步骤**：1024×768 下打开数据依据面板 → 直接点击左侧状态矩阵（`#kz-chart-3`）或柱图（`#kz-chart-1`）。
- **实际行为**：Playwright 连续报 `aside subtree intercepts pointer events`，点击被抽屉拦截，无法连续操作图表。
- **影响**：窄屏用户必须多一步关闭抽屉才能继续浏览图表，打断操作流。医学经理若不会按 Esc，会以为图表坏了。
- **证据**：操作日志中的 TimeoutError（截图 06 后连续 3 次复现）。

## P2 问题

### P2-1. 不同指标/组别固定并列时无口径差异提示

- **复现步骤**：固定"产品甲 · 主要终点 EASI评分较基线变化值"与"产品丙 · 次要终点疾病活动度评分较基线变化值"→ 查看固定对照表格。
- **实际行为**：两列正常并列，字段逐行对比，但无任何提示说明"主要终点"与"次要终点"、"EASI"与"疾病活动度评分"属于不同量表/口径。
- **影响**：医学经理在快速核对时可能忽略指标定义差异，直接对比数值，导致误判。
- **证据**：截图 02、JS 提取。

### P2-2. 柱图具体柱子点击在自动化测试中仍难以触发

- **复现步骤**：通过 Playwright 标准 DOM click 点击 bar chart 容器或 SVG path → URL 无变化；仅通过 ECharts `instance.trigger('click')` 才能触发。
- **备注**：此问题可能是自动化测试的事件模拟限制，真实浏览器中用户直接点击 SVG 柱子可能正常。但由于容器点击也无法触发，需确认 ECharts 点击热区是否足够大（例如图例、标题、空白区域是否也能触发）。
- **证据**：JS 测试记录。

## 结论

**REVISE**

理由：
- P1-1（筛选后固定项静默移除无中文说明）仍然违反"筛选后不错误保留或扩大范围"的成功标准，对医学经理的核心使用场景造成实质性误导。虽然表格作为"完整记录"保留，但固定对照面板是用户专门用于横向核对的工具，其内容被静默削减必须明确告知。
- P1-2（窄屏抽屉遮挡主内容点击）在 1024×768 下仍然阻断连续图表操作，上一轮已报告，本轮未修复。

上述两项在真实工作流中足以让医学经理产生"数据丢失"或"系统不稳定"的误判。建议修复后再次复测。
