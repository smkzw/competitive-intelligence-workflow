#### 状态 2：筛选面板展开 + 同维度单选（1280px）

#### 状态 3：1024px 响应式布局
**证据**：filter-1024.png 显示导航已折叠为右上角"菜单"按钮，搜索框隐藏。筛选栏中"已选 1 项"摘要换行到第二行（`flex-wrap: wrap` 生效）。筛选面板完整显示无溢出。表格 3 列仍可读。"重点模块"卡片从并排变为单列堆叠。
**观察**：摘要换行导致筛选栏高度增加，但无信息截断。**布局基本可用**。

#### 状态 4：产品维度含"超长标识测试项"
**证据**：两张截图的产品组中均出现第四个按钮"超长标识测试项"，与产品α/β/γ并列。
**源码证据**：filter-test.html:91 存在 `data-val="xxxxxxxx...`（超长字符串）的筛选项。
**观察**：这是明显的测试数据污染。若用户误点，URL hash 将携带超长编码，可能触发 2048 字节限制（`URL_SIZE_LIMIT`），导致"当前选择过多，请保存为本地视图"提示。

#### 状态 5：筛选器命名与表格展示不一致
**证据**：筛选器显示"产品α/β/γ"，表格"产品"列显示"产品甲/乙/丙"。
**源码验证**：`window.__FILTER_ROWS__` 中 `product` 字段（如 product-gamma）与 `product_label`（如 产品丙）分离。筛选器标签从 HTML 文本取，表格从 `product_label` 取。
**观察**：医学经理无法直观判断"产品α"是否等于"产品甲"。这是跨维度数据映射的展示断层。

#### 状态 6："本模块"区域包含跨模块筛选器
**证据**：截图中"本模块"区域同时包含"终点"（疗效）和"不良事件术语"（安全性）两个维度。
**源码验证**：`data-module-id="b-safety"` 的不良事件术语组被放在 `data-scope="module"` 的 section 内，而该 section 的 `data-module-id="b-efficacy"`。
**观察**：医学经理会认为"本模块"下的所有筛选只影响当前疗效模块，但"不良事件术语"实际影响安全模块行。这种语义层级混乱增加认知负担。

#### 状态 7：空结果状态（基于代码推断）
**证据**：portal.js:791-828 `filterVisibleRows()` 逻辑。当 `hasFilters && count === 0` 时显示 `#kz-filter-empty`。
**推断**：选择"产品α"（page）+ "次要终点"（module b-efficacy）将产生空结果（row-001 是主要终点，row-003 是产品α但次要终点... 等等，row-003 就是产品α+次要终点，不会空）。
**真正空结果组合**："产品β"（page）同时 + "终点=次要终点"（b-efficacy module）+ "不良事件=治疗期不良事件"（b-safety module）→ row-002（product-beta, ep-pri）被 b-efficacy 排除，row-005（product-beta, ae-sae）被 b-safety 排除。**逻辑支持空结果**。

### 三、P0/P1/P2 问题清单

#### P0-1：测试数据"超长标识测试项"污染生产界面
- **位置**：filter-test.html:91，产品筛选组
- **用户影响**：医学经理看到无意义按钮"超长标识测试项"，误点后 URL 携带超长编码，可能触发 2048 字节限制导致状态无法保存，产生"当前选择过多"困惑提示。
- **最小修复**：删除该测试筛选项及其数据行，或将其移至仅测试环境可见的 fixture。

#### P0-2：页面标题与导语暴露内部测试性质
- **位置**：`<title>筛选验证页 - 筛选状态测试</title>`、`<h1>筛选验证页</h1>`、导语"本页面展示筛选功能验证，使用合成数据"
- **用户影响**：医学经理直接看到"验证""合成数据""测试"等内部术语，严重破坏专业信任感。设计规范 §2 明确禁止"程序状态、日志标签、提示词或后端字段名"出现在用户可见层。
- **最小修复**：标题改为"竞品数据筛选"，导语改为"选择适应症、产品和终点以查看对应试验数据"，删除所有"验证/合成/测试"字样。

#### P1-1：筛选器标签（产品α/β/γ）与表格展示（产品甲/乙/丙）命名不一致
- **位置**：筛选按钮文本 vs 表格"产品"列
- **用户影响**：医学经理无法建立"产品α=产品甲"的心智映射，在筛选和结果之间产生认知断层。可能怀疑自己是否选对了产品。
- **最小修复**：统一命名体系，筛选器和表格使用同一套产品名称（如统一为"产品甲/乙/丙"或统一为通用名）。

#### P1-2："本模块"语义层级混乱（疗效+安全混放）
- **位置**：筛选面板"本模块"section 内同时包含终点（b-efficacy）和不良事件术语（b-safety）
- **用户影响**：医学经理不理解"模块"概念，看到"本模块"下有疗效终点也有安全不良事件，会误以为所有筛选共同作用于同一组数据。实际疗效终点只过滤疗效行，安全AE只过滤安全行。
- **最小修复**：将"不良事件术语"移至独立的安全模块筛选区域，或重命名"本模块"为更具体的"疗效模块"，并增加安全模块独立区域。

#### P1-3：筛选入口使用"⚙"齿轮图标
- **位置**：`.kz-filter-entry__icon`
- **用户影响**：齿轮是软件/设置的标准符号，对不熟悉计算机的医学经理不够直观。设计规范要求"中文原生的临床试验语境表达"。
- **最小修复**：将"⚙"改为更直观的图标（如"🔽"下箭头或"⧩"筛选符号）或直接去掉图标，仅用"筛选 ▼"文字。

#### P1-4："更多条件"折叠缺乏视觉提示
- **位置**：`<details class="kz-filter-advanced">`
- **用户影响**：医学经理可能完全注意不到"更多条件"可以展开，从而遗漏"分母角色"筛选。
- **最小修复**：为 summary 增加展开/折叠指示箭头（▶/▼），或使用更明显的按钮样式替代原生 details。

#### P1-5：表格表头字号 13px 踩设计规范底线
- **位置**：`#kz-filter-row-table th { font-size: 13px; }`（portal.css:768）
- **用户影响**：设计规范 core.md §0.7 要求 site_html 正文≥16px，高密度表≥14px，NEVER <13px。表头 13px 处于绝对下限，在 1024px 或高分屏上可能难以阅读。
- **最小修复**：表头字号提升至 14px 或 15px。

#### P1-6：重置按钮无确认，误操作风险高
- **位置**："重置本页筛选"、"重置本模块筛选"
- **用户影响**：懒惰/不熟悉的用户可能误触重置，尤其在 1024px 触控场景下，已选条件瞬间清空且无法撤销（除非立即后退）。
- **最小修复**：增加 `confirm()` 确认对话框，或将重置改为"撤销"机制（保留上一次状态）。

#### P2-1：缺少"清除全部"统一入口
- **位置**：筛选栏
- **用户影响**：需要分别点击"重置本页"和"重置本模块"两个按钮才能完全清空，操作冗余。
- **最小修复**：在筛选栏增加一个"清除全部"按钮，或让每个 chip 的移除更突出。

#### P2-2：行计数文案过于数据库化
- **位置**："共 X 条记录"
- **用户影响**："条记录"是数据库术语，不够临床语境化。
- **最小修复**：改为"共 X 项数据"或"匹配 X 项结果"。

#### P2-3：筛选面板内"不良事件术语"与"终点"间距不足
- **证据**：两张截图中"终点"组和"不良事件术语"组之间间距较小，视觉分组不够明显。
- **用户影响**：医学经理可能将疗效终点和安全不良事件误认为同一维度。
- **最小修复**：增加组间间距（从 16px 增至 24px），或在组之间增加分隔线。

#### P2-4：1024px 下"已选 X 项"摘要换行导致筛选栏高度不均
- **证据**：filter-1024.png 中摘要换行后，筛选栏高度增加但内容偏少，留白不均。
- **用户影响**：视觉节奏被打断，信息层级模糊。
- **最小修复**：在 1024px 媒体查询中调整摘要位置，或允许 chip 区域更早换行。

### 四、最值得保留的设计

1. **URL Hash 状态持久化**（portal.js:420-478）：`v1~pid=...~ps=...~m=...~ms=...` 格式简洁、可分享、支持后退/前进/刷新恢复，是筛选系统的核心资产。
2. **Chips 摘要 + 逐条移除**（portal.js:633-675）：已选条件以 chip 形式展示，每个 chip 可独立移除，符合"懒惰"用户的精细化撤销需求。
3. **双层级筛选架构**（全页 + 本模块）：区分页面级和模块级筛选是临床报告的必要设计，避免了所有筛选混杂在一起。
4. **空结果状态明示限制条件**（portal.js:758-789）：空结果时列出所有已选条件，帮助用户理解"为什么没数据"。
5. **键盘可达性**（Enter/Space 激活、Esc 关闭面板、focus-visible  outline）：无障碍基础扎实。
