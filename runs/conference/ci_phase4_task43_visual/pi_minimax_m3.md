## 5. 最值得保留的设计

1. **三层级 + 双清除按钮**：「整份报告条件 / 疗效数据 / 安全性数据」三段，每段独立 ghost 按钮，零教学即可理解。
2. **chip 摘要前缀用模块名而非 scope 关键字**：「整份报告 · 适应症：系统性红斑狼疮 × / 疗效数据 · 终点：主要终点 × / 安全性数据 · 不良事件术语：治疗期不良事件 ×」对临床经理是自然语言，不是软件术语。
3. **空状态卡列全已选 + 三个独立清除按钮**：失败时给出全部三个出口，不让用户陷入"为什么还有残留"的反复猜测。
4. **URL 即真源**：`#v1~pid=...~ps=...~m=...~ms=...` 结构稳定，分享 / 刷新 / 后退 / 前进完全一致。
5. **favicon 改为 `data:,`**：消除一切 404 噪声；不要在线 favicon，匹配 §14.12.2 "不加载远程字体/图片/脚本"。
