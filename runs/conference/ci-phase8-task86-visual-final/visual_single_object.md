## Independent Work Product

### P1-1：C-15 的大面积空白使“可选路径一”失去路径图解功能

**证据**

- `c-15-c-path-1`，Chromium `1920×1080`：`docs/acceptance/runs/8.6/visual-final/screenshots/chromium/1920x1080/c-15-c-path-1.png`
- 同页 Chromium `2048×1024`：`.../chromium/2048x1024/c-15-c-path-1.png`
- 同页 WebKit `1280×800`：`.../webkit/1280x800/c-15-c-path-1.png`

三种实图中，标题下的主卡片只使用顶部约四行文本，卡片其余大半高度为空；下方仅有一条结论条。宽屏与紧凑视口均稳定复现，不是浏览器换行问题。

**判断**

- 该页标题为“可选路径一”，但主体是段落说明而非路径、时间线、分组关系或取舍结构。医学经理在 20–30 秒浏览中看不到可被复述的“路径”。
- 这与 HTML-PPT 规范的填充式构图约束冲突：核心信息为流程/关系/分支时，应有填满正文框的可视化结构，且不得存在死带（`track_htmlppt.md` 第 190–200 行）。
- 空白本身不是品牌留白；它位于带边框的主体卡内，造成未完成版感，且与 A/B 中以图表、矩阵或紧凑表格承载结论的页面不一致。

**有界修复**

保留现有事实和中文原句，不新增或推断医学数据；把该卡改成横向三段路径：

1. `三盲、平行对照`；
2. `背景治疗至第16周 / 治疗延长至第52周`；
3. `成人入组阈值 + 第16周 IGA 成功定义`。

每段显示“设计选择—证据锚点—对决策的含义”；底部保留现有结论条。这样能使用同一信息量填充主体并使页标题与视觉对象一致。

### P1-2：B-04 疗效图缺少图形自身的指标与单位，且“无同期对照”弱化为次级标签

**证据**

- Chromium `1280×800`：`docs/acceptance/runs/8.6/visual-final/screenshots/chromium/1280x800/b-04-b-efficacy.png`
- Chromium `1920×1080`：`.../chromium/1920x1080/b-04-b-efficacy.png`
- 台账明确将该页列为重点人工复核页：`visual-baseline-ledger.md` 第 41 行。

图中纵轴刻度为 `0–105`，没有轴标题、百分号或终点名称。橙、蓝图例只标示“治疗组/对照组”。右侧 `APPOINT–PNH` 下的“无同期对照”以低对比度、小字号放在类别标签下方。

**判断**

- 视觉上首先读到的是 `82.3 / 1.8 / 92.2` 三个数字；其是否为比例、何种终点、右侧 92.2 是否可按与左侧相同的对照逻辑解读，都没有被图形本体明确锁定。
- 页面底部说明包含终点解释，但属于第二阅读层；在管理层扫描时，图表不能依赖脚注来定义纵轴。
- “无同期对照”是结果可比性的重要解释条件，当前视觉权重显著低于柱、数值和统一图例，容易造成不恰当的横向视觉比较。这是表达层级问题，不要求改动数据或结论。

**有界修复**

- 给纵轴补足清晰的指标标签，例如“达成血红蛋白稳定控制且无需输血的受试者（%）”；使用当前数据合同中的准确终点名称，不能凭页面截图补写。
- 将两组结果拆为显式列头/分区：`随机对照｜第24周` 与 `单臂结果｜无同期对照`；后者采用中性边框或“不可作直接组间比较”状态标签。
- 保留 APPOINT 的 92.2 数值，但不要让其与左侧蓝色对照柱共享同一无条件比较框架。

### P2-1：C-09 的终点名称写法不统一，削弱中文医学材料的原生性

**证据**

- Chromium `1280×800`：`docs/acceptance/runs/8.6/visual-final/screenshots/chromium/1280x800/c-09-c-endpoints.png`
- 台账重点页：`visual-baseline-ledger.md` 第 42 行。

页面前三张卡以 `IGA ≥ 2 分；评估时点 第16周` 描述；右下卡写作 `EASI ≥ 75%改善；评估时点 第16周`。同页底部结论则使用 `EASI–75`。

**判断**

同一页对同一临床终点同时出现 `EASI ≥ 75%改善` 与 `EASI–75` 两种表现，破坏术语识别的单一性。`75%改善` 的百分号与中文词语粘连，也低于该页其他卡片的中文排版质量。

**有界修复**

在数据不变前提下，指定一个受众可读的术语并全页统一。建议采用 `EASI-75 改善（评估时点：第16周）`；若源合同要求数学阈值表达，则统一为 `EASI 较基线改善 ≥75%（第16周）`。修复应复核 C-03、C-08、C-09、C-13 至 C-16 等引用 EASI 的页面，避免仅改单页产生第三种写法。

   本轮未完成 496 张逐张原图人工审阅。尤其未逐页核对 `1280×800`、`2048×1024`、`1280×720` 以及 WebKit。安全路径：Codex 仍按台账的 62 页 × 4 视口 × 2 浏览器逐图核对，不能以本轮索引观察替代。

2. **P1 修复回归风险**  
   C-15 若仅缩短卡片高度会消除视觉空白但仍不满足“可选路径”的信息形态；修复必须增加结构化路径对象，而不是把正文上移或移除边框。

4. **跨页术语回归风险**  
   C-09 术语统一后，凡引用 `EASI-75`、`EASI ≥75%`、`IGA` 的摘要、设计图谱、分组和路径页需要做定向搜索与原图复核，防止术语漂移。

   已读取的 `track_htmlppt.md` 段落显示完整文件有 2645 行；本轮仅使用与画布、chrome、字级、栅格和填充构图直接相关的可见条款。未声称完成全规范逐行合规审计。
