## D3（未到末页误显示“演示结束”）：建议关闭

我首轮将其判为“可能有意设计”，Codex 裁决为真实缺陷（`.presenter-end{display:grid}` 覆盖 `hidden`），该裁决正确——CSS `display` 优先级高于 `hidden` 属性是经典陷阱。

复核证据：

1. **视觉**：两张新演讲者原图中，下一页栏仅显示「主要疗效」预览（含缩放正确的图表 iframe），下方黑色面板区域为空白，**不再出现「演示结束」字样**。Chromium 与 WebKit 表现一致。
2. **断言**：测试第 167 行首页 `#next-end` 必须 `is_hidden()`，第 187 行末页必须 `is_visible()`——双向断言，既防误显示也防永不显示，优于单向断言。
3. **回归**：新 runtime.js 哈希已绑定台账与 manifest，且据 Codex 记录 18/18 合同测试全通过；我核实的哈希一致性与断言存在性与此记录吻合。

**关闭，无残留。** 附带说明：`.presenter-end[hidden]{display:none}` 修复在 JS 侧（哈希变化只在 runtime.js），若该规则实际写在 runtime.css 中则 css 哈希应同步变化——但本轮 css 哈希未变，说明规则确实注入于 JS 或 presenter 内联样式，与哈希证据自洽，无矛盾。
