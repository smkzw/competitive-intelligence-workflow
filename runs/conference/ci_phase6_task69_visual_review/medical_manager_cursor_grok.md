## 4. 视觉与中文原生性评价

**品牌与层级（事实 + 审美）**  
浅底、橙识别、卡片轻阴影，像康哲医学门户而不是深蓝驾驶舱。主标题 32px 深字，正文栈含微软雅黑。按钮/卡片尚和谐，动效不明显（符合「别晃」）。

**咨询级图表（事实）**  
EASI 双柱能开会用。安全性更像单列色带，行文过长，不像一张能指着说话的热图。矩阵页没有位置图，开会时这页是空的。

**中文（事实）**  
界面主体是中文医学用语（全分析集、应答率、披露状态）。夹杂可接受的 EASI-75 / TEAE / SAE。问题是：**说明书腔**（「图形定位」「同一事实范围」）、**内部字段**、搜索失败、档案「示例*」。不是机器英译整页，但也不像医学部自己写完的定稿。

**信息密度（推断）**  
页头+四枚芯片+筛选条吃掉约一半首屏，图被挤到下巴。对「懒、视觉敏感」不友好：要的是一进门看见四家柱/热图，而不是先学筛选。

**零与未公开（事实）**  
口径声明与 SAE/TEAE 表现一致，这是本包里最像「医学门户」的一点。
