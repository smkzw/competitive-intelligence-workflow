## 二、医学经理核心关切与专项核查结论

### 1. B 类试验完成情况与暴露量单位拆分（受试者计数 vs 相对剂量强度 RDI）

- **医学关切**：临床试验处置（Trial Disposition）中的受试者例数（已筛选、已随机、完成治疗、中止、退出等）是离散的人数计数，而相对剂量强度（RDI, Relative Dose Intensity）是连续百分比暴露量指标。若二者混用同一坐标轴或并入同一统计图表，会造成严重视觉误导和可比性破坏。
- **核查证据**：
  - 在 `adherence.html`、`trial-exposure-context.html`、`participant-flow.html` 等页面中，图表组数据（`window.__CHART_GROUPS__`）严格将受试者计数（无单位或“人/例”）与相对剂量强度（明确标注 `unit: "相对剂量强度"`）拆分为完全独立的图表容器与渲染模块。
  - 在 IPTACOPAN (NCT04558918)、PEGCETACOPLAN (NCT03500549) 等试验的依从性与暴露量比较中，相对剂量强度（如治疗组 99.6%、对照组 100.6%）均单独成图并配有专用数值标签，未出现人数与百分比混轴或单位模糊的问题。
- **判定**：**合格（未混淆）**。

### 2. C 类设计图谱可比较性（临床设计事实 vs 披露状态墙纸）

- **医学关切**：设计图谱不可仅呈现“已披露/未披露/尚未公开”的颜色状态块（状态墙纸），必须能让医学人员横向并排比较各竞品在具体入排标准、病程评分阈值、给药周期、对照设置等维度的具体临床设计事实。
- **核查证据**：
  - 审查 `design-map.html`、`endpoint-timepoint-matrix.html`、`population-disease-definition.html` 及各试验详情页（如 `c_trials_nct02260986`、`c_trials_nct03569293` 等）：
  - 设计图谱主表与矩阵完整包含“产品 - 试验编号 - 设计要素 - 具体内容 - 时间点 - 披露状态 - 数据依据”七列；
  - 表格直接印出具体临床参数（例如：最低年龄 18 岁、EASI 评分要求、特应性皮炎病程至少 3 年、给药剂量与频次、随访周期及统计分析集定义），支持跨试验精准并排比较，未退化为纯状态指示卡。
- **判定**：**合格（具备实质临床可比较性）**。

### 3. A/B/C 默认首屏、核心矩阵与多视口横向适配

- **医学关切**：在小屏笔记本（1024/1280）到大屏（1440/1920）下，核心疗效图、安全性热图和疗效—安全性气泡图必须在内容列内完整呈现，避免横向拖动；表格与图表必须遵循“图在前、完整表在后”的设计规范。
- **核查证据**：
  - **首屏与版式**：各报告首屏标题精炼明确（如“创新治疗格局与医学结果”、“阵发性睡眠性血红蛋白尿临床试验结果比较”），直接展示靶点分布与核心格局；
  - **图表完整性**：
    - 疗效柱状图/折线图：主要终点响应率（如 EASI-75、IGA 0/1、Hb 稳定率）对比清晰；
    - 安全性热图：AE/SAE/AESI 在单元格内均直接标注发生率百分比或例数，同时保留事件与组别标签；
    - 疗效—安全性气泡图：横轴（主要疗效）、纵轴（TEAE 发生率）、气泡大小（试验组样本量）三维映射规范，未提供坐标的试验在页内单列说明；
  - **视口适配**：全站 114 个页面在 `1024×768`、`1280×800`、`1440×900`、`1920×1080` 下图表容器均能自适应宽度，无截断或横向溢出。
- **判定**：**合格**。

### 4. 中文原生医学表达与无工程/日志语言残留

- **医学关切**：禁止在报告中出现 `gate`、`signal`、`registry-only`、`AI evidence synthesis`、`accepted`、`pending`、`not_run`、`raw_id`、`undefined`、`null`、`NaN` 等程序与内部状态术语。
- **核查证据**：
  - 对全站 HTML 的受众可见文本进行了正则与全文检索；
  - 除 `SIGNAL-AD`（特应性皮炎 Bempikibart II 期试验的正式官方研究名称）外，未发现任何后端字段、日志标记或未处理的 JavaScript 占位符；
  - 术语均转换为规范的临床表达（如“主要分析人群”、“登记结果报告期”、“特别关注不良事件”、“未公开”、“不适用”等）。
- **判定**：**合格**。

### 5. 交互下钻与证据溯源一致性

- **医学关切**：用户点击任何定量数值或结论，均能平滑呼出证据抽屉（Evidence Drawer），展示数据来源、原始文献/登记号定位、版本与免责说明。
- **核查证据**：
  - 抽屉组件（`evidence-drawer`）在 A、B、C 三类报告中均统一定义，提供事实依据、版本历史与冲突标注，下钻逻辑连续且不破坏当前页面筛选状态。
- **判定**：**合格**。
