# Task 6.7 试验完成情况与受试者处置事实合同

## 目标

建立可追溯、可比较但不强行补全的 `trial_disposition_observation` 合同，完整保存受试者流转、原因、依从性、补救治疗、禁用药和方案偏离等公开事实。全部处置数值均为非阻断字段：即使随机、治疗、完成、退出人数及主要原因未公开，也要生成结构化披露状态，不能伪造为零、空白或阻断 B 类报告。

## 字段与科学边界

- 身份：产品、试验、阶段/期间、队列、组别或总体层级、分析人群。
- 字段族：筛选、筛败、随机、接受治疗、完成治疗、完成研究、停止治疗、退出研究、失访；筛败/停止治疗/退出研究原因；依从性、补救治疗、禁用药、方案偏离及其公开层级。
- 计量：受试者数或事件数、统计形式、分子、分母、来源报告比例、可复算比例、分母角色、时间窗。
- 原因：来源原文、规范原因、是否互斥、是否穷尽；原因非互斥或非穷尽时不得暗示总和等于总体退出率。
- 依从性：必须保留来源阈值或计算定义；方案偏离的受试者数和事件数不得互换，重大 PD、导致排除的 PD 等层级分别保存。
- “完成治疗”与“完成研究”、“停止治疗”与“退出研究”必须分别建模；筛败率保持筛选总体语境，不分配到随机组。
- 仅在分子、正分母和语境明确时确定性复算比例；来源比例与复算值不一致时保留来源值并加中文差异标记，不静默修正。
- 明确零、原文未报告、未公开、低于列示阈值、不适用、冲突和技术路径未解决沿用 `FactDisclosureState`，不得新增第二套缺失枚举。
- 已报告事实必须有来源版本和精确定位；缺失状态不得携带数值；技术路径未解决必须保留路由回执，不得降级为“未公开”。

## 验收标准

- [ ] 预定义字段族覆盖上述全部流转、原因和试验实施字段，不使用自由文本字段名替代规范字段族。
- [ ] 受试者/事件、完成治疗/完成研究、停止治疗/退出研究和各种分母角色有不可混用的正负例。
- [ ] 比例只在可复算时计算，来源比例不一致时保留并标记；不从 100% 或其他类别补造值。
- [ ] 原因互斥/穷尽、依从性定义、PD 层级和总体/组别作用域均可追溯。
- [ ] 所有数值字段缺失均为非阻断披露状态；报告 GateSpec 不因处置缺失新增 critical 单元。
- [ ] schema 与模型一致，稳定行身份和来源谱系通过 `model_copy` 对抗测试。
- [ ] Task 6.1–6.6、Gate、A/B 报告相关回归、Ruff、strict mypy、schema/diff 检查通过。
