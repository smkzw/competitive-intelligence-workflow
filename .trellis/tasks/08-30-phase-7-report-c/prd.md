# Phase 7 C 类完整门户

## 目标

面向资深临床试验医学经理，提供逐产品、逐试验、逐队列/组别、逐设计字段的方案事实比较；任一结论可下钻至登记版本或附件中的精确位置。

## 阶段门槛

- 关键设计事实缺少人群、分组、终点或时间点时不生成草稿。
- 登记字段足以覆盖关键设计时，Protocol/SAP 缺失可通过并以专业中文说明证据范围。
- 统计细节只保留分析人群、主要比较逻辑等公开字段；缺失不阻断，不推断。
- 只输入适应症时不得生成唯一“最佳方案”，必须给出至少两条有证据的可选路径及权衡，或明确需要的产品背景。
- C 类最终仍执行康哲站点式 HTML、图在前表在后、完整证据下钻和生成前视觉美化复核。
