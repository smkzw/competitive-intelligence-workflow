# Task 7.3 产品要求

- 医学经理可从设计图谱快速比较产品、试验、阶段、人群、分组、干预/对照、终点、时间点、访视/疗程、样本量和已公开统计设计。
- 每一项终点比较必须把“终点名称、完整定义、评估时间点”作为不可拆分的三元身份；同名终点但定义或时间点不同，不得静默合并。
- 逐试验档案必须完整包含该试验当前快照中的全部设计观察，不只展示预设字段或少数代表性条目。
- 入选和排除视图复用 Task 7.2 的稳定下钻链；所有视图均能回到同一来源版本和精确定位。
- 未公开统计字段保持未公开/未报告/不适用等真实状态，不填入行业常见做法，不显示工程状态标签。
- 本任务只建立页面所需的数据投影，不制作 HTML，也不声称 C 报告已经生成。
