# Task 7.3 技术设计

- 在 `reports/c/pages.py` 复用 `DesignObservation`、`EvidenceLocator`、稳定 ID 和 Task 7.2 入排投影；不新增第二套事实合同。
- 对传入观察先逐条调用公共重新校验，再按试验、组别和字段族确定性投影；输入顺序不应改变稳定身份或档案事实集合。
- 终点三元身份由终点观察与明确配对的时间点观察形成，必须具有同一产品、试验、队列、组别和配对键；不得仅按显示名称或出现顺序配对。
- 任何同名终点在完整定义或时间点不同的情况下保留独立身份；缺定义或时间点不得生成可比较终点行。
- 逐试验档案的观察身份集合必须与该试验输入观察身份集合完全相等，并保留原文、来源版本、定位、披露状态和冲突处置。
- 统计页面仅投影已公开字段及真实缺失状态；禁止推断统计模型、效应量、多重性等未公开细节。
- 设计图谱和各专题投影共享同一观察/终点/档案稳定身份，供 Task 7.5 页面直接使用。
