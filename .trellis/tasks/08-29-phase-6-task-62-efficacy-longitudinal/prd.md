# Task 6.2 疗效和纵向结果

## 目标

为 B 类报告建立可审计、可复现的首页终点依据和疗效视图模型，使医学经理能够在治疗组与对照组并列的前提下查看单时间点、纵向及来源直接报告的效应量结果，并在当前可比范围内主动排序。

## 范围

- 建立 CDE、FDA 平行监管依据与竞品主要终点采用依据。
- 建立单时间点柱状图、纵向折线图、来源效应量森林图所需的强类型视图模型；本任务不创建物理 HTML 页面。
- 建立默认不排名、仅对当前兼容桶生效、缺失值不伪装为零的可逆排序合同。
- 复用 Task 6.1 的研究角色和终点—时间窗兼容结果，不复制兼容逻辑。
- 不实现安全性、基线、受试者处置、气泡矩阵或 B 门户。

## 不可放宽的要求

- 已废止指南只保留历史，不驱动默认；草案必须明确标为“草案”，不能伪装成最终指南。
- CDE 与 FDA 不设静默优先级；兼容依据合并时保留全部标签和精确来源定位，实质语境差异必须分列。
- 竞品共识只以锁定的适格核心试验为分母，只计算主要终点；支持研究及次要/探索终点不得增加采用计数。
- 严格多数才能写“多数竞品采用”；无严格多数时，只能在最高命中且至少两项试验时写“最常采用”。
- 治疗与安慰剂/对照始终并列；不得执行 Meta、NMA、MAIC、STC 或跨试验调整。
- 原终点、实际时间点、方向、单位、分析形式、组别、分母与来源行标识不得在视图转换中丢失。
- 默认顺序按靶点分组及稳定标识，不使用疗效数值；用户排序只在当前兼容桶内生效，并能恢复默认。

## 验收标准

- [ ] 计划指定的三份测试先形成 RED，再全部 GREEN。
- [ ] 指南依据保留司法辖区、机构、标题、状态、版本/日期、人群、研发语境、精确定位、捕获版本和废止关系。
- [ ] 竞品终点依据保存分母、命中试验、原始终点角色、兼容规则及合并/分列理由。
- [ ] 单时间点、纵向和来源效应量三类视图均使用同一事实行，治疗与对照并列。
- [ ] 用户排序不跨兼容桶、不将未知按零排序，恢复默认后顺序完全可复现。
- [ ] Task 6.1、A 类报告及相关来源回归通过；Ruff、strict mypy、差异检查通过。
- [ ] 独立审阅确认没有把科学差异隐藏在合并或排序中。
