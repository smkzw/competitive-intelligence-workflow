# Phase 5 A 类完整竞品门户

## Goal

面向中国资深临床试验医学经理，完整呈现目标适应症下全部创新治疗项目；成熟项目证据不足时明确阻断，不删药、不做 Top-N、不用空壳继续生成。

## Acceptance Criteria

- [x] Task 5.1：范围、成熟度与 `result_bearing` 证据合同通过。
- [x] Task 5.2：格局、产品、临床组合、监管、企业交易、专利和历史边缘视图通过。
  - 全量创新治疗不截断；逐产品稳定路由与完整档案。
  - 临床组合关系闭合；中国/境外监管分轨。
  - 企业角色、地域权益、交易条款不混写。
  - 专利、法域、期限与监管独占分列；历史/边缘项目不消失。
- [x] Task 5.3：疗效、安全热图与疗效—安全气泡矩阵通过。
- [x] Task 5.4：A 全部物理页面与完整 fixture 通过。
- [x] Task 5.5：脱敏案例、负例与 fresh 特应性皮炎独立验收通过。

## Non-negotiables

- 只纳入创新治疗；传统背景治疗不获得竞品档案。
- 所有合格项目完整保留，暂停、终止、撤回和放弃项目不消失。
- 有可归属数值结果即进入成熟证据层；关键疗效或 TEAE/SAE 不足时阻断整个 A，不删除该产品继续。
- 用户界面只显示专业中文医学/竞争情报，不显示工作流、提示词或工程状态。

## Task 5.4 完成判定

- 真实生成 12 个静态责任页和锁定快照内每一个产品的详情页；首页、疗效、安全性、疗效—安全性矩阵分别承担独立责任。
- 首页同时展示竞争格局、疗效、安全性和疗效—安全性位置四个图形摘要；详情页一律图在前、完整数据表在后。
- 全局搜索、页面导航、产品下钻、多选筛查、网址状态和数据依据在 `file://` 下可用；用户不需要理解工程概念。
- 本次 `a-complete` 输入摘要、运行标识、报告快照、站点清单和真实站点目录摘要闭合；不得借用旧站点或旧截图。
- Chromium 与 WebKit 在 1280、1440、1920 三档宽度遍历全部物理页面，无断链、控制台错误、横向溢出、固定区遮挡或用户可见工程文案。
