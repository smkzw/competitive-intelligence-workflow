# Task 10.4 设计

## 清单模型

JSONL 每行是一条稳定 `item_id` 记录。单文件迁移使用文件 SHA-256；目录、历史范围或敏感类别使用不泄露内容的集合摘要或哨兵摘要，并以 `validation_evidence` 说明机械验证方法。

`final_disposition` 仅允许：

- `migrated`：经批准并已进入新仓；目标必须可重算验证。
- `retained_as_history`：只保留为设计/决策证据，不成为运行输入。
- `not_migrated`：明确拒绝迁移；不得有新路径或运行依赖。

## 白名单与黑名单

白名单是封闭集合，不能因为旧根存在更多文件而自动扩张。黑名单按稳定类别登记，避免把会话、缓存或明文凭据逐文件复制到清单；清单只记录类别路径和处置，不读取或传播凭据内容。

## 失败关闭

未知字段、重复 ID、目标逃逸、摘要漂移、`not_migrated` 项出现目标路径、未覆盖必需类别、旧根运行引用或兼容入口被误当权威合同时，测试失败。
