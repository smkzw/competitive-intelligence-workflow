# Task 6.6 基线人口学、疾病语境与严重程度视图模型

## 目标

把 Task 6.5 已验收的完整基线事实转换为资深医学经理可直接比较的三个页面责任视图：人口学、疾病语境、基线疾病严重程度。视图必须图在前、完整表格在后，筛选、网址状态和证据下钻使用同一事实集；不得为提高可绘制性而混合统计口径、重分箱、补造类别或生成跨试验优劣评分。

## 需求

- 连续变量：同一规范概念、量表/版本、方向、单位、基线定义和统计形式兼容时使用点图/区间图；只有中心值时使用带数值标签的点图。均值、中位数、标准差、四分位数和范围不互换，不凭空生成误差线。
- 分类变量：只有分母明确时生成分组比例柱状图；不完整类别不得生成暗示总和为 100% 的堆叠图，不以 100% 减法补类别，不强制二元化或重分箱。
- 严重程度：每个兼容桶独立形成小多图；量表、版本、方向、单位、基线定义、基线时间或统计形式不同必须拆分并保留中文差异提示。
- 默认变量顺序固定为样本量、年龄、性别、当前适应症全部关键严重度锚点，再按人口学、疾病语境、其他严重度的稳定变量身份排列；不得按数值优劣排序。
- 完整表格保留全部筛选后事实，包括无可绘制数值的披露状态、来源统计形式、分母、原文值、兼容差异和证据身份。
- 支持产品、靶点、试验、队列、组别、地区、分析人群、变量域、规范变量、统计形式、量表、单位和披露状态多选；当前域不适用的筛选项隐藏或禁用，不冒充数据缺失。
- 页面筛选、模块筛选、图、表、当前证据焦点和网址状态必须可逆同步；无结果时保留当前范围并给出中文空状态，不自动放宽筛选。
- 用户可见标签必须为中文临床试验语境，不暴露内部状态名、程序标签或日志术语。

## 验收标准

- [ ] 人口学、疾病语境、严重程度三类视图均由 `BaselineObservation` 单一事实源确定性生成。
- [ ] 连续/分类/严重程度图形资格和拆分规则有正负例，禁止科学口径混画和数据补造。
- [ ] 图形行与完整表格行具有可核对的一致来源身份；表格不因默认图形选择丢行。
- [ ] 所有规定筛选维度、页面/模块重置、URL 往返及证据焦点同步通过测试。
- [ ] `reported_zero`、未公开、原文未报告、冲突、技术路径未解决和不适用保持不同中文状态；无数值时不生成空坐标轴。
- [ ] Task 6.1–6.5、Gate、A/B 报告相关回归以及 Ruff、strict mypy、schema/diff 检查通过。
- [ ] 独立医学语义复核确认不存在跨试验优劣评分、虚假误差线、自动重分箱或中文工程化文案。
