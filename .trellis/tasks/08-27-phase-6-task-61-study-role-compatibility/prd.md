# Task 6.1 研究角色与终点时间窗兼容规则

## 目标

在 B/C 报告分析前建立可审计、版本化、失败关闭的研究角色和 B 类终点—时间窗兼容合同，防止不相干研究、论文类型或模型临场判断污染核心横向比较。

## 研究角色要求

- B 核心层默认只纳入目标适应症中有结果的 II/III 期、关键或注册相关试验。
- 健康志愿者、纯 PK/BE、无关适应症、一般观察性研究和 EAP/同情使用默认排除。
- 支持层必须指向一个已命名的安全性、监管或特殊人群问题，并证明核心层无法替代该证据。
- 罕见病、肿瘤或加速开发中的早期试验，只有提供决策相关且不可替代的证据时才可标为特殊核心。
- C 类早期试验纳入理由必须精确指向剂量、终点、适应性设计、人群、estimand 或注册逻辑之一；“重要”等笼统理由不通过。
- `study_role` 与 `publication_role` 分列保存；事后分析、综述、支持论文或主要报告的论文角色变化不得改写母试验角色。
- 每个非默认角色保存纳入理由、命中规则、规则版本和证据版本。

## 终点与时间窗要求

- 只有同时命中版本化终点规则和时间窗规则的记录才进入同一兼容桶；无规则或越界即分列。
- 兼容性至少固定临床构念、方向、允许单位、分析形式和时间窗上下界。
- 每条观察保留原终点、定义、原单位、实际时间点、原始终点角色、分析形式、规则 ID 和差异标签。
- 不能把不同方向、不可换算单位、不同分析形式或超出约略时间窗的记录模糊合并。
- 规则文件及加载器必须确定性、版本化，拒绝未知字段、重复规则和无中文差异说明。

## 验收标准

- [ ] 五类默认排除研究全部机械排除。
- [ ] 支持层和特殊核心分别满足“已命名问题/决策域 + 不可替代证据”。
- [ ] C 类早期研究的具体设计决策域可审计。
- [ ] 论文角色变化不影响研究角色。
- [ ] 终点和时间窗兼容/不兼容正负例保留全部原始语义和规则谱系。
- [ ] 计划指定的三份测试文件原样 RED 后 GREEN，A 类相关回归不受影响。
- [ ] Ruff、strict mypy、`git diff --check` 和独立验证通过。
