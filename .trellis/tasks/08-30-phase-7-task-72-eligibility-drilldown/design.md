- 在 `reports/c/design.py` 基于 Task 7.1 的 `DesignObservation` 建立入排结构化投影，不复制证据定位合同。
- 稳定链固定为：适应症 → 产品 → 试验 → 队列/组别 → 设计要素 → 原始字段 → 量表/评分 → 筛选或评估时间 → 运算符/阈值/值/单位 → 来源版本与 locator。
- 参数化测试覆盖 fixture/测试语料中的每条适用观察；参数 case 数必须与适用观察总数一致，防止只抽查少量“好看案例”。

- 当前仓库尚无完整 C 类真实报告 fixture；本任务使用可审计的登记观察测试语料建立合同，真实 C fixture 和页面在后续 Task 7.5 另行验收，不得声称已完成端到端报告。
