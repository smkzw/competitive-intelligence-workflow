# Phase 6 B 类完整门户

## 目标

面向中文母语的资深临床试验医学经理，生成可快速判断创新药潜在疗效信号和安全性风险、同时可下钻全部结果、基线和受试者处置事实的站点式 B 类报告。

## 范围

- 纳入目标适应症中有结果的 II/III 期、关键或注册相关核心试验；其他研究只按可审计角色进入支持层。
- 提供疗效、纵向结果、安全性、疗效—安全性矩阵、基线与人群、试验完成情况、产品/试验档案、证据与局限等完整页面族。
- 首页与详情页均图在前、完整表在后；筛选、网址状态、证据抽屉使用同一事实行。
- 本阶段只生成站点式 HTML；PDF、HTML-PPT、PPTX 留待 Phase 8。
- 不做系统安全测试，不实施 B 之外的 C 类页面。

## 不可放宽的要求

- 研究角色与论文角色永久分列；事后分析、综述或支持论文不得改写母试验角色。
- 终点和约略时间窗只有命中版本化兼容规则才可横向比较；保留原终点、实际时间点、方向、单位、分析形式和差异标签。
- 治疗组与安慰剂/对照组始终并列；不执行 Bucher、MAIC、STC、Meta 或 NMA，不生成默认疗效名次、安全性排名或综合分数。
- 每项核心试验的每个可比较组必须具备基线样本量、年龄、性别和至少一个适应症严重程度锚点；不足时阻断 B。
- 所有预定义试验完成/处置字段必须建模，但单独未公开不阻断 B，也不得写成 0 或空白。
- 所有用户可见文字为中国临床试验语境的原生中文，不展示提示词、日志、后端状态名或无必要英文标签。

## 子任务

1. Task 6.1：研究角色与终点—时间窗兼容规则。
2. Task 6.2：疗效、纵向结果与指南/竞品终点依据。
3. Task 6.3：安全性热图与完整 AE 视图。
4. Task 6.4：疗效—安全性气泡图和比较矩阵。
5. Task 6.5–6.6：基线数据合同、硬门槛与视图模型。
6. Task 6.7–6.8：试验完成/处置合同与视图模型。
7. Task 6.9：完整物理门户、产品/试验档案和交互。
8. Task 6.10：fresh PNH 纵切、D70 正负例、科学与视觉独立验收。
