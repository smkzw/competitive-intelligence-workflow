# Task 8.7 需求

- A/B/C 可编辑 PPTX 必须从同一份当前锁定报告快照启动；报告身份、版本、快照摘要、声明/证据快照和 coverage 集在锁定后不可变。
- PPT Master 作业必须有类型化状态、固定九阶段顺序、每阶段一份可审计收据和持久化恢复指针。
- 同一全局 PPT Master 锁下最多一个活动作业、一个活动阶段尝试；A/B/C 也不得并行调用 PPT Master。
- 暂停只发生在阶段边界；恢复只能从最后一份已提交收据的下一阶段继续，不能依赖文件时间或目录猜测进度。
- 前置收据/产物缺失、摘要漂移、收据过期、阶段错序、跨报告/跨快照复用和终态重开必须在产生副作用前拒绝。
- 提供中文操作指引、A/B/C 代表性正例以及过期、错序、跨报告、前置摘要漂移负例。
- Task 8.7 不生成或接受 A/B/C PPTX 成片，不替代 Task 8.8 串行生成、Task 8.9 OOXML/PowerPoint/逐页视觉验收或 Task 8.10 四格式覆盖。
