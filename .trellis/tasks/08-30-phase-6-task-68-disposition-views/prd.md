# Task 6.8 试验完成情况与受试者处置视图模型

## 目标

将 Task 6.7 的同一组事实行确定性投影为“图在前、完整表在后”的试验完成情况页面族视图。用户无需理解统计或工程标签，即可看清各试验的受试者流转、依从性、失访/退出、筛败、补救治疗、禁用药和方案偏离；没有数值时仍能看清到底是未公开、原文未报告、技术路径未解决、不适用还是明确为零。

## 用户与科学要求

- 默认顺序固定为筛选/筛败、随机/治疗、完成治疗/完成研究、停止治疗/退出研究、失访，再展示依从性、补救治疗、禁用药和方案偏离；原因不按 Top-N 截断。
- 跨试验默认按分母角色和兼容统计形式拆分小多图；单试验流转可形成 CONSORT 式流转视图，但“完成治疗/完成研究”“停止治疗/退出研究”不可合并。
- 原因只有在同一原因集合明确互斥且穷尽时才允许 100% 堆叠图；否则使用独立条形图/点图，不能把原因比例相加成总退出率。
- 当前筛选范围没有可绘制数值时，主图区域必须转为试验 × 预定义字段的披露状态矩阵，不能留下空坐标轴。
- 所有图点、流转节点、状态单元和完整表格行绑定同一稳定 `row_id`、事实版本和证据位置；筛选、证据聚焦和网址状态同步。
- 表格保留来源原名/定义、人数或事件、来源值、分子/分母、来源比例、复算比例、分母角色、时间窗、原因原文/规范原因、互斥/穷尽、依从性定义/阈值、PD 层级、差异和披露状态。
- 支持产品、靶点（事实不含时明确禁用）、试验、期间、队列、组别、分析人群、字段族、字段、规范原因、分母角色、时间窗、计量对象、统计形式和披露状态多选。
- 用户可复制网址恢复相同筛选和证据焦点；未知/过期 `row_id` 失败关闭并规范化网址；页面/模块/全局重置不能残留失配图表或证据。
- 所有用户可见标签为中文临床试验原生表达，不出现枚举值、蛇形命名、提示词或日志术语。

## 验收标准

- [ ] 图表面板、完整表格、状态矩阵和证据引用严格共享同一事实行，公共操作后重新构建并核对同步性。
- [ ] 单试验流转、跨试验小多图、原因图和无数值状态矩阵的选择规则均有正负例。
- [ ] 非互斥或非穷尽原因绝不生成 100% 堆叠图；事件数不显示为受试者比例。
- [ ] 未公开/未报告/技术路径未解决/不适用/明确零分别显示，缺失值不转为 0。
- [ ] 网址 repeated-param 往返、多选筛选、证据聚焦、三层重置和不可用筛选均通过。
- [ ] Task 6.1–6.7、A/B/Gate/contract 回归、Ruff、strict mypy、diff 检查通过。
- [ ] 本任务不创建物理页面；Task 6.9 生成实际 HTML 后再进行 Chromium/WebKit 与指定模型视觉试用。

## 非目标

- 除为避免不同单位事实身份碰撞而补入单位身份外，不扩展 Task 6.7 事实语义，也不修改 B 类证据门槛。
- 不创建模板、CSS、JS、PDF、PPT 或视觉验收结论。
