# Task 8.3 产品要求

## 目标

让三份已接受的原生 PDF 在普通用户使用的标准 PDF 阅读器中可直接打开、检索和阅读，并把全部 54 页的当前渲染与逐页验收固化为可重复证据。

## 用户可见责任

- A、B、C 三份 PDF 均能正常打开，中文文字可选择和检索，书签可导航。
- 页码、纵横方向、页眉页脚、章节顺序和跨页表头完整；不得出现裁切、重叠、黑块、乱码或不可读图表。
- 验收使用 Task 8.2 最终文件的完整 SHA-256；文件变化后旧结论自动失效。
- 原始逐页图和 contact sheet 均由当前 PDF 重新生成，不能复用旧截图冒充。
- 用户不需要理解验证脚本、内部状态或日志；对外只给出简洁中文结论。

## 完成证据

- 只读验收模型可确定性输出每份报告及每页状态，任何缺页、摘要漂移或验收缺口失败关闭。
- `tools/verify_pdf.py` 生成原始页图、contact sheet、逐页文本与结构报告，并绑定最终哈希。
- `tests/acceptance/test_pdf_outputs.py` 覆盖打开、中文检索、书签、页码、方向、页眉页脚、续表和证据绑定。
- 标准 PDF 阅读器真实打开检查、隔离视觉审阅与 Codex 全页终验均通过。
