# Task 7.4 产品要求

- 先呈现竞品设计中反复出现的模式、重要差异和异常点，再提供候选设计路径；不得把综合结论写成来源事实。
- 只有适应症和竞品设计事实时，至少提供两条有证据的可选路径，每条说明适用前提、主要权衡和对应试验/观察依据。
- 默认不排序、不打“最佳”“推荐第一名”标签，也不得生成唯一方案；如证据不足以支持两条不同路径，明确停止综合而不是凑数。
- 产品特异建议必须有独立背景合同；本任务没有该合同，因此不得针对用户自有产品给出确定性建议。
- 所有归一化或雷达类维度必须能回到原始事实和值；无原始数值时不得生成分数。
- 面向用户的文字使用自然中文临床试验表达，不出现内部状态码、工程标签或提示词复述。
