# Task 7.4 技术设计

- 在 `reports/c/synthesis.py` 消费 Task 7.1 的 `DesignObservation` 和 Task 7.3 的稳定事实身份，不复制来源事实或页面投影。
- 综合分三层保存：事实模式/差异/异常点；证据支持的候选路径；路径前提和权衡。每项均绑定观察身份，综合文本与来源原文分离。
- 候选路径由至少两个不同试验设计签名支持；签名应基于人群、干预/对照、终点三元、疗程/访视等已公开事实，不能按药物名或模型直觉生成。
- 同一设计签名的多个试验可形成共同模式；仅单试验出现且与共同模式不同的事实可标记为异常点，但不得自动判定优劣。
- 输出是无顺序语义的稳定集合；即便序列为确定性展示顺序，也不得含排名字段或“最佳/首选/推荐”等中文。
- 归一化数据只有在原始数值、单位和公式均明确时才允许产生，并必须同时保留原始行；本任务最小实现可不生成归一化视图。
- 证据只支持一条独立路径、关键事实被阻断或观察为空时，失败关闭并给出自然中文原因，不生成草稿或占位路径。
