# PRD — R2.3 Publication 与人工补件产品门

## 目标

把现有 publication 分类器、manual-supply ledger 和 ManualInboxService 从孤立能力
接入严格研究提交与产品运行。登记关联的主要结果、延长期主要结果、关键安全性或
长期暴露论文必须逐篇决策；自动获取穷尽且关键全文仍不可用时，只建立一个用户可见
Markdown 补件门，并在一次响应后确定性恢复或转入带限制/证据不足分支。

## 验收

- 规则、模型和独立复核共同形成类型化 publication verdict；综述、普通 ad hoc 和
  无关探索分析默认排除，边界/分歧不能由生产上下文自审。
- 必需论文先运行自动路线；网络、解析、权限、未公开与真实未找到保持不同状态。
- 同一快照最多一个 manual-supply gate；一个响应后不重复询问。
- `file_received` 必须经过真实文件核验，并在用户收件目录原地规范重命名；记录原名、
  SHA-256、DOI/登记号和新名，碰撞/错文件/扫描不可读/登记号不一致失败关闭且不改字节。
- 用户确认无法取得后：官方登记/监管足以回答核心问题则带限制继续，否则只交付简洁
  证据不足页；受影响报告在此前暂停，不生成草稿或空门户。
- A/B/C 多报告项目只暂停受影响报告；状态、恢复、快照与运行清单可审计且幂等。
- 聚焦、integration、全仓 gate、bundle/fresh-install 和独立执行审阅全部通过。

## 边界

不实现 PDF/PPT 交付，不运行真实药智账号，不把 publication 作为 C 类登记设计字段
的替代，不触碰其他工程，不以旧 Skill 文案代替当前 v1.3 正式设计。
