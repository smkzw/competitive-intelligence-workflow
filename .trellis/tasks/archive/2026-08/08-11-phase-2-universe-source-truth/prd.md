# Phase 2 创新药宇宙、来源路由与科学真源

## Goal

Task 2.1-2.7：创新药纳排、完整竞品宇宙、多来源规划与恢复、国内外连接器、摄取定位、事实与声明链。

## Requirements

- 竞品宇宙只纳入创新药及含创新组件的方案；传统药、仿制药和生物类似药不得获得独立竞品身份。
- 改良制剂、重定位、固定复方和未知边界项无规则命中时必须等待审查，不能被静默纳入或排除，也不能闭合竞品宇宙。
- 药物、方案、企业、试验、队列、组别和外部登记号使用稳定内部身份；不得 Top-N 截断适格宇宙。
- 国内外官方登记、监管、PubMed、企业/会议和指定中文行业来源按声明域路由，保留版本、日期、定位和失败诊断。
- 技术失败与“确实未找到”分开；可重试路线至少三次带退避，同一路线与替代策略分别计数，穷尽前至少两条适用替代路径。
- 原文、片段、事实、规范化值、冲突和声明形成可逆、可定位、不可覆盖的科学链；历史截止日按首次披露时间判断。
- 用户可见语言保持中文临床语境；内部状态不得直接出现在报告界面。

## Acceptance Criteria

- [x] Task 2.1 四个创新药/方案边界精确节点逐项失败/通过，边界待审查项阻止宇宙闭合。
- [x] Task 2.2 实体身份、别名冲突、组织关系和完整竞品宇宙通过。
- [x] Task 2.3 SP01–SP11 路由、重试、替代、穷尽和历史截止日通过。
- [x] Task 2.4 FG01–FG07 国外登记、论文交叉引用、监管与 FDA 指南通过。
- [x] Task 2.5 CN01–CN07 中国登记、监管、企业与指定公众号声明域通过。
- [x] Task 2.6 IF01–IF05 摄取分类和可重开定位通过。
- [x] Task 2.7 ER01–ER04 原子事实、可逆规范化、冲突和声明链通过。
- [x] Phase 2 fixture 可从来源原文重建实体—片段—事实—声明；传统药不进入宇宙，国内外路线可追溯，并由独立验收者接受。
