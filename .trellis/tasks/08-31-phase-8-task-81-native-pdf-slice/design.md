# Task 8.1 设计约束

## 权威与路线

- 读取顺序：`contracts/kangzhe/design.md` → `design_specs/ROUTER.md` → `core.md` → `project_profile.md` → `track_stream.md` → `track_pdf.md`。
- 项目内设计包为独立冻结权威，不反向修改通用 `kangzhe-design`。
- 实现遵循 ReportLab 原生排版；图表直接使用 ReportLab 矢量绘图，不新增仅为此样例服务的第三方依赖。

## 页面语言

- 纸张采用暖白或白底，康哲橙黄只用于识别线、关键数字与有限强调；风险红只用于真实风险。
- 正文默认不低于 9.5 pt，图表标签和表体默认不低于 8.5 pt；容量不足时拆页或横向排版，不缩字掩盖问题。
- 页眉、页脚、页码和正文不重叠；标题不得孤行；续表必须重复表头并显式保留上下文。
- 文字精简但不丢失临床身份，避免英文模块名、工程术语和对工作流的解释。

## 垂直切片

1. 纵向封面和摘要页，嵌入项目正式 Logo。
2. 横向比较页，包含原生矢量柱状图以及同一事实集的表格。
3. 纵向长表页，验证自动跨页、重复表头和页码。
4. 结构化验收与当前候选逐页视觉验收相互独立。
