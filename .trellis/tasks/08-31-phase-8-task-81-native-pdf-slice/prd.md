# Task 8.1 产品要求

## 目标

证明系统能够直接消费中文 `ReportViewModel`，生成适合资深医学人员阅读的原生 PDF，而不是打印 HTML、拼接网页截图或导出幻灯片。

## 垂直样例责任

- A4 纵向与横向页面能在同一文档中正确切换。
- 中文文字可选择、搜索、复制，无乱码或不可控字体回退。
- 文档具有目录书签、页码与基本元数据。
- 长表跨页后重复表头并保留试验、治疗组和时间点语境。
- 至少一幅比较图为原生矢量图，图在前、数据表在后。
- 用户可见文字为中文临床试验语境，不出现程序状态、后端标签或制作日志。

## 完成证据

- 测试明确证明构建输入不含 HTML 或 Chromium。
- `pypdf` 验证页数、纵横方向和书签；`pdftotext` 验证关键中文可检索。
- `pdftoppm` 逐页渲染当前 PDF；逐页检查无裁切、重叠、黑块、乱码、孤立标题或不可读缩字。
- 由隔离视觉审阅者审阅当前候选摘要与当前渲染，Codex 复核实际 PDF 后接受。
