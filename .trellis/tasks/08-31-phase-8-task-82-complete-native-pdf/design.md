# Task 8.2 设计约束

- 使用项目专属 `stream + pdf` 路线；`core.md`、`project_profile.md`、`track_stream.md`、`track_pdf.md` 为设计权威。
- 复用 Task 8.1 已验证的 ReportLab builder、字体、书签、纵横页与长表能力，不另建第二套 PDF 引擎。
- 每份 PDF 在生成前建立当前快照绑定的视觉策划；不得把门户页面截图、HTML 打印页或 PPT 导出当成 PDF。
- 正文默认不低于 9.5 pt，表体/轴标签不低于 8.5 pt；宽表横向、拆表或续表，禁止缩字和裁切。
- 中文原生、临床身份完整；不显示快照 ID、流程、证据门槛、提示词、程序标签或制作日志。
- Task 8.1 的留白残余只适用于小型垂直 fixture；完整 A/B/C PDF 必须达到高信息密度和完整阅读责任。
