# Task 8.2 产品要求

## 目标

基于同一适应症、同一锁定快照与同一 `coverage_set`，分别生成 A、B、C 三份原生 PDF。三份文件必须保留门户已批准的全部页面责任，但按纸面阅读顺序重新排版。

## 用户可见责任

- A 类：竞争格局、产品、临床、监管、企业关系、交易、专利、疗效、安全性和疗效—安全性矩阵。
- B 类：疗效、纵向疗效、安全性、矩阵、基线人口学/疾病严重程度、试验完成与处置、逐试验档案。
- C 类：设计图谱、人群、入排、干预、终点/定义/时间点、访视/疗程、样本量/分析集/统计、逐试验详情、设计模式和多条候选路径。
- 所有比较均先图后表，完整保留治疗组与对照组、分母、时间点、人群和披露状态。
- 缺失信息准确写“未公开”，不得删行、猜数或用视觉空白掩盖。

## 完成证据

- `three-report-complete` case 绑定当次 run、逐文件摘要与实体计数。
- PDF01–PDF09 精确测试全部通过，coverage projection 无未批准差异。
- 三份 PDF 均为原生可搜索文字、矢量图、书签、页码、续表，不含 HTML/Chromium 输入。
- 全部页面当前渲染、隔离视觉审阅和 Codex 逐页终验通过。
