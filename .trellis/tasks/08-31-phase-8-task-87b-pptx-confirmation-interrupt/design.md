# Task 8.7b 设计

## 真值与边界

来源包只消费锁定后的报告结构化数据、覆盖集合和项目内康哲设计规范快照。确认页面是一次性输入界面，不是常驻工作台；所有用户可见文字使用中文临床试验语境。

## 实现分工

1. `source_pack`：为 A/B/C 写出中文 Markdown 与摘要清单，不生成 SVG。
2. `confirmation`：产生八项推荐、验证确认结果并幂等关闭一次性确认会话。
3. `adapter`：把来源包与确认状态接入 fixture/project run；未确认时仅将 PPTX 标为等待确认，恢复时读取同一结果继续。

## 完成证据

- 同一快照的 A/B/C 来源包与清单存在且摘要一致。
- 八项推荐与确认结果通过 Schema/类型化验证。
- 首次运行只中断 PPTX，恢复后不重复询问。
- 负例覆盖缺字段、结果漂移、跨报告/跨快照复用和关闭重放。
