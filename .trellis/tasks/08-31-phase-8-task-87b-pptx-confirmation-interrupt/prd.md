# Task 8.7b 需求

- A/B/C 的 PPTX 来源包必须来自与 HTML、PDF、HTML-PPT 相同的锁定报告快照和覆盖集合。
- 每个报告写出独立中文 source pack，并在清单中绑定报告身份、页面策略、康哲设计合同摘要和来源包摘要。
- PPTX 在真实生成前一次性收集八项确认：画布格式、页数范围、目标受众、风格目标、配色方案、图标策略、字体与公式策略、图片策略。
- 未确认时只中断 PPTX；已完成或可继续的 HTML、PDF、HTML-PPT 不受影响。
- 保存推荐值和用户确认结果；确认结果覆盖推荐值，并支持幂等读取与恢复。
- 本任务不创建逐页 SVG，不生成或验收 PPTX 成片。
