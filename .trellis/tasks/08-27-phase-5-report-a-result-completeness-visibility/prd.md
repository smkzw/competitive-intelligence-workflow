# A 类结果完整性与安全热图可见性修复

## 目标

修复已交付特应性皮炎 A 类纵向切片中两个直接影响医学经理使用的缺陷：来源已有结果却未进入报告，以及安全性矩阵在首页和安全性页默认横向溢出。

## 已确认现状

- 报告含 38 条疗效数值，但 19 个结果承载产品各只保留一个终点的治疗组/对照组；例如 NCT02277743 登记结果实际含 21 个结局指标。
- 安全性共 152 行，仅 38 行有数值：任何 SAE 34 行、任何 TEAE 4 行，常见 AE 与 AESI 均为 0 行。
- 这不是来源普遍没有数据。以 NCT02277743 为例，嵌入的登记原文含 3 个安全组、22 个严重不良事件和 6 个其他不良事件；当前研究包却把全部常见 AE 写成“未公开”。
- 当前热图以产品为列，CSS 为每个产品保留至少 100px；38 个产品导致矩阵天然超过 4,000px，首页缩到 68px 仍超过默认视野。

## 必须实现

1. 研究包不得只满足“每个成熟产品一个疗效终点、TEAE 或 SAE 任一数值”的最低生成条件后就宣称结果完整。来源中已登记的结局指标、严重不良事件及达到报告阈值的常见 AE 必须被抽取或形成精确、可审计的未抽取诊断。
2. 任何 TEAE 不得由 ClinicalTrials.gov 的 `otherNumAffected` 伪装；AESI 也不得从普通 AE 名称自行推断。确实没有明确聚合值时继续标注未公开，但不能因此丢弃来源中逐事件数值。
3. 详细疗效页保留全部可解析终点、时间点、组别、单位和分析人群；首页仍按约定的常用主要终点形成摘要，不以首页摘要反向裁掉详情数据。
4. 安全性页至少展示任何 TEAE、任何 SAE、明确 AESI 和适应症常见 AE 的已公开组别数值；治疗组与对照组保持可切换并保留时间窗、分子/分母与披露状态。
5. 首页及安全性详情页在 1280px 默认视野内不得出现矩阵级横向拖动。产品改为纵向行、有限安全维度改为横向列，或采用等价的无横向溢出布局；全部产品不得被任意删减。
6. 图形先于完整表格，筛选后图表与表格使用同一行集合；面向用户文字保持中文临床语境，不显示工程标签或制作日志。

## 不做

- 不做安全攻防或系统安全专项测试。
- 不把本修复扩展为 B/C 页面、PDF、HTML-PPT 或 PPTX。
- 不对无明确来源的 TEAE、AESI 或常见 AE 进行推测填数。

## 完成判据

- 自动化反例证明：当嵌入登记来源含可解析结局或常见 AE、而报告遗漏时，研究包在生成前失败关闭并给出精确中文诊断。
- 修复后的特应性皮炎研究包与报告重新生成；抽取数量、来源定位、组别映射和披露状态经确定性检查与独立临床复核。
- 1280、1440、1920 三档 Chromium/WebKit 实屏验证首页和安全性页无横向矩阵滚动，全部产品可纵向查看，筛选有效，控制台无错误。
- 定向测试、A 类联合回归、全工程回归、Ruff、strict mypy、`git diff --check` 通过；产物清单绑定修复后的提交与当前数据摘要。
