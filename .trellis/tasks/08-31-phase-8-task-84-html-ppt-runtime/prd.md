# Task 8.4 需求

- 固定 `1280×720` 逻辑画布，仅在共同祖先 `.deck` 上按 `min(vw/1280,vh/720)` 单次等比缩放并双轴居中。
- 运行时只服务 HTML-PPT：方向键、空格、Home/End、`#/N` 深链、页码、进度条、全屏、`N` 笔记、`S` 讲者视图、当前/下一页、逐字稿、计时与 `R` 重置。
- 模块化维护母版完全离线；不加载通用主题，不保留 `T/A/O` 主题、演示动画或错误总览能力。
- 讲者预览加载同一 deck；观众与讲者双向同步；`?preview=N` 为无导航单页预览。
- 运行时视觉不得覆盖项目康哲主题；正式 FX 资产由项目 `design_specs` 在 Task 8.5 注入。
- 真实 `file://` 环境中 Chromium 与 WebKit 无远程渲染依赖、无页面错误。
