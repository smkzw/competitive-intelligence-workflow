# Task 6.5 基线观察事实与逐组完整性条件

## 目标

建立 B 类报告可追溯、可比较但不强行标准化的 `baseline_observation` 合同，并把组别基线样本量、年龄、性别构成和适应症严重程度锚点确定性接入现有 B 类逐核心试验逐组关键证据条件。关键字段不足时不生成草稿，先穷尽检索并给用户简洁中文协助指引。

## 范围

- 强类型保存产品、核心试验、队列、组别、基线分析人群、变量域、来源原名/定义、规范概念、量表/版本/方向/理论范围、数据类型、统计形式、值/单位/离散度或区间、分类水平/分箱、分子/分母、基线定义、来源版本/定位、披露状态、兼容规则与差异标签。
- 变量域至少覆盖人口学、疾病语境、基线严重程度；本任务只建事实与完整性合同，Task 6.6 再建图表和页面视图。
- 连续变量分别保存均值、标准差、中位数、四分位数、范围和来源明确的其他统计形式，不互换、不补造误差线。
- 分类比例必须有明确分母；不自动重分箱、不强制二元化、不以 100% 减法补造类别。
- 只有规范概念、量表/版本、方向、单位、基线定义和统计形式兼容时进入同一比较桶，否则保留差异并分列。
- 复用 `FactDisclosureState`、`EvidenceLocator`、稳定身份和现有 `GateSpec`；不另建冲突的缺失状态或第二套门槛引擎。

## 逐组关键条件

对每项适格核心结果试验的每个可比较组，以下四项均须由该试验该组自己的已报告事实满足：

1. 基线样本量：明确数值、分母、分析人群和单位；
2. 基线年龄：明确数值、来源定义、统计形式、分析人群和单位；
3. 基线性别构成：至少一个来源明确的分类水平，包含数值、分母和分析人群；
4. 适应症严重程度锚点：至少一个 GateSpec 指定或当前适应症认可的严重度/活动度指标，包含量表定义、单位、分析人群和基线时间。

试验总体值、另一组值、另一试验值、未知/未公开/冲突/技术路径未解决状态均不得借用。若来源确实未公开，经过既定双重穷尽后阻断草稿并告诉用户缺哪项、影响什么、可提供哪份材料；不得用零或模板占位。

## 不可放宽的要求

- 同一行不得跨产品、试验、队列或组别；行身份与来源版本、定位和内容状态闭合。
- 明确零与未报告分开；披露缺口不得携带数值，已报告事实不得缺少来源定位。
- 均值不得标成中位数；标准差、标准误、四分位距、置信区间和范围分别建模。
- 分类比例的分子、分母和来源报告比例必须一致或保留差异，不得自行修正来源。
- `not_applicable` 只接受版本化适用性依据；关键四项为始终适用，不允许借此绕过。
- Gate 绑定必须使用同一事实版本和明确 group/trial 作用域；重复绑定同一事实不能满足多个独立组。

## 验收标准

- [ ] `test_baseline_group_gate.py` 覆盖每核心试验每组四项关键条件、跨组/跨试验借用拒绝、严重程度锚点、Gate 绑定与无草稿阻断。
- [ ] 现有 B GateSpec 和 Task 3 门槛/阻断流程保持单一权威；无第二套状态机。
- [ ] Task 6.1–6.4、A/B 报告及相关来源回归通过；Ruff、strict mypy、schema 与差异检查通过。
- [ ] 独立医学经理复核确认“来源未公开”和“检索/技术路径未解决”分开，用户协助指引简洁、明确、可执行。
