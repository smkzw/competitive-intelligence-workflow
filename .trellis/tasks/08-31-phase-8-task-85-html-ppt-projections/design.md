# Task 8.5 设计

## 生成路径

`locked report-data / research-content` → 报告类型投影器 → 共享幻灯片视觉语法 → 单文件 HTML-PPT → Task 8.6 真实最大化窗口终验。

## 介质边界

- HTML-PPT 不是门户缩屏，也不是 PDF 页面翻版；每页只回答一个演示问题。
- 表格责任仍由 HTML/PDF 承担；HTML-PPT 用图表、数字块、简化对照和关键注释展示直接结果。
- 共享 Task 8.4 运行时，但所有视觉样式仅来自项目冻结的 `core + project_profile + track_htmlppt + htmlppt_fx`。

## 三份稿件的建议叙事体量

- A：15 页为基线结构；主要疗效系列超出单页可读容量时，按靶点分组增设续页，不因固定页数截断产品或缩字。
- B：24 页左右，完整展开疗效、安全性、基线和试验完成情况，不随意精简用户指定模块。
- C：16–20 页，以“元素对照 → 具体试验 → 可选路径”为主线，必须能精确定位药物、试验、评分和时间点。

## 视觉语法

- 浅色面积不低于 80%，主强调 `#FF9900`，风险红只用于风险语义。
- 封面/章节/结束页使用环境深度层；内容页用浅色页眉、斜切橙色身份和图表入场，禁止深色霓虹和内容页毛玻璃墙。
- 主图表占据页面主体；结论句不超过两行，不把备注、版本、证据口径做成主要卡片。
- 报告页不使用纯英文身份词、后端枚举值或工程调试文案。

## 输出结构

- `src/ci_workflow/renderers/html_ppt/`：共享组件、图表 SVG、A/B/C 投影器、单文件组装与清单。
- `output/html-ppt/`：三份当前候选 HTML。
- `tests/html_ppt/`：结构、内容、字号、逐字稿、离线、运行时和浏览器合同。
- `docs/acceptance/runs/8.5/`：生成哈希、页数、清单和基础浏览器证据；逐页视觉结论属于 Task 8.6。
