# Task 8.5 需求

## 用户结果

用户可直接打开 A/B/C 三份 HTML-PPT，用键盘翻页、打开逐字稿和中文演讲者视图；每份稿件必须以图形优先、视觉先行的方式直接展示锁定结果，不讲解系统流程、证据门槛或技术标签。

## 必须满足

- A/B/C 分别从当前锁定结构化报告数据生成，不从 PDF 或门户 DOM/截图生成。
- 三份稿件都是单文件、离线、固定 1280×720 画布，复用 Task 8.4 运行时。
- 康哲 Logo、品牌令牌、视觉母版、`gx_fx.css` 和 `gx_fx.js` 全部内联；运行时无网络请求。
- 三份稿件都包含封面、目录/路线、首页摘要、主题页、总结/结束页；正文页图表优先，不复制全量表格。
- A 覆盖竞争格局、产品与开发、疗效、安全性、疗效-安全性矩阵、中国/全球监管、企业/交易/专利及局限。
- B 覆盖疗效、纵向结果、安全性、矩阵、基线人口学/疾病严重度、试验完成情况全部模块、试验/产品档案及局限。
- C 覆盖设计图谱、人群/疾病定义、入排、干预/对照、终点/时间点、访视/疗程/随访、样本量/分析集/统计、逐试验档案、设计模式/可选路径及局限。
- 每张 slide 都有 150–300 个中文字符的口语化逐字稿，包含 `<strong>` 提示信号；观众页不显示逐字稿。
- 所有可见文字中文原生，清除工程/日志/prompt 语言；不低于项目 HTML-PPT 字号下限。

## 本步完成证据

- 三份单文件 HTML 可在 `file://` 打开，每页无滚动/溢出，并且清单绑定当前输入哈希。
- 至少覆盖 Chromium 和 WebKit 的结构/功能合同；Task 8.6 完成最大化窗口逐页原图验收。
- 禁用类、遥测属性、外链资源、逐字稿长度、Logo/FX/运行时注入均有可重跑断言。
