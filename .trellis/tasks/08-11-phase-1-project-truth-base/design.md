# Phase 1 技术边界

## 真源与分层

- Pydantic 领域合同负责输入、枚举和跨字段不变量；JSON Schema 是可安装包与宿主之间的机器合同。
- `ArtifactPathService` 是报告路径唯一构造器；持久记录只保存项目根内相对路径。
- SQLite 保存结构化版本事实，内容库保存不可变原文，JSONL 保存事件，检查点仅保存可重放执行状态。
- 数据截止时点属于项目合同版本；创建时物化，恢复不重算，扩大截止日只通过新合同版本。

## 用户体验约束

- 用户只提供报告类型、适应症和可选输出；不得要求用户理解枚举、目录或内部状态。
- 对用户显示简洁中文里程碑或阻断说明；代码枚举和诊断仅保存于项目记录。
- 任一分支能力缺失不得误伤已满足条件的其他报告或格式。

## 验证策略

- 每个 Task 严格使用计划列出的测试集合先 RED 后 GREEN。
- Phase 1 退出必须验证项目移动、数据库完整性、不可变链、事件重放和选择性预检。
- 独立 reviewer 只能依据代码、测试和真实空项目锚点接受或否决。
