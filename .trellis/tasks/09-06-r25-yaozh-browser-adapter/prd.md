# PRD — R2.5 药智可选浏览器适配与会话真值

## 目标

把当前“项目回答 available → 规划可选路线”推进为可验证的宿主浏览器合同：只有宿主
实际观察到药智企业版已登录页面时才报告路线 ready；能启动空白 Chromium 不能代表
会话有效。所有持久化对象均无用户名、密码、Cookie、token、授权头、浏览器存储或
会话轨迹。

## 用户结果

- 用户每项目仍只回答一次是否具备访问条件；运行期会话失效不改写该回答。
- 会话有效时，Agent 可将药智页面转为带商业数据库身份、内容摘要和外部定位的来源
  捕获；会话过期、验证码、权限不足或工具缺失时给出对应中文动作，但不阻断核心研究。
- 药智内容只用于线索与交叉核验，不能单独满足关键临床数值、监管状态或科学结论。

## 退出条件

- 假登录阳性被消除；宿主观察与确定性回执绑定项目、回答摘要、时间、来源域和结果状态。
- session expired、captcha、permission denied、tool unavailable、parser failure 分离，重复
  提交字节幂等，漂移或秘密/本机路径失败关闭。
- research-package 可明确承载药智商业数据库来源，并保持 source-policy 的 lead/cross-check
  上限；不能通过重标来源角色升级为 direct。
- 聚焦、集成、全仓 gate、bundle/fresh-install 与独立审阅通过；真实账号 smoke 另以无敏感
  截图、无会话数据的受控回执验收。

## 排除

不保存或自动抽取浏览器凭据，不复制 Edge 用户配置，不绕过验证码，不建设通用浏览器
自动化框架，不让药智成为必需来源，不进入真实三宿主 RC 或 24 门户验收。
