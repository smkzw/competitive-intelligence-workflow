# Task 6.4 疗效—安全性气泡图和比较矩阵

## 目标

把 Task 6.2 的疗效事实和 Task 6.3 的安全性事实接成面向医学经理的可配置气泡图与比较矩阵，使用户可直观看到不同竞品的潜在疗效信号、安全性观察位置和样本量，同时始终保留原始治疗—对照事实及不可比状态。

## 范围

- 默认横轴使用当前常用主要疗效终点的方向校正试验内治疗—对照信号。
- 默认纵轴使用治疗组原始 TEAE 发生率并倒序映射；明确“向上＝发生率更低＝观察到的安全性位置更有利”。
- 默认气泡面积正比于治疗组样本量，半径按平方根关系计算。
- 支持切换疗效终点、效应形式、时间点、分析人群、安全性维度/事件/窗口/分母、气泡大小、产品、试验和靶点。
- 建立可比、不兼容、未报告、不适用、待核实等矩阵状态。
- 本任务只创建强类型视图和交互状态，不创建 HTML，不计算综合分数或排名。

## 不可放宽的要求

- 每个气泡只绑定一个产品的一项明确试验和组别事实，不跨试验合并。
- 横轴方向校正不得覆盖原始疗效方向、治疗组与对照组数值；无可比治疗—对照信号时不伪造坐标。
- 纵轴使用原始安全性发生率，倒序仅是视觉映射；不得变成“安全性得分”。
- 气泡面积而非半径与样本量成正比；未知样本量不伪装为零。
- 每次筛选同步更新图、表、提示、证据链接和网址状态，所有表面引用同一行标识。
- 不兼容、未报告、不适用、待核实均为有意义状态，不得用空白代替。
- 不生成默认名次、综合分数或头对头结论。

## 验收标准

- [ ] `test_bubble_area.py` 覆盖面积公式、轴方向、原始事实保留、未知状态和无排名。
- [ ] `test_matrix_states.py` 覆盖五类矩阵状态、同一事实行、筛选/表格/证据/网址同步及可逆重置。
- [ ] Task 6.1–6.3、A/B 报告及相关来源回归通过；Ruff、strict mypy、差异检查通过。
- [ ] 独立医学经理复核确认气泡图只是二维观察工具，没有暗示跨试验因果比较或综合优劣。
