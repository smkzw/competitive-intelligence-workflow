# Task 8.6 设计

以当前 A/B/C 哈希为起点，建立逐页截图台账、DOM/控制台/网络合同和医学经理视觉审阅表。每轮遵循“当前原图 → 缺陷归因 → 最小修订 → 全相关页回归 → 原会话复验”，直至三位点名测试者与 Codex 均无确定性阻断。

报告内容、数据与证据口径冻结；允许修改主题、图表布局、标签避让、间距、字体、色彩、阴影、动效和中文原生表达。任何重新渲染都必须重算哈希并复验六个长英文标签。

## 本轮视觉决策

- 采用“结论先行、直接标注、弱化非必要图形、来源就近”的编辑原则；只借鉴咨询出版物的信息组织，不复制其品牌外观。
- 图表优先减少读者在图例与图形间往返：关键数值与系列身份尽量直接标注；标签密集时先避让、缩短或拆分，不以裁切解决。
- 动效只使用 `transform`、`opacity` 与允许的 SVG 描边属性；响应系统“减少动态效果”，导出与质检态完整冻结。
- 不新增图表依赖：当前 SVG/CSS/JS 已能覆盖本任务，避免在视觉终验阶段引入新的许可、离线和体积风险。
