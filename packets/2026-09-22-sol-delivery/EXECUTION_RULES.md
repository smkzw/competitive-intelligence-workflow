# 执行规范：成批开发验证，不做逐修改全测试

用户明确要求约束构建期测试与过度设计。旧“每任务全gate、每一点RED/GREEN、新三门户/全会商”不再作为粒度要求；最终科学与交付门不降低。

## 1. 工作单位与权限

单位是一个缺陷族或完整用户功能切片，例如分母身份+分类+A/B消费者，不是一行标签。工作包给输入、允许路径、步骤、输出与证据。
禁止git add .、reset/checkout/clean、推测历史提交；保留脏树和未跟踪证据。实施获提交授权时按完整包/连贯里程碑精确路径提交，不每步提交，不自动push/公开发布。
旧中文根不读/写/inventory/chmod/删除；不改封存验收。
默认主模型实施，原生子Agent只用于明确隔离/只读任务；不恢复旧执行/会商runner。产品独立科学复核仍必须，不能主Agent自证。旧日志模型路由不直接生效。

## 2. 强制批次测试节奏

| 时机 | 做什么 | 默认不做 |
|---|---|---|
| 包调查 | 读完整定义/调用/测试，一次成批反例确认 | 每读一个函数跑全pytest |
| 缺陷族开始 | 反例一次写齐，跑一次RED；已有同源可信失败可复用 | 每加assert就单独启动测试 |
| 连贯修改中 | 阅读/静态检查；确有定位需要最小探针并记录理由 | save-hook全测试、每改CSS全mypy、逐标签会商 |
| 包实现完 | 一次相关单元/合同/集成GREEN；UI相关用户旅程 | 重建24门户、每修bug复制完整PNH新项目 |
| 失败后 | 重跑失败及共享合同相关集，修好一次合并回归 | 无新证据重复同套全测试/模型审阅 |
| 接口里程碑 | 一次跨报告/迁移/真实入口集成，必要全开发gate | 每个小包都全gate |
| 最终候选 | 全静态/回归/科学/视觉/安装/恢复/24门户 | 以节省开发时间为由省最终门 |

两次同因失败无新证据须改假设/追调用链/缩最小复现。缩范围只能定位，不能称全仓通过。新回归要证明能在未修逻辑失败，不能补永绿测试。
同一STATUS记批次选择/理由/时间点，结果记命令、commit/dirtyhash、耗时、通过/失败/错误/未测、证据路径；无需额外测试审批系统。耗时用于优化，不设迫使省验收的硬时限。

## 3. 范围与复用

bash tools/gate.sh是quality-only：Ruff src/tests/tools、strict-mypy src/tools、活跃unit+contract、保留轨兼容子集等，不覆盖全部报告/集成/浏览器/真实来源/安装矩阵。不能据此发布。
非HTML留仓静态/合同兼容，排除首版真实输出渲染；PDF原文输入保留。
历史失败只在固定base/head、同环境/锁文件/命令/日志对照后归因，不能凭旧文字称“历史失败”。
证据只在来源/规则/相关代码/产物闭包hash不变时复用。变更重验影响标准，无关模块不全轮重审。
模型独立审阅用于冻结的科学风险批次/最终候选；先逐项处置，再审影响闭包，不每轮A+B+C+多个重叠审阅者。上下文独立不等模型独立；记录真实模型/effort/宿主/请求和输出。pending/空文件/拒绝/未执行不是通过。
阻断按科学/用户任务，不按文案风格。分母错、伪签发、缺来源、错轴不能降P3。

## 4. 目录与资源

代码开发用当前工作区/staging；不用每补丁复制144页。审阅/发布/事实revision形成不可变目标，禁止在已接受快照换字节。
RunContext显式，不读/tmp全局指针；CAS共享，缓存键含source bytes/提取器/规则/模型版本。动态核查不得被缓存替代。
测试临时文件归统一临时根；里程碑清理确认无引用、无运行使用、可再生缓存。保留来源、快照、最小失败样本、回执、恢复包，不动会话/数据库/归档历史。无明确清单时不删。禁止整runs删除或广域rm。

## 5. 最小设计

先复用再扩展，不给每个文档名词建服务。新依赖记录必要性、许可、体积、离线支持。
不引入LangGraph强依赖、graph DB、通用本体/DSL、PKI、云账号/多人协作，不把Jinja/JS整体迁移新框架。图库只画图不裁决医学。不得对PNH产品名写特判，应修共同身份并加非PNH反例。

## 6. 收尾和连续性

每包仅一次主记录：完成/待验/阻断、源/产物身份、证据范围、下一动作；直接继续下一就绪包。实施细节自行决定，有科学口径/用户行为/范围改变才原生Ask选择题。
终报分开代码、确定性、科学、浏览器、分享、安装/宿主、恢复、RC状态。缺一层不能由其他层抵消；未实际全部过门不得输出RC_FROZEN/RELEASED。
