# PRD：HTML 竞品调研多 Skill 套件 · 2026-09-22 交付基线

版本：交付基线 v2.3（0924V1 来源语义/候选纠偏，沿用 W00–W10）。产品范围来自用户原 Goal、后续裁决、五项正式新增需求及 2026-09-23 桌面范围变更；工程方案见 DESIGN。历史移动端通过/失败记录保留，但不继承为本版桌面验收。0924V1 不增加第四门户或新的发布阶段；真实状态只见 STATUS 顶节。

## 1. 用户与价值

用户是非技术背景、视觉敏感、需要深度证据的临床试验医学人员。输入适应症，选择A/B/C；系统完成研究与独立复核，交付能搜索、筛选、比较、追溯、修订和离线携带的报告。用户不编排Skill、不查内部JSON、不做工程测试。不提供自动研发结论或唯一最佳方案。

成功任务：找全相关创新竞品；理解试验差异与证据限制；找到并横比完整设计先例；修改真实事实后看到所有相关报告一致更新；把当前版本连同视图配置离线分享。页面/模型/测试次数不是成功指标。

## 3. 入口与正常旅程

1. 一句话解析适应症、报告类型、截止日；仅缺少实质选择时Ask，不让用户填工程字段。A研究管线全景，B研究结果差异，C研究方案设计先例。
2. 预检来源访问、文件处理、浏览器、独立上下文。药智可选失败不阻断核心；独立复核能力不可用不静默降级。
3. 同项目A/B/C复用一次必要检索与原文抽取，分别有自己的分析与门户。单独A、B或C无需生成其他门户。
4. 展示可解释的进展/必需补件，不把Gate/Prompt/检索日志放报告首屏。
5. 事实→图→完整表→来源原文下钻一致；零结果筛选保持零结果，不恢复全量冒充命中。
6. 用户保存修订后明确“用户修订，未独立复核”及来源原始值；旧版和旧复核仍可查，不能冒充新接受。
7. 保存配置可跨重开复用；导出静态分享后无需Python/Agent/网络阅读。离线编辑不在本轮浏览器只读分享要求内，需由安装工作流重开。

## 4. 科学合同

### 4.1 创新范围与完整性
创新疗法为竞品主集合；传统药可作为背景/救援/对照，不据结果多寡决定是否保留产品。相关性纳排须有版本化理由。中国登记/监管和全球登记/监管分别核验；公司网页/商业库可发现线索但不能替代声明域权威来源。关闭路线失败必须显式，不能伪造空轮收敛。数量不是完整性的充分证明。

### 4.2 时间、来源与Publication
区分公开日、生效日、观察窗、获取日、截止日。截止日前已公开但当时未知后续状态不得倒填；无法恢复历史来源时写限制。论文不按固定TTL丢弃，动态监管/管线不因缓存仍有效而跳过核查。
必需论文无法获取：Markdown清单、链接、唯一收件目录；验证格式/DOI/登记号/全文适格性，记录原名/hash/目标名，冲突失败且不改原文件字节。扫描PDF使用已配置OCR能力，不强行把空文本当无论文。用户同快照确认无法取得后不反复问；核心可答限制作答，否则证据不足页。证据不足页不能计入24完整门户验收。

### 4.3 事实与数值
完整语义包含人群、背景治疗、终点/事件定义、量表/方向、估计目标、分析集、统计形式、时间锚点/窗口、组/队列/期间、分母及统计对象。unknown不是zero、none或相同。
人数比例、事件次数、人时率、调整估计值分别建模；次数可大于人数但不得计算成受试者比例。报告调整率/LS mean不可由编辑n/N擅自覆盖。无控制组不得显示伪差值。分母关系必须证明，不能靠标题像、N相同或只剩一个候选。
ClinicalTrials.gov 的 AE `numAffected` 缺失时一律记“未知，待核”，即使已知 `numAtRisk` 也不得推断 0 或计算零风险率；只有原文明确为 0 才记真零，精确来源路径及恢复状态必须可查。
安全类别保留否定、严重性、TEAE、相关性、等级集合与统计对象；Grade4、Grade1或3、Grade≥3不同；非严重TEAE不升级全部TEAE；无SAE不当有SAE。复合父项不任意拆数/相加，明确子行依原文区分。
来源原子保留原始测量实例、class/category、组/臂、单位、统计形式、分析人群、访视或区间及精确来源路径；直接值、语义域、可比资格和派生值是不同层。分母缺失/冲突只影响比例派生，不能删原始人数或同测量其他组。相同数值/ID不自动表示同一统计对象，来源顺序不决定对照关系。非 AE 不自动归疗效：免疫原性、PK/PD、生物标志物和未裁决结果保留独立域/指标，再按 A/B/C 用户任务决定展示用途。非疗效观察不能自动进入疗效共同数值轴。

### 4.4 B语义与数值资格
先决定研究是否相关，再分面，最后判是否可同轴。48/50周等临床近窗可在完整语义适合时同框并弱提示，不以精确字符串分裂；不同量表/方向/估计目标/分母/分析集硬冲突不得被LLM覆盖。28天与4周仅在同锚点语义下精确换算，1月不固定等于4周。
所有相关研究可达；不可同轴保留计数/原因/小图或表，不生成空坐标。禁止默认总排名、综合效益安全分数、Meta/NMA或自动研发建议。

## 5. 三个门户

**共同要求**：中文临床语言、高密度且可读；字体、可访问性、键盘、来源编号和桌面工作区几何共享，A/B/C业务模板独立。支持 1440×900、1600×900、1920×1080、2560×1440 CSS viewport；记录实际 clientWidth/DPR，浏览器缩放后仍落在支持范围的桌面视口应可用。305/320/390 手机和 1024 竖屏退出 0923V1 发布门，历史证据原样保留；这不豁免 Chromium/WebKit、键盘回焦、阅读放大、真实来源、三宿主或24门户。宽屏画布用于并列比较、表格与证据，长段正文仍限制行长；标题、版本、常用筛选和限制摘要应使默认核心分析尽早进入首屏。建议 y≤280px 为设计目标，须在真实页面验证并记录合理例外，不能隐藏必要限制换取指标。卡片和图形按当前可绘观察、glyph、系列、标签和语义复杂度选形态与尺寸；单观察默认紧凑事实行，双观察优先小型比较，复杂矩阵才占整行。图和表共享完整查询 Q 与 fact 身份；未绘制须给出真实原因和全量记录入口，不得称作“未公开”或画空坐标。密度优化不得靠全局缩小字体、隐藏事实、全页横滚或 overflow:hidden 掩盖裁切；宽矩阵可在清楚边界内局部横滚。内部ID可保留机器绑定但不成为用户正文；绝对内部路径不得分享。每页统一来源区列外链、类型、公开日期、数据截止和必要限制；原始支持可逐事实到达。

**A**：管线全景、靶点—产品关系、阶段矩阵、地域状态时间线、疗效比较、安全密集对照与语义适格热图、多维气泡。阶段/状态/地域不同维度；I/IV/临床前/未知均可达。创新竞品宇宙不可因缺结果被删。不默认每产品只取一个“最好”终点/时点。不同数值框不得因首条输入顺序丢失分面；单组局部极值不用于全宽装饰条。登记试验的申办方须与已核研发/持权企业、许可关系分开；靶点未核者不得计为一个已知靶点或共同机制，来源集合尚未闭包时不得称“完整竞品宇宙”。
**B**：全部相关研究分面；疗效/安全/基线/亚组/暴露/处置；三类版本化气泡预设（疗效×总体安全+治疗N/暴露、疗效×严重风险+有效分析集、持续性×停药+长期暴露）。预设不足时诚实禁用，不补造数据。多臂/对照/单臂和统计类型保留，原数/方向/窗口/分母在折叠表完整展示。
**C**：默认是先例库，不要求生成候选方案。搜索中英关键词/临床主题→选择研究列→共同点/差异→完整条款/来源。保留母子句AND/OR/NOT、例外、阈值、条件人群、版本、组期；原文不可被译文/主题词覆盖。一项有效研究即可使用，未完整先例保留且显式缺口；设计模式与可选路径可有，不输出唯一最佳方案。

## 6. 编辑、配置、离线与运行

编辑是真正改当前事实而非批注或手动patch。需显式用户保存；省略字段保持原值、设置字段采用新值、清除允许字段产生显式空值及有效披露状态，不接受字符串“None”代替缺失。用户清除数值时显示“用户清除，待重新核实”，保留原来源数值可查，当前数值及依赖派生失效；这不同于“来源未公开”。原始来源不改，保存产生user_modified事实版本；原有审阅不继承。一次保存原子重建所有合法绑定的A/B/C页面/表/图/叙事/索引/来源指针，未依赖的报告不强制改动；其他同数字事实不变。两个标签页旧revision冲突明确；失败保持旧current，幂等恢复。
配置只保存合法可序列化状态，不保存函数/HTML/会话。图例隐藏、框选、缩放是视觉状态，不无声改研究集合；用户明确筛选才改变query。
分享A/B/C可单份或组合，无融合首页；资源/数据依赖闭合，当前修订默认生效；不能旧HTML+手动导入补丁。来源版权许可限制继续有效，不默认附药智商业全文/受限论文。可携合法摘录、定位与外链，受限原文清楚标注在线/授权需要。
分享必须从当次已提交的 current generation 生成。报告行/页面/row ID 是消费绑定，不改变同一来源原子的科学事实版本；来源版本、原始值、分析人群、时间或统计语境变化则依版本政策形成新事实。研究与产品可多对多关联，结果组别必须有明确臂关系；未知关系保留未知，不能按干预数组顺序强行归属。
本地编辑服务按需启动且仅loopback，不是云服务；严格Host/Origin/会话/CSRF/路径检查。静态分享读取不依赖服务或localStorage仍存在。

## 7. 最终验收与排除项

24门户：特应性皮炎、重度哮喘、类风湿关节炎、溃疡性结肠炎、CRSwNP、结节性痒疹、IgAN、PNH各A/B/C。全部物理页在 Chromium/WebKit 的 1440×900、1600×900、1920×1080、2560×1440 CSS viewport 验收；稀疏、密集、筛选后稀疏和证据侧栏四状态分别留首屏与局部截图，并记录实际内容宽、DPR、关键 bbox、卡片间距/内边距、图形高度及溢出。还须核验交互、键盘回焦、图表数值、全量数据可达及逐事实来源。分页/虚拟化允许初始 DOM 只显示一部分，但所有页稳定 ID 并集须等于查询 Q，最后一条可搜索、打开、定位来源并返回原位置。安全热图作为同事件、同统计对象、同时间/分析语境和兼容单位的可用视图；不规定固定颜色种数，零与缺失分开、同值同色。三宿主真实安装/入口/失败恢复/语义一致，不要求用户同事测试。
不交付PDF/HTML-PPT/PPTX、CSV/XLSX、雷达/证据成熟度、自动监测、排名/评分/Meta/NMA、强制LangGraph；不增加多人账号/批注云协作。PDF输入处理可保留。
发布状态仅开发候选→RC_FROZEN→RELEASED。内容复核/用户修订状态是正交状态，不新增复杂试用版本体系。旧根零接触；退役另需既定运行/恢复达标与用户再次明确授权。
