# 01 · PRD v2（临床试验医学经理工作台 · 竞品调研子系统）

## 1. 定位
- 医学经理工作台的一个子系统；**单用户、独立部署的 Web 服务**。
- 用户输入适应症与需求 → 平台自动跑完调研流水线 → 在平台内以 HTML 门户展示 A/B/C 报告。
- 内嵌最小 Skill Harness（下称 DSH）：平台自己执行 Skill，不依赖外部 Agent 宿主。

## 2. 用户与场景
用户：临床试验医学经理（中文工作语言，熟悉临床终点与安全性语义）。场景不定顺序，按需选择：

| 报告 | 回答的问题 | 主要来源 |
|---|---|---|
| A 竞争格局 | 该适应症有哪些药、谁在做、到哪一阶段、中国权益/MAH 在谁手里 | 中国登记/CDE/NMPA、CT.gov、企业管线、微信公众号、Drugs@FDA |
| B 疗效与安全性 | 关键终点与安全性怎么横比 | CT.gov 结构化结果、PubMed/PMC、会议摘要、FDA 审评 |
| C 试验设计先例 | 我们的方案怎么设计（终点/时间点/样本量/对照/入排） | CT.gov、中国登记、论文方法学 |

## 3. 功能需求
| ID | 需求 | 验收 |
|---|---|---|
| FR1 | 新建项目：适应症、报告类型（多选）、需求原话、关注点；历史截止日待M5版本资格筛选接通后开放 | Web 表单 + `POST /api/projects`；此前历史请求明确失败，不生成伪历史报告 |
| FR2 | 单进程串行排队，重复启动不重复执行；可停止并沿用已完成资料恢复 | 项目页阶段表、停止与继续；`resume_run` |
| FR3 | **中国竞品宇宙必须全面**：必跑路线 + 靶点/企业/别名反向扩展 | 每条路线在覆盖台账留痕；M2 用专家金标准清单验召回率 ≥95% |
| FR4 | 国际竞品尽可能充分：CT.gov、Drugs@FDA、PubMed、会议（全网搜索） | 覆盖台账 |
| FR5 | 覆盖率是**可见指标而不是门**：被拦截/失败的路线如实显示，不阻止出报告 | 门户「检索覆盖」区块 |
| FR6 | 字段分级：critical 严格核验（固定来源版本、逐字片段及数值）；旧模型的已核实标签须有当前规则回执，原记录不改写 | `domain/tiers.py`、`verify/assessment.py`；全部消费者读取当前裁决 |
| FR7 | 图表数值轴只放已核实数据；不可比条件（终点/时间点/统计形式/单位）分组作图 | `render/portal.py::data_b` |
| FR8 | 临床语义硬规则：unknown≠0、人数≠次数、比例只由人数/同组分母派生、安全类别保留否定/严重性/分级 | `domain/semantics.py` 单测 |
| FR9 | 每个事实可追溯：来源 URL、原文片段、抽取方式（code/llm）、历史及当前核验状态；修订前记录明确为当时状态，具体复核原因只在展开的依据内显示 | 门户表格 + `/api/projects/{id}/facts`，不增加默认正文提醒 |
| FR10 | Agent 全程留痕可回放 | `/api/runs/{id}/steps` |
| FR11 | 门户使用康哲设计 tokens + ECharts 与对应表格；桌面充分利用横向宽度，筛选后图表与表格一致 | 四桌面1440/1600/1920/2560实屏 |
| FR12 | 微信公众号检索作为可插拔外部 Skill；仅作线索来源 | `CIW_WECHAT_SEARCH_CMD` |

**明确不做**：报告内编辑、同步、撤销、配置界面、离线分享包（v1 FR13–16）；PDF/PPTX 导出；多用户/权限体系；商业数据库。

### 研究范围与部分资料恢复
- 同进程共享浏览器的任务串行执行，不同项目排队；同项目正在排队/执行时重复提交返回既有运行。取消排队任务不得开始来源或模型调用；执行中的任务在下一阶段、工具或来源单元边界停止，已完成资料和同run合格缓存保留。取消不是来源失败，不应触发备用模型；当前网络调用可完成，不强杀线程。恢复从受影响阶段重算下游，不能沿用旧空成功。本能力不承诺跨进程调度；其他进程持有的运行明确报冲突，不在启动时改写它的状态。
- 明确排除的研究或仅关联明确排除药物的研究，不继续抓取/进入A/B/C当前比较；多药研究只要仍有纳入或待核候选即保留，缺关系/待核不能按排除处理。范围变化是查询投影，不删除历史事实、来源或组别，恢复范围后仍可读取。
- trial_evidence的未完单元/来源失败不阻止已有资料继续核验与渲染，但该次运行保持失败及具体待办，不能宣称全流程完成。恢复复用合格来源单元并重建受影响的下游报告，不重复采集已完成邻居。

### 专家阅读与摘要
- 主层保留正式药名、短适应症、期别及有来源的MAH/研发角色；长登记人群逐字折叠，不能改写成未经证明的项目人群。已有明确MAH/研发角色时，冗长申办方/登记申请人放“其他企业”，只有这些角色时仍默认显示；全称、角色和来源不删除或伪归集团。C数值的来源入口行内呈现并给出字段级可访问名称，完整事实/修订/入排原文仍由统一阅读器可达，年龄依据不重复生成；短靶点标识保持一行，长组合允许换行，不缩字号或遮内容。
- 中国登记已结构化的临床表直接按原字段入库，不要求模型再次改写：保留全量终点、条件性PK、全部强度/对照组、完整入排及原文定位；计划、已入组进度、最终实际人数和地域分别保存。登记申请人、登记适应症、真实健康受试者信息和原分期共同进入阅读层；申请人不被推断为MAH，空缺或原文冲突不推算成剂量/人数。明确“曾用名”字段与药名主层分开保留，空字段标签不充当药名。
- 明确四列“企业选择不公示”终点行记为该字段未公开，不造终点或阻断其余完整记录；无解释的坏表仍报解析问题。年龄上下界分别核对数字和原始单位，非数值上界保留原文及缺口，不显示“无岁”、不推成无上限。表单“其他说明”只在显示层整理；明确列举多个适应症且完整一项匹配项目时主层可显示该项，完整原登记适应症默认折叠；有否定、限定或无法精确匹配的原句不裁改。
- 同一中国登记文档采用完整原子事务和当前来源指针；恢复不重复写入，失败不切换旧current、不改历史来源或独立论文/模型事实。每次新运行核查来源，同run已完成的来源/规则绑定单元可复用；单项失败和显式预算留下具体待办，不以少数试验替代全部应查CTR。
- 研究的默认可见身份为药物/方案、适应症、期别与有来源的公司角色；登记编号保留检索/跳转但居次。A研究列表、B组别结果、C设计/终点索引、图表及依据阅读复用同一投影；展示名不改变科学ID。正式中文名优先，没有已核实中文名不硬译；申办方不能冒充中国MAH，MAH所属集团仍须单独查证。
- 正式名称须由当前已核实的名称事实及项目来源支持，不将发现阶段name_zh直接认证为正式名称。NMPA证书仅在完整中/英文产品名唯一字面匹配时采用；多证书并存、证书内版本替换保留全部历史。每条名称与中国MAH可原位查看证号、规格、原字段和来源；空持有人不借生产商/境内责任人，证书不直接推导适应症批准或集团。每次研究运行重新核查已发现的动态证书，同run可复用核验缓存。
- 证书身份只能由实体原名或当前有来源的名称事实建立，发现中文名/别名不能单独认证另一药物，也不能推翻已经成立的来源绑定。项目内同证号/类别只保留一个当前实体归属；跨实体改变保留为未解，不自动改绑。采用规则升级须重新核对固定来源，旧规则事实保留历史但不自我认证。获取、发证/批准、有效期日期在共享依据中简洁呈现；获取时已过有效期的仅称许可记录持有人，不推断续期、撤销或当前适应症批准。不增设第二轮用户批准或医学批注。
- A/B/C共用来源档案：靶点、类型、研发/权益方、MAH集团及项目适应症的地域开发状态不由发现attrs直接认证。复用extract-results的identity_enrichment模式、逐药恢复和现有核验事务，不增加第十个Skill。集团关系保留持有人法律实体、明确控制关系及来源截至日期；同品牌/合作/代理不作控股证明。阶段原值/适应症/地域/截至日期与引文保留，多个冲突状态并列可查，不按数组顺序或最高数值择一。证据默认折叠，不向读者铺防御说明。靶点与研发代号按完整标识核对，IL-31RA的31不能借作临床数值。
- 名称、公司和档案依据复用原有阅读窗，打开原文不改变比较表列宽，不把长英文塞进药物单元格；键盘打开、关闭和实际触发者回焦一致。完整入排的周平均/平均评分阈值保留原统计限定并原位强调，不把周平均NRS变成某一次访视的NRS。
- 默认每个药物/研究使用一个身份依据入口，名称、MAH、集团与研发/登记角色仍直接可见；来源窗保留所有事实引用、法律实体、许可/观察日期。相同固定来源版本的相同引文只显示一次，不同来源版本不得因URL或引文相同合并。通用类型按确切词表显示中文，原始类型值和引文不变；未知值不猜译，已知同义标签只在显示层去重。
- 入排按原文位置提取明确评分和检验不等式，保留量表、符号、数值、单位、入选/排除、队列和完整条件。用中文阈值索引协助阅读；完整原文逐字保留，以深红加粗/下划线标阈值，以字重/下划线标逻辑和否定。不把斜线改写为“或”，不把混合AND/OR改成单一逻辑，不跨队列合并条款；未识别句子仍完整可达。原文是安全文本，不执行其中HTML或指令。
- 评分离散选择（如2或3）保留为列举值，不变成连续区间或下限；同句紧邻的双侧不等式均可提取并保留连接词，不跨条款/换行/另一指标继承。AST/ALT括号组合、SCr及明确中文正常值上限倍数按源表达呈现，不把斜线推成OR、不补未写单位。此为阅读投影，不自动判定受试者入排。
- 默认层不铺大段英文，不整段染红，也不因原文“可展开”就判为可读；真实原文、未覆盖表达和访视/时间条件均保留，不臆造中文医学结论。用真实原文正反例和实际页面验收。
- B全部相关结果按临床结果、安全性、药代、药效、免疫原性、生物标志物和其他研究指标导航；有临床结果时优先进入该领域，全部记录及完整原表始终可达。领域选择和文本查询共同驱动图/表，不把PRIMARY/SECONDARY当临床域。按实际测量词义及来源支持的局部药物分析物关系归类，不按药名后缀、单独AUC/ADA/BSA缩写或背景治疗名猜测；混合/未解指标保留原名、值、单位及来源。领域是可逆阅读投影，不改科学事实，也不代替数值共轴资格。
- 面向资深临床试验人员，正文只写有证据引用的医学信息。禁止把“边界、限制、不等于、非头对头、仅供参考”等泛化提醒及模型/流程/输入字段说明堆进报告；保留原始科学上下文和真实核实状态。
- 检索路线、命中及内部运行状态留在项目工作台，不进入A/B/C正文；来源链接、原始记录和值不因此删除。统计形式和常见测量单位使用共同精确显示映射，未知原文不猜译；原始单位/统计仍可展开查看，不换算数值或把百分号改成概率。折线标值错开线条，并按实际四宽图面核验，不能以代码选项通过替代实看。
- 没有设计/结果资料时显示简洁资料不足状态，不调用模型生成解释墙，不画空坐标轴。
- A 的靶点/阶段图不把未知属性算成可绘观察；未知候选仍完整保留在管线表。图和表按同一实体ID集合筛选，计数随查询更新；少量内容收紧高度，多靶点完整保留并可滚动查看，不以巨型单色块、重叠图例或缩字号填屏。正向布局夹具只证明几何，不替代真实来源富集验收。
- 摘要不凑条数。发布的要点必须引用当前已核实事实；模型原始回复留在内部记录，不能直接当成报告内容。
- 研究原始记录包与要点归并分开预算：前者每包≤24000字符，后者每包≤8000字符；中间归并至多2条，最终至多6条。所有完整候选要点都经过归并，不抽Top-N，不截断单条临床定义；门户全量事实/原文不受摘要条数影响。归并单元单独缓存，后续失败不重做已合格归并或资料研究。
- C 的主要和次要终点均保留所有测量实例、完整定义、访视/区间及逐项事实引用；同字段多条记录不得后写覆盖。摘要输入与页面投影须核对这一集合，不以来源库仍有原文冒充消费完整。
- C标量也按观察保留：计划/实际入组、组、人群、访视和单位不同不能互相取代。唯一已核实观察优先显示，待核提案原位折叠；多个已核实观察等权显示，各自关联数值、上下文和依据，不按数据库顺序或来源级别选真值。概览数值图只采用无歧义的已核实观察，其余完整保留在对照表与依据中。
- 抽取采用整批原子写入；相同run、阶段及提案的恢复重放不得重复新增事实或把已通过修订降为冲突。明确supersedes必须同项目、实体、字段及科学上下文；不同上下文保留为独立观察。旧值、旧引文与来源版本通过C修订前记录只读可达。抽取结果绑定本次实际读取的唯一来源版本；读了同URL多个版本但不能逐事实确定时保留待核，不猜最新版本。
- 默认阅读层中文呈现规范状态、分组及年龄单位，未知编码/原始医学名称不猜译；完整终点定义、组别说明、入排逻辑与来源原文原位展开。页面正文和控件不低于16px，桌面四宽实屏另行验收，代码检查不代替审美接受。
- C概览图按真实条目数收敛高度，筛后稀疏状态不能沿用密集空壳；全量图数据/对应表/来源保持同查询。长入排原文通过同页宽幅阅读打开，不挤在窄单元格；原文和事实引用不复制改写。关闭/Esc回实际触发者并保留查询，缺少JS/native dialog时原details内容仍可读。
- C期别分布以紧凑整数计数条形呈现，筛后单类别收紧，不保留低信息圆环空壳；同药同期别的不同研究，图上保留临床名称并追加次级登记号消歧，完整显示可见点的标签，不退回仅编号或按顺序混同研究。
- 大资料集按完整业务记录分批总结再归并，不以固定150条替代全量输入。只去除摘要不需重复携带的来源全文/图形配置及可由fact_id定位的重复地址/定位元数据；临床定义、访视/区间、分析人群、统计形式及入排逻辑保持完整。每份摘要任务JSON（含关注点与引用ID）≤24000字符；单条定义过大时明确失败，不截断定义。包含大量终点的单项研究允许按完整终点分包，每包重复研究、药物、组别、人群与入排上下文，标记研究分包序号/总数及主要/次要终点总数；不把分包算作新研究，不拆单个定义，不裁掉尾部终点。该预算不限制完整门户或抽取任务范围。
- 合格分批结果可在同一运行中恢复；数据、规则、Skill、输出合同或指定模型变化即失效。复用不等于新的模型调用，不等于已完成独立科学验收。
- 候选纳排也处理全量集合，每批至多30个完整候选、任务JSON至多60000字符；不是Top-N。结论绑定候选ID和原名/已知别名，去标点或共享别名不构成实体等同。缺项、重复或错误绑定保留为待核并记录问题，不后写覆盖、不静默排除；有这些问题的批次不缓存为可复用结果。
- 同一字面身份规则延伸到试验关联和事实写回，正式中文名、短代码可匹配，不用删标点/子串宣称同一药物。剂量/剂型/复合标签及共享别名等宽检索命中保留为待核候选关联，不删除研究、不冒充已确认身份。无法唯一归属的抽取事实留在抽取记录及问题清单，不猜归父药物；其他正常事实继续处理。M2须用来源解决别名及剂型关系，不能把全部待核永久视作完成。
- 默认遍历完整登记游标、全部匹配研究和药物，不以50/15/30等内部数量代替完成范围。明确执行预算耗尽或部分抽取失败时，保存未处理ID/单元及合格既有结果；未完状态不能标为成功，其他不受阻部分可继续呈现。恢复只补未完或输入/所用来源/规则/模型改变的单元；它不是一次新的资料核查。

## 4. 非功能
- 开发状态保留适应症的人群/严重程度及声明截至日，默认格中同时显示；明确“成人中重度特应性皮炎”的批准不得泛化为所有年龄/严重程度。相同项目疾病的明确年龄/程度限定可作为独立来源观察；不同限定/期别并列，不选最大或最后一条。公告中的日期声明不是实际批准日或今日仍有效的证明；获取日、Updated不自动补为as_of。默认不增加说明墙，资格规则在后台，实际范围/日期与原文依据可读。
- 阶段图与表共用完整来源观察，图中保留地域、原人群/疾病范围、声明日期、来源类型与事实引用；不同限定阶段可以同时绘制，不因标量unknown而丢记录、不加“见表格”等防御段落。阶段计数按每个明确范围/日期的药物去重，来源事实引用并集完整；不是互斥比例或取最高阶段。企业公告作为该来源的阶段声明呈现“企业公告”标签，不充当监管核准标签全文；监管原文的既往治疗条件、Updated与企业声明日期不拼接，不借此认证完整M3或历史版本资格。
- 安装包包含9个同字节内嵌Skill；默认不依赖开发目录，显式Skill路径覆盖不静默回退。构建不递归清除未知目录、不跟随作者或输出符号链接；缺失/空Skill配置的现有校验命令失败且不创建资料。不新增诊断平台、安装服务或第二套Skill作者源。
- v2加固阶段支持在项目工作台下载当前事实JSON/CSV；仅选择该项目current_facts，按事实source_id附精确来源版本/摘要及原始语境，不按同URL猜最新源。零、缺失、布尔、空串与结构化值保留类型；CSV的value_json/context_json供无损读取，文本公式前缀安全转义并以csv_escaped_fields显式列出，JSON保持原文。导出只读、不调用模型或来源、不附凭据/日志/CAS全文，不是项目备份或离线分享包；历史截止日未支持时不能把当前数据包装成当时版本。
- 部署：单机 `ciw2 serve`；默认只监听 127.0.0.1；对外时设 `CIW_ACCESS_TOKEN`。
- LLM：OpenAI 兼容接口；当前指定 cms-router/glm-5.3-flash，备用 DGX/deepseek → DGX/qwen。切换需保留实际模型与路由记录，密钥只来自环境变量。
- 模型输出预算用满不能当成完成：即使残留JSON可解析也不接受截断回复。仅finish_reason=length允许原模型/原输入一次扩大输出预算（8192→16384上限），失败再走既定备用；不关闭思考、不改effort、不截医学输入。首次失败与成功/二次失败的安全用量都留痕，不能只记最后回复成本。
- 搜索服务异常不得将请求URL、密钥或服务原始报错落入日志/回传模型；保留实际HTTP状态/异常类型。服务失败、数据格式损坏、未配置和真正空结果分别处理，中国来源备用site检索有独立覆盖记录；HTTP200本身不证明检索成功。
- 数据：SQLite + 内容寻址存储（CAS），全部在 `CIW_DATA_DIR`，不入 git。
- 文本型PDF经已安装原生解析器读取，固定原始字节、完整正文、页码/字符定位及实际解析版本；原件相同而解析结果/规则改变不覆盖旧来源。网络核查与解析复用分开记账，不能以缓存冒充本次HTTP、以下载时间证明历史公开资格。解析/扫描失败保留原件和具体处理问题，不生成空结果或自动调用OCR、不绕过访问权限；科学结论仍须满足原文与语境核验。
- NMPA原证书中的正式商品名独立保留来源/证号/原值定位，不等同于发现别名或新的通用名。只有当前来源中唯一归属的注册商品名可辅助识别官方原文的明确药物类型同位表述；重名、另一药物、否定或仅同句共现不建立靶点关系。相关核验同时绑定采用的名称事实，名称依据撤回、重名或提交期间变化时，不继续沿用旧核验结果；历史科学值/旧源不改写。
- 靶点/类型的名称依据含当前正式中英文名、实体原名及会造成前缀冲突的注册品牌，不只绑定短品牌；离线复核提交时复验当前依据，失效不追加已确认回执或计入已确认数。科研类型描述中的完整靶点标识不是负数；研发方须有明确研发关系，“某公司的产品”、制造或销售不作研发证明。公告Updated日期与获批日期分开保存。
- 同位置的长/短注册品牌歧义双向保留待核；单纯存在否定与“无进展生存期”等正常术语分开。研发药物的生产工艺不等于研发药物本身；4-1BB等分段标识不提供人数，真实数值区间与负数分别核对。离线试算同样复查当前成员及依据，但不追加裁决。
- 门户先完成本批模板和临时文件准备，再逐文件原子替换；模板/准备写入失败保留旧报告字节，渲染重试不重跑已成功前置阶段。多文件替换不是整批事务；后续文件替换失败必须如实标记阶段失败，不宣称全部更新或断电恢复通过。
- 一次 A 报告运行目标 ≤30 分钟、LLM 成本可控（每个 Skill 有步数预算）。
- 公共仓库：不得提交本机路径、密钥、第三方全文、运行产物。
- 恢复运行必须属于当前项目；不存在或跨项目的运行ID在创建/更改运行及初始化模型前拒绝，不损害原运行记录。
