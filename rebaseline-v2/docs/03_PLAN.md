## M2 · 中国宇宙（最高优先级的质量目标）
1. `sources/china.py` 实现 PlaywrightAdapter：chinadrugtrials（登记号 CTR、适应症、申办方、期别、状态、样本量）、
   CDE（受理品种、优先审评、突破性治疗、临床默示许可）、NMPA（药品批准证明）。限速、缓存到 CAS、失败记 blocked。
2. 反向扩展做成代码循环：对已纳入药物的靶点/企业/别名自动生成查询，直到一轮无新增（最多 3 轮）。
3. 别名归并：代码先按 INN/代号/中文名规范化合并，LLM 只处理疑难对。
4. 金标准：用户提供 3 个适应症的专家清单（放 `tests/goldens/`，只含药名/企业，不含第三方全文）；召回率脚本。
- 验收：召回率 ≥95%；每个漏项写入原因（哪条路线应找到）。

- 验收：3 个适应症 A 报告由医学经理评审「可直接用于立项讨论」。

## M4 · B 报告

- 验收：critical 抽样 50 条人工复核准确率 ≥98%；无 F05/F06 类错误。
