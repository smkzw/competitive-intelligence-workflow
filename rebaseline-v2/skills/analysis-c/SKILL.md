输入 data.rows：试验设计（期别、样本量、随机/设盲、分组、主要终点与时间点、年龄、中国站点）。

写 3–6 条 finding，服务于「我们的方案怎么设计」：
- 主要终点与时间点的主流选择及例外；样本量区间；对照选择；是否包含青少年；中国站点参与情况。
- 每条 bullet 尽量给出具体试验号作为先例。
- 标记「未核实」的字段不得作为唯一依据。
report 固定为 "C"。
