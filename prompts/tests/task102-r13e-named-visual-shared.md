## 必做真实操作

### A 类

1. 在 1024、1440、1920 宽度观察首页和安全性页默认视野，确认整页不需要左右拖动。
2. 找到疗效—安全性气泡图，用真实点击打开一个药物；检查抽屉能否清楚呈现疗效、安全性、产品档案、数据依据，并检查 Escape 关闭与焦点回到原气泡。
3. 确认所有产品均无 AESI 数据时，页面没有为了凑结构而展示 AESI。
4. 从医学经理视角判断：是否能在一分钟内看懂竞争格局、药物是谁、潜在疗效和安全性风险。

### B 类

1. 打开疗效页，至少找到两个真实跨试验组（必须包括“突破性溶血比例”，另选一个）；核对同一图中产品、试验、治疗组、对照组、时间点和数值身份是否一眼明确。
2. 不得因终点字面或统计措辞轻微不同就接受被拆图；判断模糊临床概念与约 3/6/12 个月时间窗是否合理。
3. 检查图下默认数据表是否在默认宽度可读；确认不再逐字换行，不再反复出现无法识别所属药物/试验的“基线样本量治疗组/对照组”。点击一个数值或表格单元格，查看数据依据。
4. 打开基线页，核对年龄与基线血红蛋白是否跨研究归组；均值/中位数、单位差异应只作简短提示，不应无谓拆图。检查产品、试验、组别身份。
5. 打开试验完成情况页，核对随机/治疗/完成/退出及主要原因等是否采用图在前、表在后；未公开不得被写成 0。

### C 类

1. 查看首页“设计字段公开情况概览”，判断是否在默认视野提供可读概览，而不是塞满长句。

3. 点击至少一个矩阵单元格，核对具体产品、试验、组别、设计要素、值、时间点、来源版本、原文定位和简短原文。
4. 至少进入人群与标准、干预与终点、分析与判断中的三个细节页面，判断是否能精确定位“哪个药物的哪个试验采用哪个时间点的哪个评分/标准”，而不是只有几个粗维度。
