# A 类数值缺失与安全性矩阵复核

## 结论

本次问题不是单一的“页面漏显示”，而是四类问题叠加：

1. **默认疗效口径过窄**：首页强制要求第16周 EASI-75，已有第4、8、12周结果或采用 IGA 0/1 主终点的产品被隐藏。
2. **安全性术语未归并**：`Headache / HEADACHE`、`Nasopharyngitis / NASOPHARYNGITIS` 被拆成不同维度，已有数值未进入默认热图。
3. **总体 TEAE 来源覆盖不足**：ClinicalTrials.gov 结果主要提供逐项 SAE/常见 AE，不能把多个事件的人数相加后冒充“任何 TEAE”。原数据门槛又允许成熟产品只凭 SAE 通过，导致默认总体 TEAE 列存在不符合成熟度的空白。
4. **旧空值占位与已补证据并存**：新取得的总体 TEAE 已进入事实集，但旧的空值占位行、事实和结论没有同步移除，仍可能在展示层制造“未公开”假象。

## 五层对账

| 层级 | 当前证据 | 判断 |
|---|---:|---|
| 来源取得 | 38 个产品、49 项试验、86 条来源 | 登记结果与主要论文/监管材料交叉补证；仍没有公开结果的产品保留未公开 |
| 事实抽取 | 疗效 6,780 行均为数值；安全性 10,228 行中 10,152 行为已公开数值 | 没有发现已入包数值在抽取时丢失；总行数不能代表产品级覆盖 |
| 临床归一 | 头痛、鼻咽炎存在大小写别名 | 受控归并后各由 13 个产品提升至 16 个产品；`Tension Headache` 未错误并入 |
| 报告投影 | 首页原仅显示 21 个产品的疗效 | 主终点/时间点回退后显示 28 个产品；剩余 10 个产品确无疗效数值 |
| 默认可见 | 原安全性热图大量总体 TEAE 为空，宽屏还出现 3+1 分块 | 当前 1024 px 以上四维同矩阵；768 px 为 2+2；两种内核均无横向拖动 |

## 当前产品级覆盖

- 有任意疗效数值：28/38；无疗效数值：杰克替尼、Bempikibart、Barzolvolimab、Lutikizumab、CM326、IBI356、SHR-1905、TQH2722、SKB575 / HBM7575、ANB032。
- 有任意安全性数值：26/38；12 个产品在当前证据范围内仍无量化安全性结果。
- 治疗组有精确“任何 TEAE”：20/38；治疗组与对照组均有精确“任何 TEAE”：19/38。
- 疗效有数值：28/38；安全性任一维度有数值：26/38。剩余缺口是当前证据中确实未公开或未取得的结果，不再是旧空值覆盖新数值。

## 已修复的用户可见行为

- 首页疗效按产品优先显示最接近第16周的 EASI-75；未采用该终点时显示 IGA 0/1，并逐产品标出指标与时间点。
- 安全性图与筛选使用同一受控术语键；保留原始术语、试验、组别和观察窗。
- 安全性矩阵按产品纵向、事件横向排列；768 px 为两块各 2 个维度，1024/1280/1440 px 为单矩阵 4 个维度。
- 数值格显示中文观察窗短标签，原始观察窗保留在悬停信息和明细表中。
- 长矩阵的维度列头固定在站点导航下方；首页、详情页共用同一布局与数据选择函数。
- “未公开”与“暂无公开记录”继续分开，不以零填补缺失。
