# 竞品调研站点设计配置

用户当前要求、事实真实性与现行任务包高于品牌默认值。本文件只登记本项目
适配，不是第二套产品 PRD。当前规范为 Kangzhe Design 6.0.0 / KZ6-0929-A04。

- 唯一交付轨为 HTML-only 站点。A/B/C 独立且同优先级，不把三类业务模板融合。
- 目标桌面视口为 1440×900、1600×900、1920×1080、2560×1440 CSS px；这是用户
  明确指定的项目矩阵，替代通用 site_viewports 默认值。手机历史证据不改写，
  不恢复移动发布门。键盘、跨浏览器、缩放、减少动态与来源访问仍须验证。
- tokens/tokens.json 是品牌数值唯一来源；本项目选择整页 responsive 正文档，
  实际字号与共同间距登记在页面计划。正文与必要标签地板为 16px，不逐卡缩字。
- 利用宽度靠真实分类、并列比较与合理网格；缩短稀疏卡的高度，不填假点、
  空坐标轴、冗余说明，不裁字。完整原文和未绘制原因保持可达。
- 所有结构化数据采用合适图形与原位折叠完整表格；数值图采用 ECharts，
  单观察事实行不是伪柱图。无法制图的文本以可检索对照表呈现。
- 每页来源区必须保留登记、监管、论文等实际外部来源与版本、截止和限制。
  本公开技术/医学研究报告不适用 PPT 的简化引用规则，不展示内部路径、
  Gate、提示词、调试标签或凭据。事实修订保留原来源值及用户修改状态。
- 站点不使用 PPT 双菱形、PPT 页眉、播放工具条或固定幻灯片画布。
- 当前选择 global_procedural_optical_field；该选择只是计划，必须由真实
  页面运行、逐页首屏业务叙事、生命周期、静态真值和视觉证据证明豁免。
  普通渐变、库文件存在或组件 PASS 不能冒称动态和审美验收。
- 只引入站点适用的规范所有者、tokens 与官方 Logo，不加载旧设计轨或
  HTML-PPT/PPT/PDF 运行资源。旧 design_specs 保留为历史开发资料。
- design_specs/schemas 下的三份 CI 视觉回执 schema 是现有应用适配合同，
  不构成旧版品牌规范入口；本次不为更新品牌而另造渲染框架或任务平台。
- 正式交付仍受当前科学、来源、视觉、保存、分享、安装/三宿主、恢复和
  24 门户验收约束，P0/P1 清零；局部通过不宣布 RC。

## 加载顺序

读取 design_specs/00-authority.md、01-core.md、03-typography-language.md、
04-image-pipeline.md、tracks-site.md；随后按本页功能读取 02-liquid-glass.md、
05-charts.md、06-motion-film.md、07-drilldown.md。时间结构才使用 08-gantt.md；
原登记方案时间默认只读，不因参考组件有编辑能力就改写来源。
制作前锁定页面与电影计划，终审读取 10-quality-gates.md。12-reference-patterns.md
是机制参考，不增加 ARCO 或其他示例运行依赖。

规范中的 runtime、tools、schemas 路径描述上游能力和证据要求，本目录不是
完整上游引擎安装包。CI 使用自己的现有 portal 作者资产；不得因这里未带
上游实现而声称功能不存在，也不得复制旧代码补缺。需要接口时由项目资料包
指向已核验的上游接口，安装后的正常报告运行不依赖用户个人目录。
