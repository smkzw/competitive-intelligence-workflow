# 竞品调研工作流 · 原生 PDF 轨

本轨与 `core.md`、`project_profile.md`、`track_stream.md` 一起加载，仅用于原生 PDF。

## 1. 交付定位

- PDF 是独立排版的正式阅读文件，不是门户打印页、网页截图集合或幻灯片导出替代物。
- 内容直接呈现用户筛选后的结果；没有筛选时呈现该报告默认全量结果。
- 信息密度高且完整，段落逻辑清楚，视觉克制；不增设工作流、筛选说明、数据版本或验收过程页面。

## 2. 页面结构

- A/B/C 各自拥有封面、目录、首页摘要、按门户页面责任展开的正文、证据索引和必要附录。
- 首页摘要与门户使用同一锁定数据，但按纸面阅读顺序重新排版。
- 疗效、安全性、疗效—安全性矩阵、基线和试验完成情况均先图后表；图表与表格共享稳定 row ID。
- 宽表优先横向页面、分组续表或拆成相邻页面；不得把表格压到不可读字号。
- 跨页表必须重复表头，并显示“续表”；药物、试验、治疗组和时间点上下文不能在换页后丢失。

## 3. 原生结构

- 文字必须可选择和搜索；不得把整页或正文栅格化。
- 图形优先矢量；确需位图时保留足够分辨率并限定在图片内容本身。
- 生成书签、目录跳转、页码、文档标题和报告类型元数据。
- 字体嵌入或使用项目许可的可替代字体；中文不得乱码、缺字或回退到不可控字体。

## 4. 排版与可读性

- 正文默认不低于 9.5 pt，图表标签和表体默认不低于 8.5 pt，参考文献不低于 7.5 pt；能拆页时不得用缩字解决容量问题。
- 页边距、页眉页脚和正文互不重叠；段落标题不得孤行留在页底。
- 重点结论采用康哲橙黄强调和中性层级，不使用大面积品牌色背景。
- 红色只用于安全风险、关键缺口和必须注意的比较限制。

## 5. 图表

- 疗效使用柱状图、折线图或森林图，并同时保留试验组和安慰剂/对照组。
- 安全性使用分维度热图，不用简单排名；色阶图例必须可读且兼顾灰度打印辨识。
- 疗效—安全性矩阵使用气泡图，默认映射与门户一致；静态 PDF 必须在图旁列出当前映射。
- 图表不得依赖悬停才能理解；交互态信息必须投影为可见标签、图例或表格。

## 6. 机器验收

- 使用 PDF 解析器证明存在原生文本、书签、页码和预期页数范围。
- 检查空白页、孤立标题、裁切、重叠、续表表头、字体、乱码、图表分辨率和链接。
- 逐页渲染为当前 PDF 绑定的图像进行人工检查；旧渲染图或截图不能作为证据。
- 逐页抽取文本并与 coverage projection 对账；缺少门户责任或静默删值时失败。
- 非原生 PDF、网页截图拼接、PPT 导出冒充、旧文件改写 mtime 均为负例。
