# A 类历史失败样本

这些目录只保存能够稳定复现旧工程缺陷的最小脱敏片段，不迁移旧运行时、旧模板或旧数据结构。`sample.json` 中的 `source_sha256` 是旧工程原文件摘要，用于证明样本来源未被替换；负例验收器必须逐项否决。

| 目录 | 旧工程相对来源类别 | 裁剪说明 | 必须识别的问题 |
|---|---|---|---|
| `legacy-a-five-products-zero-trials` | 旧 A 类交付清单 | 仅保留产品数、试验数及报告类型 | 有 5 个产品但 0 项试验，不能视为完整报告 |
| `legacy-a-style-break` | 旧站点样式表 | 保留导致页面不可读的 `body` 规则 | CSS 变量表达式缺少闭合括号 |
| `legacy-a-false-green` | 旧 CSU 质量检查结果 | 保留卡片计数与总判定 | 0 项试验、0 个关键卡片仍被判为通过 |
| `legacy-a-ad-shell` | 旧 AD 质量检查结果 | 保留内容计数和交付判定 | 没有可追溯报告内容却形成空壳交付 |

样本中不含凭证、个人信息或旧工程绝对路径。旧工程在 Phase 10 获得用户明确授权前保持只读，本目录只承担回归测试职责。
