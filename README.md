# 竞品调研多 Skill 工作流

这是按已批准 v1.2 规格净重构的新工程。它面向资深临床试验医学人员，通过一个入口完成 A 类适应症竞品档案、B 类临床试验结果调研和 C 类临床试验方案设计调研，并按需生成站点式 HTML、原生 PDF、HTML-PPT 与可编辑 PPTX。

当前状态：Phase 0 基线建设。旧工程仅作为迁移证据读取，不参与新系统运行。

## 产品底线

- 关键证据不足时不生成草稿或占位报告。
- 只纳入创新药；传统药仅可作为背景、救援或对照事实出现。
- A、B、C 是三个各自完整的多页面门户，不以首页或 Top-N 摘要代替正文。
- 用户可见语言采用中文原生临床试验表达，不展示检索日志、Prompt 或后端标签。
- 所有格式从同一不可变报告快照生成，但分别按其原生媒介验收。

## 项目管理

工程使用 Trellis 保存任务、设计、实施和恢复状态。当前任务可用以下命令查看：

```bash
python3 ./.trellis/scripts/task.py current --source
python3 ./.trellis/scripts/task.py list
```

正式运行命令将在 Phase 0 的 CLI 合同冻结后提供。
